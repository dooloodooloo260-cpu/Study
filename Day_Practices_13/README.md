# Day 13: LeetCode бодлого

Энд бодлого бүрийн зорилго, ямар төрлийн асуудалд хэрэглэх, бодож эхлэх чиглэлийг Монгол хэлээр товчлов. Оролтын нарийн формат, жишээ, хязгаарлалтыг LeetCode холбоосоос шалгаарай.

Өнөөдрийн 5 бодлого. Бусад өдрийн бодлоготой давхцахгүй.

1. [Plus One](https://leetcode.com/problems/plus-one/) — #66 · Easy
   - **Зорилго:** Массив эсвэл тоон дарааллын элементүүдээс нэрэнд заасан үр дүнг олж/өөрчил.
   - **Хэрэглээ:** Жагсаалтын хос, хэсэг, дараалал болон байрлалыг тооцоход.
   - **Бодох чиглэл:** Сүүлийн цифрээс эхлэн carry-г дамжуулж, бүх цифр 9 байх тохиолдлыг шалга.
2. [Add Binary](https://leetcode.com/problems/add-binary/) — #67 · Easy
   - **Зорилго:** Тоог хоёртын дүрслэлд хувирган битийн түвшинд нэрэнд заасан тооцоог хий.
   - **Хэрэглээ:** Flag/permission багцлах, битэн төлөв хадгалах, хурдан XOR тооцоонд.
   - **Бодох чиглэл:** Хоёр мөрийг баруунаас зүүн тийш нэмээд carry-г хадгал.
3. [Text Justification](https://leetcode.com/problems/text-justification/) — #68 · Hard
   - **Зорилго:** Текстийн тэмдэгт, хэсэг эсвэл дүрмийг шалгаж нэрэнд заасан үр дүнг гарга.
   - **Хэрэглээ:** Текст хайлт, өгөгдөл цэвэрлэх, формат шалгах болон хэлний боловсруулалтад.
   - **Бодох чиглэл:** Тэмдэг бүрийг нэг удаа боловсруулах боломжийг хайж, давтамж эсвэл индекс хадгал.
4. [Sqrt(x)](https://leetcode.com/problems/sqrtx/) — #69 · Easy
   - **Зорилго:** x-ийн квадрат язгуурын бүхэл хэсгийг үржүүлэх функц ашиглалгүй ол.
   - **Хэрэглээ:** Том хайлтын муж, босго утга, эрэмбэлэгдсэн өгөгдөлд хурдан хайлт хийхэд.
   - **Бодох чиглэл:** Хариуны мужид binary search хийж mid² утгыг үржүүлгийн overflow-оос хамгаалан харьцуул.
5. [Climbing Stairs](https://leetcode.com/problems/climbing-stairs/) — #70 · Easy
   - **Зорилго:** Нэг эсвэл хоёр алхмаар шат өгсөх боломжийн тоог ол.
   - **Хэрэглээ:** Олон сонголтоос ашиг/зардал, алхам, замын хамгийн сайн үр дүнг тооцоход.
   - **Бодох чиглэл:** Алхам n-д хүрэх боломжийг өмнөх нэг ба хоёр алхмын тоонуудын нийлбэрээр DP хий.
