# Day 32: LeetCode бодлого

Энд бодлого бүрийн зорилго, ямар төрлийн асуудалд хэрэглэх, бодож эхлэх чиглэлийг Монгол хэлээр товчлов. Оролтын нарийн формат, жишээ, хязгаарлалтыг LeetCode холбоосоос шалгаарай.

Өнөөдрийн 5 бодлого. Бусад өдрийн бодлоготой давхцахгүй.

1. [Intersection of Two Linked Lists](https://leetcode.com/problems/intersection-of-two-linked-lists/) — #160 · Easy
   - **Зорилго:** Холбоост жагсаалтын зангилаа, заагчийг ашиглан нэрэнд заасан үйлдлийг хий.
   - **Хэрэглээ:** Дараалсан өгөгдөлд оруулах/устгах, холбоос урвуулах болон жагсаалтыг алхахад.
   - **Бодох чиглэл:** Заагчийн өмнөх/дараах холбоог тэмдэглэж, өөрчлөхөөс өмнө дараагийн зангилааг хадгал.
2. [Find Peak Element](https://leetcode.com/problems/find-peak-element/) — #162 · Medium
   - **Зорилго:** Өгөгдлөөс зорилтот утга, байрлал эсвэл мужийг ол; эхний/сүүлийн тохиолдлыг шаардлагатай бол ялга.
   - **Хэрэглээ:** Том хайлтын муж, босго утга, эрэмбэлэгдсэн өгөгдөлд хурдан хайлт хийхэд.
   - **Бодох чиглэл:** Монотон нөхцөл эсвэл хөршийн хамааралд binary search хийж хайлтын мужийг багасга.
3. [Maximum Gap](https://leetcode.com/problems/maximum-gap/) — #164 · Medium
   - **Зорилго:** Боломжит сонголтуудаас нэрэнд заасан хамгийн их утга эсвэл хэмжээг тооц.
   - **Хэрэглээ:** Тайлангийн дараалал, эрэмбэлсэн хайлт, давхцал болон top-K олоход.
   - **Бодох чиглэл:** Эрэмбэлсний дараа нэг нэвтрэлт, хоёр заагч эсвэл greedy сонголт хийж болохыг шалга.
4. [Compare Version Numbers](https://leetcode.com/problems/compare-version-numbers/) — #165 · Medium
   - **Зорилго:** Текстийн тэмдэгт, хэсэг эсвэл дүрмийг шалгаж нэрэнд заасан үр дүнг гарга.
   - **Хэрэглээ:** Текст хайлт, өгөгдөл цэвэрлэх, формат шалгах болон хэлний боловсруулалтад.
   - **Бодох чиглэл:** Тэмдэгтүүдийг зүүнээс баруун тийш төлөвтэй уншиж, тэмдэг/цифр/тусгаарлагчийн дүрмийг шалга.
5. [Fraction to Recurring Decimal](https://leetcode.com/problems/fraction-to-recurring-decimal/) — #166 · Medium
   - **Зорилго:** Томьёо, тоон шинж эсвэл хязгаарыг ашиглан математикийн үр дүнг тооц.
   - **Хэрэглээ:** Тоон хөрвүүлэлт, тоолол, геометр, үр ашигтай арифметикт.
   - **Бодох чиглэл:** Хязгаар, parity, модуль эсвэл томьёог ашиглаж бүх хувилбарыг шалгах шаардлагыг багасга.
