# Day 16: LeetCode бодлого

Энд бодлого бүрийн зорилго, ямар төрлийн асуудалд хэрэглэх, бодож эхлэх чиглэлийг Монгол хэлээр товчлов. Оролтын нарийн формат, жишээ, хязгаарлалтыг LeetCode холбоосоос шалгаарай.

Өнөөдрийн 5 бодлого. Бусад өдрийн бодлоготой давхцахгүй.

1. [Search in Rotated Sorted Array II](https://leetcode.com/problems/search-in-rotated-sorted-array-ii/) — #81 · Medium
   - **Зорилго:** Эрэмбэлэгдсэн өгөгдөл эсвэл боломжит хариунаас зорилтот утга, байрлал, хязгаарыг хай.
   - **Хэрэглээ:** Том хайлтын муж, босго утга, эрэмбэлэгдсэн өгөгдөлд хурдан хайлт хийхэд.
   - **Бодох чиглэл:** Зүүн/баруун хязгаарын invariant-аа хадгалан binary search хий.
2. [Remove Duplicates from Sorted List II](https://leetcode.com/problems/remove-duplicates-from-sorted-list-ii/) — #82 · Medium
   - **Зорилго:** Нэрэнд заасан элемент эсвэл зангилааг устгаж үлдсэн өгөгдлийг зөв хадгал.
   - **Хэрэглээ:** Тайлангийн дараалал, эрэмбэлсэн хайлт, давхцал болон top-K олоход.
   - **Бодох чиглэл:** Эрэмбэлсний дараа нэг нэвтрэлт, хоёр заагч эсвэл greedy сонголт хийж болохыг шалга.
3. [Remove Duplicates from Sorted List](https://leetcode.com/problems/remove-duplicates-from-sorted-list/) — #83 · Easy
   - **Зорилго:** Нэрэнд заасан элемент эсвэл зангилааг устгаж үлдсэн өгөгдлийг зөв хадгал.
   - **Хэрэглээ:** Тайлангийн дараалал, эрэмбэлсэн хайлт, давхцал болон top-K олоход.
   - **Бодох чиглэл:** Эрэмбэлсний дараа нэг нэвтрэлт, хоёр заагч эсвэл greedy сонголт хийж болохыг шалга.
4. [Largest Rectangle in Histogram](https://leetcode.com/problems/largest-rectangle-in-histogram/) — #84 · Hard
   - **Зорилго:** Өндрийн histogram дотор багтах хамгийн том тэгш өнцөгтийн талбайг ол.
   - **Хэрэглээ:** Хаалт шалгах, undo, илэрхийлэл задлах болон дараагийн их/бага элементийг олоход.
   - **Бодох чиглэл:** Стекэд хадгалах төлөв, push/pop хийх мөчийг дүрмээр тодорхойл.
5. [Maximal Rectangle](https://leetcode.com/problems/maximal-rectangle/) — #85 · Hard
   - **Зорилго:** Торон хүснэгтийн нүд, хөршийн холбоонд хайлт, тоолол эсвэл замын үр дүнг ол.
   - **Хэрэглээ:** Газрын зураг, зураг-пикселийн бүс, торон тоглоомын байрлал тооцоход.
   - **Бодох чиглэл:** BFS/DFS болон visited ашигла; хамгийн богино алхам шаардвал BFS сонго.
