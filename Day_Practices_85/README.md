# Day 85: LeetCode бодлого

Энд бодлого бүрийн зорилго, ямар төрлийн асуудалд хэрэглэх, бодож эхлэх чиглэлийг Монгол хэлээр товчлов. Оролтын нарийн формат, жишээ, хязгаарлалтыг LeetCode холбоосоос шалгаарай.

Өнөөдрийн 5 бодлого. Бусад өдрийн бодлоготой давхцахгүй.

1. [Game Play Analysis I](https://leetcode.com/problems/game-play-analysis-i/) — #511 · Easy
   - **Зорилго:** Өгөгдлийн сангийн хүснэгтүүдээс нэрэнд заасан хэрэглэгч, бүлэг, эрэмбэ эсвэл статистикийг гарга.
   - **Хэрэглээ:** Тайлан, хэрэглэгчийн үйлдлийн статистик, олон хүснэгтийн өгөгдөл нэгтгэхэд.
   - **Бодох чиглэл:** Түлхүүр, бүлэглэлт, JOIN/window function хэрэгтэй эсэхийг ялгаж, NULL ба давхардлыг шалга.
2. [Find Bottom Left Tree Value](https://leetcode.com/problems/find-bottom-left-tree-value/) — #513 · Medium
   - **Зорилго:** Өгөгдлөөс зорилтот утга, байрлал эсвэл мужийг ол; эхний/сүүлийн тохиолдлыг шаардлагатай бол ялга.
   - **Хэрэглээ:** Файлын хавтас, DOM/JSON зэрэг шаталсан өгөгдөл боловсруулахад.
   - **Бодох чиглэл:** DFS-ийн буцаах утга юу болохыг тодорхойл; хоосон мод, навчийг шалга.
3. [Freedom Trail](https://leetcode.com/problems/freedom-trail/) — #514 · Hard
   - **Зорилго:** Асуудлыг давтагддаг жижиг төлөвүүдэд хувааж боломжийн тоо эсвэл хамгийн сайн үр дүнг ол.
   - **Хэрэглээ:** Олон сонголтоос ашиг/зардал, алхам, замын хамгийн сайн үр дүнг тооцоход.
   - **Бодох чиглэл:** Төлөв, шилжилт, base case-аа бичээд давтагдсан дэд асуудлын хариуг хадгал.
4. [Find Largest Value in Each Tree Row](https://leetcode.com/problems/find-largest-value-in-each-tree-row/) — #515 · Medium
   - **Зорилго:** Өгөгдлөөс зорилтот утга, байрлал эсвэл мужийг ол; эхний/сүүлийн тохиолдлыг шаардлагатай бол ялга.
   - **Хэрэглээ:** Файлын хавтас, DOM/JSON зэрэг шаталсан өгөгдөл боловсруулахад.
   - **Бодох чиглэл:** DFS-ийн буцаах утга юу болохыг тодорхойл; хоосон мод, навчийг шалга.
5. [Longest Palindromic Subsequence](https://leetcode.com/problems/longest-palindromic-subsequence/) — #516 · Medium
   - **Зорилго:** Нэрэнд заасан нөхцөлийг хангах хамгийн урт/богино хэсэг, зам эсвэл дарааллыг ол.
   - **Хэрэглээ:** Олон сонголтоос ашиг/зардал, алхам, замын хамгийн сайн үр дүнг тооцоход.
   - **Бодох чиглэл:** Хоёр индексийн хоорондох хамгийн урт palindrome-ийн уртыг DP-ээр байгуул.
