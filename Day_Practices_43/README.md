# Day 43: LeetCode бодлого

Энд бодлого бүрийн зорилго, ямар төрлийн асуудалд хэрэглэх, бодож эхлэх чиглэлийг Монгол хэлээр товчлов. Оролтын нарийн формат, жишээ, хязгаарлалтыг LeetCode холбоосоос шалгаарай.

Өнөөдрийн 5 бодлого. Бусад өдрийн бодлоготой давхцахгүй.

1. [Contains Duplicate II](https://leetcode.com/problems/contains-duplicate-ii/) — #219 · Easy
   - **Зорилго:** HashMap/Set ашиглан давтамж, өмнө үзсэн утга эсвэл хурдан хайлтыг удирд.
   - **Хэрэглээ:** Давхардал илрүүлэх, хос тааруулах, давтамж тоолох, индексжүүлэхэд.
   - **Бодох чиглэл:** HashMap/Set-д түлхүүр хадгалж давтамж, өмнө үзсэн утга эсвэл хосыг хурдан шалга.
2. [Contains Duplicate III](https://leetcode.com/problems/contains-duplicate-iii/) — #220 · Hard
   - **Зорилго:** HashMap/Set ашиглан давтамж, өмнө үзсэн утга эсвэл хурдан хайлтыг удирд.
   - **Хэрэглээ:** Давхардал илрүүлэх, хос тааруулах, давтамж тоолох, индексжүүлэхэд.
   - **Бодох чиглэл:** HashMap/Set-д түлхүүр хадгалж давтамж, өмнө үзсэн утга эсвэл хосыг хурдан шалга.
3. [Maximal Square](https://leetcode.com/problems/maximal-square/) — #221 · Medium
   - **Зорилго:** Торон хүснэгтийн нүд, хөршийн холбоонд хайлт, тоолол эсвэл замын үр дүнг ол.
   - **Хэрэглээ:** Газрын зураг, зураг-пикселийн бүс, торон тоглоомын байрлал тооцоход.
   - **Бодох чиглэл:** BFS/DFS болон visited ашигла; хамгийн богино алхам шаардвал BFS сонго.
4. [Count Complete Tree Nodes](https://leetcode.com/problems/count-complete-tree-nodes/) — #222 · Medium
   - **Зорилго:** Өгөгдсөн оролтоос нэрэнд заасан объект эсвэл тохиолдлын тоог тооц.
   - **Хэрэглээ:** Тайлан, хэрэглэгчийн үйлдлийн статистик, олон хүснэгтийн өгөгдөл нэгтгэхэд.
   - **Бодох чиглэл:** DFS-ийн буцаах утга юу болохыг тодорхойл; хоосон мод, навчийг шалга.
5. [Rectangle Area](https://leetcode.com/problems/rectangle-area/) — #223 · Medium
   - **Зорилго:** Цэг, шулуун, тэгш өнцөгт зэрэг геометрийн объектын хамаарлыг тооц.
   - **Хэрэглээ:** Координатын зураглал, огтлолцол, чиглэл болон талбай тооцоход.
   - **Бодох чиглэл:** Координатын хүрээ, давхцал болон булангийн parity/талбайн нөхцөлийг тооц.
