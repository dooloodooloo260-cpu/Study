# Day 72: LeetCode бодлого

Энд бодлого бүрийн зорилго, ямар төрлийн асуудалд хэрэглэх, бодож эхлэх чиглэлийг Монгол хэлээр товчлов. Оролтын нарийн формат, жишээ, хязгаарлалтыг LeetCode холбоосоос шалгаарай.

Өнөөдрийн 5 бодлого. Бусад өдрийн бодлоготой давхцахгүй.

1. [Number of Segments in a String](https://leetcode.com/problems/number-of-segments-in-a-string/) — #434 · Easy
   - **Зорилго:** Өгөгдсөн оролтоос нэрэнд заасан объект эсвэл тохиолдлын тоог тооц.
   - **Хэрэглээ:** Текст хайлт, өгөгдөл цэвэрлэх, формат шалгах болон хэлний боловсруулалтад.
   - **Бодох чиглэл:** Тэмдэг бүрийг нэг удаа боловсруулах боломжийг хайж, давтамж эсвэл индекс хадгал.
2. [Non-overlapping Intervals](https://leetcode.com/problems/non-overlapping-intervals/) — #435 · Medium
   - **Зорилго:** Хугацаа эсвэл интервалуудын давхцал, нэгтгэл, дараалалтай холбоотой үр дүнг ол.
   - **Хэрэглээ:** Цагийн хуваарь, уулзалтын өрөө, нөөцийн захиалга болон event-ийн мужид.
   - **Бодох чиглэл:** Эхлэх цэгээр эрэмбэлээд өмнөх интервалтай давхцах эсэхээр нэгтгэ.
3. [Find Right Interval](https://leetcode.com/problems/find-right-interval/) — #436 · Medium
   - **Зорилго:** Өгөгдлөөс зорилтот утга, байрлал эсвэл мужийг ол; эхний/сүүлийн тохиолдлыг шаардлагатай бол ялга.
   - **Хэрэглээ:** Цагийн хуваарь, уулзалтын өрөө, нөөцийн захиалга болон event-ийн мужид.
   - **Бодох чиглэл:** Эхлэх цэгээр эрэмбэлээд өмнөх интервалтай давхцах эсэхээр нэгтгэ.
4. [Path Sum III](https://leetcode.com/problems/path-sum-iii/) — #437 · Medium
   - **Зорилго:** Нэрэнд заасан элементүүдийн нийлбэрийг зорилтот нөхцөлтэй уялдуулан ол.
   - **Хэрэглээ:** Жагсаалтын хос, хэсэг, дараалал болон байрлалыг тооцоход.
   - **Бодох чиглэл:** Оролтын хэмжээ, эрэмбэ, давхардалд тулгуурлан HashMap, хоёр заагч, prefix sum эсвэл sliding window-ийг сонго.
5. [Find All Anagrams in a String](https://leetcode.com/problems/find-all-anagrams-in-a-string/) — #438 · Medium
   - **Зорилго:** Өгөгдлөөс зорилтот утга, байрлал эсвэл мужийг ол; эхний/сүүлийн тохиолдлыг шаардлагатай бол ялга.
   - **Хэрэглээ:** Текст хайлт, өгөгдөл цэвэрлэх, формат шалгах болон хэлний боловсруулалтад.
   - **Бодох чиглэл:** Мөр бүрт тэмдэгтийн давтамжийн гарын үсэг эсвэл эрэмбэлсэн түлхүүр үүсгэн бүлэглэ.
