# Day 80: LeetCode бодлого

Энд бодлого бүрийн зорилго, ямар төрлийн асуудалд хэрэглэх, бодож эхлэх чиглэлийг Монгол хэлээр товчлов. Оролтын нарийн формат, жишээ, хязгаарлалтыг LeetCode холбоосоос шалгаарай.

Өнөөдрийн 5 бодлого. Бусад өдрийн бодлоготой давхцахгүй.

1. [Largest Palindrome Product](https://leetcode.com/problems/largest-palindrome-product/) — #479 · Hard
   - **Зорилго:** Текстийн тэмдэгт, хэсэг эсвэл дүрмийг шалгаж нэрэнд заасан үр дүнг гарга.
   - **Хэрэглээ:** Текст хайлт, өгөгдөл цэвэрлэх, формат шалгах болон хэлний боловсруулалтад.
   - **Бодох чиглэл:** Тэмдэг бүрийг нэг удаа боловсруулах боломжийг хайж, давтамж эсвэл индекс хадгал.
2. [Sliding Window Median](https://leetcode.com/problems/sliding-window-median/) — #480 · Hard
   - **Зорилго:** Массив эсвэл тоон дарааллын элементүүдээс нэрэнд заасан үр дүнг олж/өөрчил.
   - **Хэрэглээ:** Жагсаалтын хос, хэсэг, дараалал болон байрлалыг тооцоход.
   - **Бодох чиглэл:** Хэмжээг k-д хязгаарласан heap эсвэл quickselect ашиглахыг харьцуул.
3. [Magical String](https://leetcode.com/problems/magical-string/) — #481 · Medium
   - **Зорилго:** Текстийн тэмдэгт, хэсэг эсвэл дүрмийг шалгаж нэрэнд заасан үр дүнг гарга.
   - **Хэрэглээ:** Текст хайлт, өгөгдөл цэвэрлэх, формат шалгах болон хэлний боловсруулалтад.
   - **Бодох чиглэл:** Тэмдэг бүрийг нэг удаа боловсруулах боломжийг хайж, давтамж эсвэл индекс хадгал.
4. [License Key Formatting](https://leetcode.com/problems/license-key-formatting/) — #482 · Easy
   - **Зорилго:** Текстийн тэмдэгт, хэсэг эсвэл дүрмийг шалгаж нэрэнд заасан үр дүнг гарга.
   - **Хэрэглээ:** Текст хайлт, өгөгдөл цэвэрлэх, формат шалгах болон хэлний боловсруулалтад.

5. [Smallest Good Base](https://leetcode.com/problems/smallest-good-base/) — #483 · Hard
   - **Зорилго:** Эрэмбэлэгдсэн өгөгдөл эсвэл боломжит хариунаас зорилтот утга, байрлал, хязгаарыг хай.
   - **Хэрэглээ:** Том хайлтын муж, босго утга, эрэмбэлэгдсэн өгөгдөлд хурдан хайлт хийхэд.
   - **Бодох чиглэл:** Хариуны боломжит мужид monotonic нөхцөл байгаа эсэхийг шалгаад binary search хэрэглэ.
