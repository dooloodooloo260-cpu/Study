# Day 10: LeetCode бодлого

Энд бодлого бүрийн зорилго, ямар төрлийн асуудалд хэрэглэх, бодож эхлэх чиглэлийг Монгол хэлээр товчлов. Оролтын нарийн формат, жишээ, хязгаарлалтыг LeetCode холбоосоос шалгаарай.

Өнөөдрийн 5 бодлого. Бусад өдрийн бодлоготой давхцахгүй.

1. [N-Queens](https://leetcode.com/problems/n-queens/) — #51 · Hard
   - **Зорилго:** Сонголтуудыг туршиж, нөхцөл зөрчсөн салааг буцааж тайрч хүчинтэй шийдлүүдийг ол.
   - **Хэрэглээ:** Таавар, хослол үүсгэх, хязгаарлалттай байрлуулах асуудалд.
   - **Бодох чиглэл:** Backtracking хийж сонголт бүрийн дараа төлөвөө сэргээ; давхардал болон боломжгүй салааг эрт тайр.
2. [N-Queens II](https://leetcode.com/problems/n-queens-ii/) — #52 · Hard
   - **Зорилго:** Сонголтуудыг туршиж, нөхцөл зөрчсөн салааг буцааж тайрч хүчинтэй шийдлүүдийг ол.
   - **Хэрэглээ:** Таавар, хослол үүсгэх, хязгаарлалттай байрлуулах асуудалд.
   - **Бодох чиглэл:** Backtracking хийж сонголт бүрийн дараа төлөвөө сэргээ; давхардал болон боломжгүй салааг эрт тайр.
3. [Maximum Subarray](https://leetcode.com/problems/maximum-subarray/) — #53 · Medium
   - **Зорилго:** Боломжит сонголтуудаас нэрэнд заасан хамгийн их утга эсвэл хэмжээг тооц.
   - **Хэрэглээ:** Олон сонголтоос ашиг/зардал, алхам, замын хамгийн сайн үр дүнг тооцоход.
   - **Бодох чиглэл:** Kadane-ийн санаагаар одоогийн төгсгөлтэй хамгийн сайн нийлбэрийг шинэчил.
4. [Spiral Matrix](https://leetcode.com/problems/spiral-matrix/) — #54 · Medium
   - **Зорилго:** Торон хүснэгтийн нүд, хөршийн холбоонд хайлт, тоолол эсвэл замын үр дүнг ол.
   - **Хэрэглээ:** Газрын зураг, зураг-пикселийн бүс, торон тоглоомын байрлал тооцоход.
   - **Бодох чиглэл:** Дээд/доод мөр, зүүн/баруун баганын хилүүдийг үе шаттай нарийсга.
5. [Jump Game](https://leetcode.com/problems/jump-game/) — #55 · Medium
   - **Зорилго:** Эхний индексээс үсрэлтээр сүүлийн индексэд хүрэх боломжтой эсэхийг шалга.
   - **Хэрэглээ:** Хуваарь, нөөц хуваарилах, зардал багасгах зэрэг сонголтын асуудалд.
   - **Бодох чиглэл:** Одоогоор хүрч болох хамгийн баруун индексийг greedily шинэчил; II хувилбарт хүрэх хүрээг түвшнээр тооц.
