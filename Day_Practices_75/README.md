# Day 75: LeetCode бодлого

Энд бодлого бүрийн зорилго, ямар төрлийн асуудалд хэрэглэх, бодож эхлэх чиглэлийг Монгол хэлээр товчлов. Оролтын нарийн формат, жишээ, хязгаарлалтыг LeetCode холбоосоос шалгаарай.

Өнөөдрийн 5 бодлого. Бусад өдрийн бодлоготой давхцахгүй.

1. [Sort Characters By Frequency](https://leetcode.com/problems/sort-characters-by-frequency/) — #451 · Medium
   - **Зорилго:** Өгөгдлийг эрэмбэлэх эсвэл эрэмбийн шинжийг ашиглан шаардагдах үр дүнг ол.
   - **Хэрэглээ:** Тайлангийн дараалал, эрэмбэлсэн хайлт, давхцал болон top-K олоход.
   - **Бодох чиглэл:** Эрэмбэлсний дараа нэг нэвтрэлт, хоёр заагч эсвэл greedy сонголт хийж болохыг шалга.
2. [Minimum Number of Arrows to Burst Balloons](https://leetcode.com/problems/minimum-number-of-arrows-to-burst-balloons/) — #452 · Medium
   - **Зорилго:** Боломжит сонголтуудаас нэрэнд заасан хамгийн бага утга, зардал эсвэл алхмыг ол.
   - **Хэрэглээ:** Олон сонголтоос ашиг/зардал, алхам, замын хамгийн сайн үр дүнг тооцоход.
   - **Бодох чиглэл:** Төлөв, шилжилт, base case-аа бичээд давтагдсан дэд асуудлын хариуг хадгал.
3. [Minimum Moves to Equal Array Elements](https://leetcode.com/problems/minimum-moves-to-equal-array-elements/) — #453 · Medium
   - **Зорилго:** Боломжит сонголтуудаас нэрэнд заасан хамгийн бага утга, зардал эсвэл алхмыг ол.
   - **Хэрэглээ:** Хуваарь, нөөц хуваарилах, зардал багасгах зэрэг сонголтын асуудалд.
   - **Бодох чиглэл:** Одоогийн хамгийн ашигтай сонголт эцсийн зөв шийдэлд хүргэх нөхцөлийг шалга.
4. [4Sum II](https://leetcode.com/problems/4sum-ii/) — #454 · Medium
   - **Зорилго:** Нэрэнд заасан элементүүдийн нийлбэрийг зорилтот нөхцөлтэй уялдуулан ол.
   - **Хэрэглээ:** Жагсаалтын хос, хэсэг, дараалал болон байрлалыг тооцоход.
   - **Бодох чиглэл:** Оролтын хэмжээ, эрэмбэ, давхардалд тулгуурлан HashMap, хоёр заагч, prefix sum эсвэл sliding window-ийг сонго.
5. [Assign Cookies](https://leetcode.com/problems/assign-cookies/) — #455 · Easy
   - **Зорилго:** Одоогийн алхам бүрт зөв сонголт хийж эцсийн боломжит/хамгийн сайн үр дүнд хүр.
   - **Хэрэглээ:** Хуваарь, нөөц хуваарилах, зардал багасгах зэрэг сонголтын асуудалд.
   - **Бодох чиглэл:** Одоогийн хамгийн ашигтай сонголт эцсийн зөв шийдэлд хүргэх нөхцөлийг шалга.
