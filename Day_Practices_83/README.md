# Day 83: LeetCode бодлого

Энд бодлого бүрийн зорилго, ямар төрлийн асуудалд хэрэглэх, бодож эхлэх чиглэлийг Монгол хэлээр товчлов. Оролтын нарийн формат, жишээ, хязгаарлалтыг LeetCode холбоосоос шалгаарай.

Өнөөдрийн 5 бодлого. Бусад өдрийн бодлоготой давхцахгүй.

1. [Diagonal Traverse](https://leetcode.com/problems/diagonal-traverse/) — #498 · Medium
   - **Зорилго:** Торон хүснэгтийн нүд, хөршийн холбоонд хайлт, тоолол эсвэл замын үр дүнг ол.
   - **Хэрэглээ:** Газрын зураг, зураг-пикселийн бүс, торон тоглоомын байрлал тооцоход.
   - **Бодох чиглэл:** Диагональ бүрийн эхлэл, чиглэлийг ээлжлүүлж матрицын хил дотор алх.
2. [Keyboard Row](https://leetcode.com/problems/keyboard-row/) — #500 · Easy
   - **Зорилго:** Текстийн тэмдэгт, хэсэг эсвэл дүрмийг шалгаж нэрэнд заасан үр дүнг гарга.
   - **Хэрэглээ:** Текст хайлт, өгөгдөл цэвэрлэх, формат шалгах болон хэлний боловсруулалтад.
   - **Бодох чиглэл:** Тэмдэг бүрийг нэг удаа боловсруулах боломжийг хайж, давтамж эсвэл индекс хадгал.
3. [Find Mode in Binary Search Tree](https://leetcode.com/problems/find-mode-in-binary-search-tree/) — #501 · Easy
   - **Зорилго:** Өгөгдлөөс зорилтот утга, байрлал эсвэл мужийг ол; эхний/сүүлийн тохиолдлыг шаардлагатай бол ялга.
   - **Хэрэглээ:** Файлын хавтас, DOM/JSON зэрэг шаталсан өгөгдөл боловсруулахад.
   - **Бодох чиглэл:** Зүүн/баруун хязгаарын invariant-аа хадгалан binary search хий.
4. [IPO](https://leetcode.com/problems/ipo/) — #502 · Hard
   - **Зорилго:** Олон утгаас хамгийн их/бага эсвэл дараагийн чухал элементийг үр ашигтай сонго.
   - **Хэрэглээ:** Ажлын эрэмбэ, top-K жагсаалт, урсгал өгөгдлийн тэргүүлэх утгад.
   - **Бодох чиглэл:** Хамгийн чухал одоогийн сонголтыг heap-аар сонгож, шинэ боломжуудыг дараалалд нэм.
5. [Next Greater Element II](https://leetcode.com/problems/next-greater-element-ii/) — #503 · Medium
   - **Зорилго:** Stack ашиглан өмнөх төлөв, хаалт эсвэл дараагийн их/бага элементийн хамаарлыг боловсруул.
   - **Хэрэглээ:** Хаалт шалгах, undo, илэрхийлэл задлах болон дараагийн их/бага элементийг олоход.
   - **Бодох чиглэл:** Monotonic stack ашиглан өмнөх боломжгүй сонголтыг pop хийж, дараагийн илүү тохирох утгыг хадгал.
