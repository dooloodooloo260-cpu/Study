# Day 55: LeetCode бодлого

Энд бодлого бүрийн зорилго, ямар төрлийн асуудалд хэрэглэх, бодож эхлэх чиглэлийг Монгол хэлээр товчлов. Оролтын нарийн формат, жишээ, хязгаарлалтыг LeetCode холбоосоос шалгаарай.

Өнөөдрийн 5 бодлого. Бусад өдрийн бодлоготой давхцахгүй.

1. [Create Maximum Number](https://leetcode.com/problems/create-maximum-number/) — #321 · Hard
   - **Зорилго:** Одоогийн алхам бүрт зөв сонголт хийж эцсийн боломжит/хамгийн сайн үр дүнд хүр.
   - **Хэрэглээ:** Хуваарь, нөөц хуваарилах, зардал багасгах зэрэг сонголтын асуудалд.
   - **Бодох чиглэл:** Одоогийн хамгийн ашигтай сонголт эцсийн зөв шийдэлд хүргэх нөхцөлийг шалга.
2. [Coin Change](https://leetcode.com/problems/coin-change/) — #322 · Medium
   - **Зорилго:** Асуудлыг давтагддаг жижиг төлөвүүдэд хувааж боломжийн тоо эсвэл хамгийн сайн үр дүнг ол.
   - **Хэрэглээ:** Олон сонголтоос ашиг/зардал, алхам, замын хамгийн сайн үр дүнг тооцоход.
   - **Бодох чиглэл:** Төлөв, суурь нөхцөл, шилжилтийг бичээд давтагдсан дэд асуудлын хариуг хадгал.
3. [Wiggle Sort II](https://leetcode.com/problems/wiggle-sort-ii/) — #324 · Medium
   - **Зорилго:** Одоогийн алхам бүрт зөв сонголт хийж эцсийн боломжит/хамгийн сайн үр дүнд хүр.
   - **Хэрэглээ:** Хуваарь, нөөц хуваарилах, зардал багасгах зэрэг сонголтын асуудалд.
   - **Бодох чиглэл:** Одоогийн хамгийн ашигтай сонголт эцсийн зөв шийдэлд хүргэх нөхцөлийг шалга.
4. [Power of Three](https://leetcode.com/problems/power-of-three/) — #326 · Easy
   - **Зорилго:** Томьёо, тоон шинж эсвэл хязгаарыг ашиглан математикийн үр дүнг тооц.
   - **Хэрэглээ:** Тоон хөрвүүлэлт, тоолол, геометр, үр ашигтай арифметикт.
   - **Бодох чиглэл:** Хязгаар, parity, модуль эсвэл томьёог ашиглаж бүх хувилбарыг шалгах шаардлагыг багасга.
5. [Count of Range Sum](https://leetcode.com/problems/count-of-range-sum/) — #327 · Hard
   - **Зорилго:** Өгөгдсөн оролтоос нэрэнд заасан объект эсвэл тохиолдлын тоог тооц.
   - **Хэрэглээ:** Жагсаалтын хос, хэсэг, дараалал болон байрлалыг тооцоход.
   - **Бодох чиглэл:** Оролтын хэмжээ, эрэмбэ, давхардалд тулгуурлан HashMap, хоёр заагч, prefix sum эсвэл sliding window-ийг сонго.
