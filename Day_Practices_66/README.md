# Day 66: LeetCode бодлого

Энд бодлого бүрийн зорилго, ямар төрлийн асуудалд хэрэглэх, бодож эхлэх чиглэлийг Монгол хэлээр товчлов. Оролтын нарийн формат, жишээ, хязгаарлалтыг LeetCode холбоосоос шалгаарай.

Өнөөдрийн 5 бодлого. Бусад өдрийн бодлоготой давхцахгүй.

1. [Rotate Function](https://leetcode.com/problems/rotate-function/) — #396 · Medium
   - **Зорилго:** Асуудлыг давтагддаг жижиг төлөвүүдэд хувааж боломжийн тоо эсвэл хамгийн сайн үр дүнг ол.
   - **Хэрэглээ:** Олон сонголтоос ашиг/зардал, алхам, замын хамгийн сайн үр дүнг тооцоход.
   - **Бодох чиглэл:** Эхний жингийн нийлбэрийг олж, эргэлт бүрийн үр дүнг өмнөхөөс O(1)-д шинэчил.
2. [Integer Replacement](https://leetcode.com/problems/integer-replacement/) — #397 · Medium
   - **Зорилго:** Томьёо, тоон шинж эсвэл хязгаарыг ашиглан математикийн үр дүнг тооц.
   - **Хэрэглээ:** Тоон хөрвүүлэлт, тоолол, геометр, үр ашигтай арифметикт.
   - **Бодох чиглэл:** Хязгаар, parity, модуль эсвэл томьёог ашиглаж бүх хувилбарыг шалгах шаардлагыг багасга.
3. [Random Pick Index](https://leetcode.com/problems/random-pick-index/) — #398 · Medium
   - **Зорилго:** Нэрэнд заасан үйлдлүүдийг шаардлагатай хурдтай дэмжих өгөгдлийн бүтцийг загварчил.
   - **Хэрэглээ:** Кэш, индекс, санамсаргүй сонголт, API-ийн төлөв хадгалалтад.
   - **Бодох чиглэл:** Үйлдэл бүрийн хурдны шаардлагад нийцүүлэн бүтцүүдийг хослуулж, шинэчлэлтийн invariants-ийг хадгал.
4. [Evaluate Division](https://leetcode.com/problems/evaluate-division/) — #399 · Medium
   - **Зорилго:** Орой ба холбоосоос хүрэх боломж, бүлэг, зам эсвэл зөв дарааллыг тогтоо.
   - **Хэрэглээ:** Замын сүлжээ, хэрэглэгчдийн холбоо, ажлын хамаарал болон чиглүүлэлтэд.
   - **Бодох чиглэл:** BFS/DFS болон visited ашигла; хамгийн богино алхам шаардвал BFS сонго.
5. [Nth Digit](https://leetcode.com/problems/nth-digit/) — #400 · Medium
   - **Зорилго:** Томьёо, тоон шинж эсвэл хязгаарыг ашиглан математикийн үр дүнг тооц.
   - **Хэрэглээ:** Тоон хөрвүүлэлт, тоолол, геометр, үр ашигтай арифметикт.
   - **Бодох чиглэл:** Хязгаар, parity, модуль эсвэл томьёог ашиглаж бүх хувилбарыг шалгах шаардлагыг багасга.
