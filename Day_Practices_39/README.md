# Day 39: LeetCode бодлого

Энд бодлого бүрийн зорилго, ямар төрлийн асуудалд хэрэглэх, бодож эхлэх чиглэлийг Монгол хэлээр товчлов. Оролтын нарийн формат, жишээ, хязгаарлалтыг LeetCode холбоосоос шалгаарай.

Өнөөдрийн 5 бодлого. Бусад өдрийн бодлоготой давхцахгүй.

1. [Binary Tree Right Side View](https://leetcode.com/problems/binary-tree-right-side-view/) — #199 · Medium
   - **Зорилго:** Модон бүтэц дээр нэрэнд заасан утга, зам, дараалал эсвэл шинжийг ол.
   - **Хэрэглээ:** Файлын хавтас, DOM/JSON зэрэг шаталсан өгөгдөл боловсруулахад.
   - **Бодох чиглэл:** DFS-ийн буцаах утга юу болохыг тодорхойл; хоосон мод, навчийг шалга.
2. [Number of Islands](https://leetcode.com/problems/number-of-islands/) — #200 · Medium
   - **Зорилго:** Торон газрын зураг дахь хоорондоо хөрш хуурай нүднүүдээс бүрдэх арлуудын тоог ол.
   - **Хэрэглээ:** Газрын зураг, зураг-пикселийн бүс, торон тоглоомын байрлал тооцоход.
   - **Бодох чиглэл:** Газрын нүд олдох бүрт BFS/DFS хийж бүх хөршийг тэмдэглээд нэг аралд тоол.
3. [Bitwise AND of Numbers Range](https://leetcode.com/problems/bitwise-and-of-numbers-range/) — #201 · Medium
   - **Зорилго:** Тоог хоёртын дүрслэлд хувирган битийн түвшинд нэрэнд заасан тооцоог хий.
   - **Хэрэглээ:** Flag/permission багцлах, битэн төлөв хадгалах, хурдан XOR тооцоонд.
   - **Бодох чиглэл:** XOR, AND, OR, shift оператор ашиглан бит тус бүрийн төлөвийг тооц.
4. [Happy Number](https://leetcode.com/problems/happy-number/) — #202 · Easy
   - **Зорилго:** Томьёо, тоон шинж эсвэл хязгаарыг ашиглан математикийн үр дүнг тооц.
   - **Хэрэглээ:** Тоон хөрвүүлэлт, тоолол, геометр, үр ашигтай арифметикт.
   - **Бодох чиглэл:** Хязгаар, parity, модуль эсвэл томьёог ашиглаж бүх хувилбарыг шалгах шаардлагыг багасга.
5. [Remove Linked List Elements](https://leetcode.com/problems/remove-linked-list-elements/) — #203 · Easy
   - **Зорилго:** Нэрэнд заасан элемент эсвэл зангилааг устгаж үлдсэн өгөгдлийг зөв хадгал.
   - **Хэрэглээ:** Дараалсан өгөгдөлд оруулах/устгах, холбоос урвуулах болон жагсаалтыг алхахад.
   - **Бодох чиглэл:** Заагчийн өмнөх/дараах холбоог тэмдэглэж, өөрчлөхөөс өмнө дараагийн зангилааг хадгал.
