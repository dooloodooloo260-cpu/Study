# 01-р өдөр: Өгөгдлийн бүтэц ба алгоритмтай танилцах

## Тавтай морил

Энэ хөтөлбөрөөр бодит асуудлыг шийдэх үр ашигтай код бичиж сурна. Компьютер
өгөгдлийг хэрхэн зохион байгуулдгийг, түүнийг шалгарсан аргуудаар хэрхэн
боловсруулдгийг үзнэ.

Өгөгдлийн бүтэц ба алгоритм нь компьютерын шинжлэх ухааны үндэс юм. Бидний
бичсэн программ бүр өгөгдөл хадгалах, хайх, өөрчлөх эсвэл ямар нэг үр дүн
гаргахдаа эдгээрийг ашигладаг.

## Энэ хичээлээр юу сурах вэ?

Эхлээд код хэр хурдан ажилладаг, хэр хэмжээний санах ой хэрэглэдгийг хэмжиж,
яагаад чухал болохыг ойлгоно. Дараа нь массив, жагсаалт, стек, дараалал зэрэг
суурь өгөгдлийн бүтэцтэй танилцана. Бүтэц бүр өөрийн давуу болон сул талтай
учраас асуудалдаа тохирохыг нь сонгож сурах нь сайн программ зохиох нэг чухал
чадвар юм.

Суурь ойлголтоо бататгасны дараа tree, graph, hash table зэрэг өгөгдлийн
бүтцийг судална. Эдгээр нь өгөгдлийн сан, нийгмийн сүлжээ зэрэг олон системийн
ажиллагаанд ашиглагддаг.

## Яагаад энэ сэдвээс эхлэх вэ?

Программчлал гэдэг нь зөвхөн ажилладаг код бичих биш. Сайн код:

- хурдан ажилладаг;
- санах ойг зохистой ашигладаг;
- оролтын хязгаар болон захын тохиолдлуудыг зөв боловсруулдаг.

Өгөгдлийн бүтцийг ойлгохгүй бол жижиг оролт дээр ажилладаг ч бодит хэмжээний
өгөгдөл дээр удаашрах эсвэл алдаа гаргах аргыг сонгож болзошгүй. Тохиромжгүй
шийдэл хэдхэн миллисекунд ажиллахын оронд секунд зарцуулж, эсвэл өгөгдөл
томроход программын ажиллагааг доголдуулж болно. Энэ хичээлүүд асуудлын
хэв маягийг таньж, шийдлээ үндэслэлтэй сонгох суурь өгнө.

## Хичээлүүд хэрхэн явагдах вэ?

Бүлэг бүр нэг ойлголтыг тайлбарлаж, ажиллах кодын жишээ үзүүлнэ. Аргыг хэрхэн
хэрэгжүүлэхээс өмнө яагаад хэрэгтэй, ямар үед тохирохыг авч үзнэ. Жишээнүүдэд
Java ашиглана. Java нь мэргэжлийн хөгжүүлэлт, сургалт, техникийн ярилцлагад
өргөн хэрэглэгддэг бөгөөд уншихад ойлгомжтой бичиглэлтэй. Мөн санах ойн
удирдлагын олон ажлыг Java өөрөө хариуцдаг тул анхаарлаа алгоритмдаа
төвлөрүүлэх боломжтой.

Хөтөлбөр нь суурь ойлголтоос эхэлж, бодит программд хэрэглэдэг ахисан аргууд
руу шатлан ахина. Зарим сэдэв эхэндээ хэцүү санагдаж болно. Энэ бол хэвийн:
алгоритмыг сууриас нь ойлгоход хугацаа, давтлага шаардлагатай. Жишээг
ажиллуулж, өөрөө өөрчилж, тайлбарлан дадлага хийгээрэй.

## Алгоритм гэж юу вэ?

Алгоритм гэдэг нь асуудлыг шийдэх алхамчилсан заавар юм. Үүнийг зорьсон үр
дүнд хүрэхийн тулд тодорхой дарааллаар дагадаг жортой зүйрлэж болно.
Программчлалд алгоритм нь компьютерт яг юу хийхийг заана: утга шалгах, тоог
харьцуулах, эсвэл нөхцөл биелтэл үйлдлийг давтах гэх мэт.

### Алгоритм өдөр тутамд

- Утасныхаа харилцагчаас нэр хайхад хайлтын алгоритм тохирох мэдээллийг олно.
- Газрын зураг чиглэл гаргахад боломжит замуудыг тооцно.
- Имэйлийг огноогоор эрэмбэлэхэд эрэмбэлэх алгоритм мессежүүдийн дарааллыг
  өөрчилнө.

Энгийн алгоритм нь жагсаалтаас хамгийн их тоог олох байж болно. Харин видео
шахах эсвэл хэрэглэгчид сонирхох бүтээгдэхүүн санал болгох алгоритм илүү
төвөгтэй. Аль аль нь тодорхой зорилгод хүргэх алхмуудаас бүрдэнэ.

## Жишээ: жагсаалтаас хамгийн их тоог олох

Массивын эхний тоог одоогоор хамгийн их гэж үзье. Дараа нь үлдсэн тоонуудыг
нэг нэгээр шалгана. Илүү их тоо таарвал хамгийн их утгыг шинэчилнэ.

```java
public class FindMax {
    static int findMax(int[] numbers) {
        if (numbers == null || numbers.length == 0) {
            throw new IllegalArgumentException(
                    "Массив null эсвэл хоосон байж болохгүй.");
        }

        int maxNumber = numbers[0];

        for (int i = 1; i < numbers.length; i++) {
            if (numbers[i] > maxNumber) {
                maxNumber = numbers[i];
            }
        }

        return maxNumber;
    }

    public static void main(String[] args) {
        int[] numbers = {4, 9, 2, 15, 7};
        System.out.println(findMax(numbers)); // 15
    }
}
```

Энд `maxNumber` хувьсагч нь одоогоор олдсон хамгийн их утгыг хадгална. `for`
давталт үлдсэн элемент бүрийг шалгаж, хэрэгтэй үед утгыг шинэчилнэ. Ингэснээр
шалгах, харьцуулах, шинэчлэх гэсэн алхмууд нийлж алгоритм болно.

**Оролтын нөхцөл:** хамгийн их утга олохын тулд дор хаяж нэг элементтэй массив
шаардлагатай. Иймээс жишээ нь `null` эсвэл хоосон массив ирвэл тодорхой алдаа
мэдэгдэнэ.

**Хугацааны төвөгшил:** `n` элементтэй массивын элемент бүрийг хамгийн ихдээ
нэг удаа шалгана. Тиймээс хугацааны төвөгшил нь `O(n)`.

**Нэмэлт санах ойн төвөгшил:** массивын хэмжээнээс үл хамааран `maxNumber`
болон `i` гэсэн цөөн хувьсагч ашиглана. Тиймээс нэмэлт санах ойн төвөгшил нь
`O(1)`.

## Дадлага

1. Кодыг ажиллуулж, `15` хэвлэгдэж байгааг шалга.
2. Массивыг сөрөг тоонууд болон давхардсан хамгийн их утгатайгаар сольж
   турш.
3. Нэг элементтэй массивын үр дүнг шалга.
4. Хоосон массив болон `null` өгвөл ямар алдаа гарч байгааг ажигла.
5. Алгоритмыг өөрийн үгээр алхам бүрээр тайлбарла.

## Өөрийгөө шалгах асуулт

1. Алгоритм гэж юу вэ?
2. `maxNumber`-т яагаад массивын эхний утгыг эхлээд хадгалж байна вэ?
3. `for` давталт хэдэн удаа ажиллах вэ?
4. `O(n)` ба `O(1)` энэ жишээнд юуг илэрхийлж байна вэ?
5. Оролт хоосон байж болохгүй гэдгийг код яаж ил тод болгож байна вэ?

## Дууссан гэж үзэх шалгуур

- Хамгийн их утгыг олох кодыг ажиллуулж, өөр оролтоор шалгасан.
- Алгоритмын алхмуудыг тайлбарлаж чадна.
- Хугацааны `O(n)` болон нэмэлт санах ойн `O(1)` төвөгшлийг тайлбарлаж
  чадна.
