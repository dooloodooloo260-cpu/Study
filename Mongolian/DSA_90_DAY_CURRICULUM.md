# Өгөгдлийн бүтэц ба алгоритм: 90 өдрийн хөтөлбөр

Энэ нь repository-ийн одоогийн Java хөтөлбөрөөс тусдаа, таны жагсаасан
өгөгдлийн бүтэц ба алгоритмын сэдвүүдийг Монгол хэлээр 90 өдөрт хуваасан
хөтөлбөр юм. Өдөр бүр нэг сэдвийг судалж, Java дээр жижиг хэрэгжүүлэлт эсвэл
бодлогоор бататгана. Хуваарилалт нь эхлээд суурийг тавьж, дараа нь сэдвүүдийг
ахиулан холбохоор зохиогдсон.

5. Өмнөх өдрийн кодыг дахин уншиж, нэг сайжруулалт хий.
