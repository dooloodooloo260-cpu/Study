# Day 65: LeetCode бодлого

Энд бодлого бүрийн зорилго, ямар төрлийн асуудалд хэрэглэх, бодож эхлэх чиглэлийг Монгол хэлээр товчлов. Оролтын нарийн формат, жишээ, хязгаарлалтыг LeetCode холбоосоос шалгаарай.

Өнөөдрийн 5 бодлого. Бусад өдрийн бодлоготой давхцахгүй.

1. [Perfect Rectangle](https://leetcode.com/problems/perfect-rectangle/) — #391 · Hard
   - **Зорилго:** Цэг, шулуун, тэгш өнцөгт зэрэг геометрийн объектын хамаарлыг тооц.
   - **Хэрэглээ:** Координатын зураглал, огтлолцол, чиглэл болон талбай тооцоход.
   - **Бодох чиглэл:** Координатын хүрээ, давхцал болон булангийн parity/талбайн нөхцөлийг тооц.
2. [Is Subsequence](https://leetcode.com/problems/is-subsequence/) — #392 · Easy
   - **Зорилго:** Өгсөн өгөгдөл нэрэнд заасан дүрэм, бүтэц эсвэл нөхцөлийг хангаж байгаа эсэхийг шалга.
   - **Хэрэглээ:** Олон сонголтоос ашиг/зардал, алхам, замын хамгийн сайн үр дүнг тооцоход.
   - **Бодох чиглэл:** Төлөв, шилжилт, base case-аа бичээд давтагдсан дэд асуудлын хариуг хадгал.
3. [UTF-8 Validation](https://leetcode.com/problems/utf-8-validation/) — #393 · Medium
   - **Зорилго:** Текстийн тэмдэгт, хэсэг эсвэл дүрмийг шалгаж нэрэнд заасан үр дүнг гарга.
   - **Хэрэглээ:** Текст хайлт, өгөгдөл цэвэрлэх, формат шалгах болон хэлний боловсруулалтад.
   - **Бодох чиглэл:** Тэмдэг бүрийг нэг удаа боловсруулах боломжийг хайж, давтамж эсвэл индекс хадгал.
4. [Decode String](https://leetcode.com/problems/decode-string/) — #394 · Medium
   - **Зорилго:** Stack ашиглан өмнөх төлөв, хаалт эсвэл дараагийн их/бага элементийн хамаарлыг боловсруул.
   - **Хэрэглээ:** Хаалт шалгах, undo, илэрхийлэл задлах болон дараагийн их/бага элементийг олоход.
   - **Бодох чиглэл:** Стекэд хадгалах төлөв, push/pop хийх мөчийг дүрмээр тодорхойл.
5. [Longest Substring with At Least K Repeating Characters](https://leetcode.com/problems/longest-substring-with-at-least-k-repeating-characters/) — #395 · Medium
   - **Зорилго:** Нэрэнд заасан нөхцөлийг хангах хамгийн урт/богино хэсэг, зам эсвэл дарааллыг ол.
   - **Хэрэглээ:** Текст хайлт, өгөгдөл цэвэрлэх, формат шалгах болон хэлний боловсруулалтад.
   - **Бодох чиглэл:** DFS-ийн буцаах утга юу болохыг тодорхойл; хоосон мод, навчийг шалга.
