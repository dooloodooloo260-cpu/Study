# Day 48: LeetCode бодлого

Энд бодлого бүрийн зорилго, ямар төрлийн асуудалд хэрэглэх, бодож эхлэх чиглэлийг Монгол хэлээр товчлов. Оролтын нарийн формат, жишээ, хязгаарлалтыг LeetCode холбоосоос шалгаарай.

Өнөөдрийн 5 бодлого. Бусад өдрийн бодлоготой давхцахгүй.

1. [Add Digits](https://leetcode.com/problems/add-digits/) — #258 · Easy
   - **Зорилго:** Томьёо, тоон шинж эсвэл хязгаарыг ашиглан математикийн үр дүнг тооц.
   - **Хэрэглээ:** Тоон хөрвүүлэлт, тоолол, геометр, үр ашигтай арифметикт.
   - **Бодох чиглэл:** Сүүлийн цифрээс эхлэн carry-г дамжуулж, бүх цифр 9 байх тохиолдлыг шалга.
2. [Single Number III](https://leetcode.com/problems/single-number-iii/) — #260 · Medium
   - **Зорилго:** Тоог хоёртын дүрслэлд хувирган битийн түвшинд нэрэнд заасан тооцоог хий.
   - **Хэрэглээ:** Flag/permission багцлах, битэн төлөв хадгалах, хурдан XOR тооцоонд.
   - **Бодох чиглэл:** XOR/shift ашиглаж бит тус бүрийн давтамж эсвэл байрлалыг тооц.
3. [Trips and Users](https://leetcode.com/problems/trips-and-users/) — #262 · Hard
   - **Зорилго:** Өгөгдлийн сангийн хүснэгтүүдээс нэрэнд заасан хэрэглэгч, бүлэг, эрэмбэ эсвэл статистикийг гарга.
   - **Хэрэглээ:** Тайлан, хэрэглэгчийн үйлдлийн статистик, олон хүснэгтийн өгөгдөл нэгтгэхэд.
   - **Бодох чиглэл:** Түлхүүр, бүлэглэлт, JOIN/window function хэрэгтэй эсэхийг ялгаж, NULL ба давхардлыг шалга.
4. [Ugly Number](https://leetcode.com/problems/ugly-number/) — #263 · Easy
   - **Зорилго:** Томьёо, тоон шинж эсвэл хязгаарыг ашиглан математикийн үр дүнг тооц.
   - **Хэрэглээ:** Тоон хөрвүүлэлт, тоолол, геометр, үр ашигтай арифметикт.
   - **Бодох чиглэл:** Хязгаар, parity, модуль эсвэл томьёог ашиглаж бүх хувилбарыг шалгах шаардлагыг багасга.
5. [Ugly Number II](https://leetcode.com/problems/ugly-number-ii/) — #264 · Medium
   - **Зорилго:** Томьёо, тоон шинж эсвэл хязгаарыг ашиглан математикийн үр дүнг тооц.
   - **Хэрэглээ:** Тоон хөрвүүлэлт, тоолол, геометр, үр ашигтай арифметикт.
   - **Бодох чиглэл:** Хязгаар, parity, модуль эсвэл томьёог ашиглаж бүх хувилбарыг шалгах шаардлагыг багасга.
