# Day 02: LeetCode бодлого

Энд бодлого бүрийн зорилго, ямар төрлийн асуудалд хэрэглэх, бодож эхлэх чиглэлийг Монгол хэлээр товчлов. Оролтын нарийн формат, жишээ, хязгаарлалтыг LeetCode холбоосоос шалгаарай.

Өнөөдрийн 5 бодлого. Бусад өдрийн бодлоготой давхцахгүй.

1. [Container With Most Water](https://leetcode.com/problems/container-with-most-water/) — #11 · Medium
   - **Зорилго:** Хоёр өндөр баганын хооронд үүсэх савнуудын хамгийн их багтаамжийг ол.
   - **Хэрэглээ:** Жагсаалтын хос, хэсэг, дараалал болон байрлалыг тооцоход.
   - **Бодох чиглэл:** Хоёр заагчаас бага өндөртэй талыг дотогшлуул; талбайн боломжит дээд утгыг хадгал.
2. [Integer to Roman](https://leetcode.com/problems/integer-to-roman/) — #12 · Medium
   - **Зорилго:** Өгсөн бүхэл тоог хүчинтэй Ром тооны тэмдэглэгээ болгон хөрвүүл.
   - **Хэрэглээ:** Тоон хөрвүүлэлт, тоолол, геометр, үр ашигтай арифметикт.
   - **Бодох чиглэл:** Хязгаар, parity, модуль эсвэл томьёог ашиглаж бүх хувилбарыг шалгах шаардлагыг багасга.
3. [Roman to Integer](https://leetcode.com/problems/roman-to-integer/) — #13 · Easy
   - **Зорилго:** Ром тооны тэмдэглэгээг бүхэл тоо болгон хөрвүүл.
   - **Хэрэглээ:** Тоон хөрвүүлэлт, тоолол, геометр, үр ашигтай арифметикт.
   - **Бодох чиглэл:** Хязгаар, parity, модуль эсвэл томьёог ашиглаж бүх хувилбарыг шалгах шаардлагыг багасга.
4. [Longest Common Prefix](https://leetcode.com/problems/longest-common-prefix/) — #14 · Easy
   - **Зорилго:** Өгсөн бүх мөрийн хамгийн урт нийтлэг эхлэлийг ол.
   - **Хэрэглээ:** Текст хайлт, өгөгдөл цэвэрлэх, формат шалгах болон хэлний боловсруулалтад.
   - **Бодох чиглэл:** Хамгийн богино мөрийг суурь болгон бусад мөртэй индекс бүрээр харьцуулж зөрсөн хэсэгт зогс.
5. [3Sum](https://leetcode.com/problems/3sum/) — #15 · Medium
   - **Зорилго:** Нийлбэр нь тэг болох давхардалгүй гурван элементийн хослолуудыг ол.
   - **Хэрэглээ:** Жагсаалтын хос, хэсэг, дараалал болон байрлалыг тооцоход.
   - **Бодох чиглэл:** Массивыг эрэмбэлээд нэг утгыг тогтоон үлдсэн хоёрт хоёр заагч ашигла; ижил утгын давхардлыг алгас.
