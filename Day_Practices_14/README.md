# Day 14: LeetCode бодлого

Энд бодлого бүрийн зорилго, ямар төрлийн асуудалд хэрэглэх, бодож эхлэх чиглэлийг Монгол хэлээр товчлов. Оролтын нарийн формат, жишээ, хязгаарлалтыг LeetCode холбоосоос шалгаарай.

Өнөөдрийн 5 бодлого. Бусад өдрийн бодлоготой давхцахгүй.

1. [Simplify Path](https://leetcode.com/problems/simplify-path/) — #71 · Medium
   - **Зорилго:** Unix замын `.` болон `..` хэсгийг боловсруулж canonical замыг гарга.
   - **Хэрэглээ:** Хаалт шалгах, undo, илэрхийлэл задлах болон дараагийн их/бага элементийг олоход.
   - **Бодох чиглэл:** Замын хэсгүүдийг `/`-ээр салгаж stack-д нэм; `..` таарахад хамгийн сүүлийн хэсгийг ав.
2. [Edit Distance](https://leetcode.com/problems/edit-distance/) — #72 · Medium
   - **Зорилго:** Массив эсвэл тоон дарааллын элементүүдээс нэрэнд заасан үр дүнг олж/өөрчил.
   - **Хэрэглээ:** Жагсаалтын хос, хэсэг, дараалал болон байрлалыг тооцоход.
   - **Бодох чиглэл:** Тэмдэгтийн индексүүдээр DP төлөв байгуулж, одоогийн тэмдэгтийн боломжит шилжилтийг тооц.
3. [Set Matrix Zeroes](https://leetcode.com/problems/set-matrix-zeroes/) — #73 · Medium
   - **Зорилго:** Торон хүснэгтийн нүд, хөршийн холбоонд хайлт, тоолол эсвэл замын үр дүнг ол.
   - **Хэрэглээ:** Газрын зураг, зураг-пикселийн бүс, торон тоглоомын байрлал тооцоход.
   - **Бодох чиглэл:** Хөрш нүднүүдийг BFS/DFS-ээр шалгаж visited тэмдэглэ; хил ба диагоналийн дүрмийг нягтал.
4. [Search a 2D Matrix](https://leetcode.com/problems/search-a-2d-matrix/) — #74 · Medium
   - **Зорилго:** Торон хүснэгтийн нүд, хөршийн холбоонд хайлт, тоолол эсвэл замын үр дүнг ол.
   - **Хэрэглээ:** Газрын зураг, зураг-пикселийн бүс, торон тоглоомын байрлал тооцоход.
   - **Бодох чиглэл:** Хөрш нүднүүдийг BFS/DFS-ээр шалгаж visited тэмдэглэ; хил ба диагоналийн дүрмийг нягтал.
5. [Sort Colors](https://leetcode.com/problems/sort-colors/) — #75 · Medium
   - **Зорилго:** Өгөгдлийг эрэмбэлэх эсвэл эрэмбийн шинжийг ашиглан шаардагдах үр дүнг ол.
   - **Хэрэглээ:** Тайлангийн дараалал, эрэмбэлсэн хайлт, давхцал болон top-K олоход.
   - **Бодох чиглэл:** Эрэмбэлсний дараа нэг нэвтрэлт, хоёр заагч эсвэл greedy сонголт хийж болохыг шалга.
