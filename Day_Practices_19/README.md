# Day 19: LeetCode бодлого

Энд бодлого бүрийн зорилго, ямар төрлийн асуудалд хэрэглэх, бодож эхлэх чиглэлийг Монгол хэлээр товчлов. Оролтын нарийн формат, жишээ, хязгаарлалтыг LeetCode холбоосоос шалгаарай.

Өнөөдрийн 5 бодлого. Бусад өдрийн бодлоготой давхцахгүй.

1. [Unique Binary Search Trees](https://leetcode.com/problems/unique-binary-search-trees/) — #96 · Medium
   - **Зорилго:** Эрэмбэлэгдсэн өгөгдөл эсвэл боломжит хариунаас зорилтот утга, байрлал, хязгаарыг хай.
   - **Хэрэглээ:** Том хайлтын муж, босго утга, эрэмбэлэгдсэн өгөгдөлд хурдан хайлт хийхэд.
   - **Бодох чиглэл:** Зүүн/баруун хязгаарын invariant-аа хадгалан binary search хий.
2. [Interleaving String](https://leetcode.com/problems/interleaving-string/) — #97 · Medium
   - **Зорилго:** Текстийн тэмдэгт, хэсэг эсвэл дүрмийг шалгаж нэрэнд заасан үр дүнг гарга.
   - **Хэрэглээ:** Текст хайлт, өгөгдөл цэвэрлэх, формат шалгах болон хэлний боловсруулалтад.
   - **Бодох чиглэл:** Тэмдэгтийн индексүүдээр DP төлөв байгуулж, одоогийн тэмдэгтийн боломжит шилжилтийг тооц.
3. [Validate Binary Search Tree](https://leetcode.com/problems/validate-binary-search-tree/) — #98 · Medium
   - **Зорилго:** Өгсөн өгөгдөл нэрэнд заасан дүрэм, бүтэц эсвэл нөхцөлийг хангаж байгаа эсэхийг шалга.
   - **Хэрэглээ:** Файлын хавтас, DOM/JSON зэрэг шаталсан өгөгдөл боловсруулахад.
   - **Бодох чиглэл:** Зүүн/баруун хязгаарын invariant-аа хадгалан binary search хий.
4. [Recover Binary Search Tree](https://leetcode.com/problems/recover-binary-search-tree/) — #99 · Medium
   - **Зорилго:** Модон бүтэц дээр нэрэнд заасан утга, зам, дараалал эсвэл шинжийг ол.
   - **Хэрэглээ:** Файлын хавтас, DOM/JSON зэрэг шаталсан өгөгдөл боловсруулахад.
   - **Бодох чиглэл:** Зүүн/баруун хязгаарын invariant-аа хадгалан binary search хий.
5. [Same Tree](https://leetcode.com/problems/same-tree/) — #100 · Easy
   - **Зорилго:** Модон бүтэц дээр нэрэнд заасан утга, зам, дараалал эсвэл шинжийг ол.
   - **Хэрэглээ:** Файлын хавтас, DOM/JSON зэрэг шаталсан өгөгдөл боловсруулахад.
   - **Бодох чиглэл:** DFS-ийн буцаах утга юу болохыг тодорхойл; хоосон мод, навчийг шалга.
