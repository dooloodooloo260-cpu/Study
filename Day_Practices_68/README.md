# Day 68: LeetCode бодлого

Энд бодлого бүрийн зорилго, ямар төрлийн асуудалд хэрэглэх, бодож эхлэх чиглэлийг Монгол хэлээр товчлов. Оролтын нарийн формат, жишээ, хязгаарлалтыг LeetCode холбоосоос шалгаарай.

Өнөөдрийн 5 бодлого. Бусад өдрийн бодлоготой давхцахгүй.

1. [Queue Reconstruction by Height](https://leetcode.com/problems/queue-reconstruction-by-height/) — #406 · Medium
   - **Зорилго:** FIFO дарааллаар элемент эсвэл төлөвийг боловсруул.
   - **Хэрэглээ:** Үйлчилгээний дараалал, түвшин түвшний хайлт, ажил түгээхэд.
   - **Бодох чиглэл:** FIFO дарааллаар төлөвүүдийг боловсруулж, аль төлөвийг хэзээ нэмэхээ тогтоо.
2. [Trapping Rain Water II](https://leetcode.com/problems/trapping-rain-water-ii/) — #407 · Hard
   - **Зорилго:** Stack ашиглан өмнөх төлөв, хаалт эсвэл дараагийн их/бага элементийн хамаарлыг боловсруул.
   - **Хэрэглээ:** Хаалт шалгах, undo, илэрхийлэл задлах болон дараагийн их/бага элементийг олоход.
   - **Бодох чиглэл:** Стекэд хадгалах төлөв, push/pop хийх мөчийг дүрмээр тодорхойл.
3. [Longest Palindrome](https://leetcode.com/problems/longest-palindrome/) — #409 · Easy
   - **Зорилго:** Нэрэнд заасан нөхцөлийг хангах хамгийн урт/богино хэсэг, зам эсвэл дарааллыг ол.
   - **Хэрэглээ:** Текст хайлт, өгөгдөл цэвэрлэх, формат шалгах болон хэлний боловсруулалтад.
   - **Бодох чиглэл:** Тэмдэг бүрийг нэг удаа боловсруулах боломжийг хайж, давтамж эсвэл индекс хадгал.
4. [Split Array Largest Sum](https://leetcode.com/problems/split-array-largest-sum/) — #410 · Hard
   - **Зорилго:** Нэрэнд заасан элементүүдийн нийлбэрийг зорилтот нөхцөлтэй уялдуулан ол.
   - **Хэрэглээ:** Жагсаалтын хос, хэсэг, дараалал болон байрлалыг тооцоход.
   - **Бодох чиглэл:** Оролтын хэмжээ, эрэмбэ, давхардалд тулгуурлан HashMap, хоёр заагч, prefix sum эсвэл sliding window-ийг сонго.
5. [Fizz Buzz](https://leetcode.com/problems/fizz-buzz/) — #412 · Easy
   - **Зорилго:** Томьёо, тоон шинж эсвэл хязгаарыг ашиглан математикийн үр дүнг тооц.
   - **Хэрэглээ:** Тоон хөрвүүлэлт, тоолол, геометр, үр ашигтай арифметикт.
   - **Бодох чиглэл:** Хязгаар, parity, модуль эсвэл томьёог ашиглаж бүх хувилбарыг шалгах шаардлагыг багасга.
