# Day 30: LeetCode бодлого

Энд бодлого бүрийн зорилго, ямар төрлийн асуудалд хэрэглэх, бодож эхлэх чиглэлийг Монгол хэлээр товчлов. Оролтын нарийн формат, жишээ, хязгаарлалтыг LeetCode холбоосоос шалгаарай.

Өнөөдрийн 5 бодлого. Бусад өдрийн бодлоготой давхцахгүй.

1. [LRU Cache](https://leetcode.com/problems/lru-cache/) — #146 · Medium
   - **Зорилго:** Нэрэнд заасан үйлдлүүдийг шаардлагатай хурдтай дэмжих өгөгдлийн бүтцийг загварчил.
   - **Хэрэглээ:** Кэш, индекс, санамсаргүй сонголт, API-ийн төлөв хадгалалтад.
   - **Бодох чиглэл:** Үйлдэл бүрийн хурдны шаардлагад нийцүүлэн бүтцүүдийг хослуулж, шинэчлэлтийн invariants-ийг хадгал.
2. [Insertion Sort List](https://leetcode.com/problems/insertion-sort-list/) — #147 · Medium
   - **Зорилго:** Өгөгдлийг эрэмбэлэх эсвэл эрэмбийн шинжийг ашиглан шаардагдах үр дүнг ол.
   - **Хэрэглээ:** Тайлангийн дараалал, эрэмбэлсэн хайлт, давхцал болон top-K олоход.
   - **Бодох чиглэл:** Эрэмбэлсний дараа нэг нэвтрэлт, хоёр заагч эсвэл greedy сонголт хийж болохыг шалга.
3. [Sort List](https://leetcode.com/problems/sort-list/) — #148 · Medium
   - **Зорилго:** Өгөгдлийг эрэмбэлэх эсвэл эрэмбийн шинжийг ашиглан шаардагдах үр дүнг ол.
   - **Хэрэглээ:** Тайлангийн дараалал, эрэмбэлсэн хайлт, давхцал болон top-K олоход.
   - **Бодох чиглэл:** Эрэмбэлсний дараа нэг нэвтрэлт, хоёр заагч эсвэл greedy сонголт хийж болохыг шалга.
4. [Max Points on a Line](https://leetcode.com/problems/max-points-on-a-line/) — #149 · Hard
   - **Зорилго:** Боломжит сонголтуудаас нэрэнд заасан хамгийн их утга эсвэл хэмжээг тооц.
   - **Хэрэглээ:** Координатын зураглал, огтлолцол, чиглэл болон талбай тооцоход.
   - **Бодох чиглэл:** Цэг бүрээс бусад цэг хүртэлх налалтыг харьцуул; бутархай налалтыг хурааж хадгал.
5. [Evaluate Reverse Polish Notation](https://leetcode.com/problems/evaluate-reverse-polish-notation/) — #150 · Medium
   - **Зорилго:** Stack ашиглан өмнөх төлөв, хаалт эсвэл дараагийн их/бага элементийн хамаарлыг боловсруул.
   - **Хэрэглээ:** Хаалт шалгах, undo, илэрхийлэл задлах болон дараагийн их/бага элементийг олоход.
   - **Бодох чиглэл:** Тэмдэгт мөрийг хэсэглэж stack ашиглан замын хэсэг эсвэл операндын дарааллыг боловсруул.
