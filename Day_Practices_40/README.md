# Day 40: LeetCode бодлого

Энд бодлого бүрийн зорилго, ямар төрлийн асуудалд хэрэглэх, бодож эхлэх чиглэлийг Монгол хэлээр товчлов. Оролтын нарийн формат, жишээ, хязгаарлалтыг LeetCode холбоосоос шалгаарай.

Өнөөдрийн 5 бодлого. Бусад өдрийн бодлоготой давхцахгүй.

1. [Count Primes](https://leetcode.com/problems/count-primes/) — #204 · Medium
   - **Зорилго:** Өгөгдсөн оролтоос нэрэнд заасан объект эсвэл тохиолдлын тоог тооц.
   - **Хэрэглээ:** Тоон хөрвүүлэлт, тоолол, геометр, үр ашигтай арифметикт.
   - **Бодох чиглэл:** Eratosthenes-ийн шигшүүрээр нийлмэл тоонуудын үржвэрийг тэмдэглэ.
2. [Isomorphic Strings](https://leetcode.com/problems/isomorphic-strings/) — #205 · Easy
   - **Зорилго:** Текстийн тэмдэгт, хэсэг эсвэл дүрмийг шалгаж нэрэнд заасан үр дүнг гарга.
   - **Хэрэглээ:** Текст хайлт, өгөгдөл цэвэрлэх, формат шалгах болон хэлний боловсруулалтад.
   - **Бодох чиглэл:** Тэмдэг бүрийг нэг удаа боловсруулах боломжийг хайж, давтамж эсвэл индекс хадгал.
3. [Reverse Linked List](https://leetcode.com/problems/reverse-linked-list/) — #206 · Easy
   - **Зорилго:** Элементүүдийн холбоо, дарааллыг хадгалан өгөгдлийг урвуулах эсвэл дахин байрлуулах үйлдэл хий.
   - **Хэрэглээ:** Дараалсан өгөгдөлд оруулах/устгах, холбоос урвуулах болон жагсаалтыг алхахад.
   - **Бодох чиглэл:** Заагчийн өмнөх/дараах холбоог тэмдэглэж, өөрчлөхөөс өмнө дараагийн зангилааг хадгал.
4. [Course Schedule](https://leetcode.com/problems/course-schedule/) — #207 · Medium
   - **Зорилго:** Орой ба холбоосоос хүрэх боломж, бүлэг, зам эсвэл зөв дарааллыг тогтоо.
   - **Хэрэглээ:** Замын сүлжээ, хэрэглэгчдийн холбоо, ажлын хамаарал болон чиглүүлэлтэд.
   - **Бодох чиглэл:** Хамаарлын чиглэлт граф байгуулж топологийн эрэмбэ эсвэл цикл илрүүл.
5. [Implement Trie (Prefix Tree)](https://leetcode.com/problems/implement-trie-prefix-tree/) — #208 · Medium
   - **Зорилго:** Модон бүтэц дээр нэрэнд заасан утга, зам, дараалал эсвэл шинжийг ол.
   - **Хэрэглээ:** Файлын хавтас, DOM/JSON зэрэг шаталсан өгөгдөл боловсруулахад.
   - **Бодох чиглэл:** DFS-ийн буцаах утга юу болохыг тодорхойл; хоосон мод, навчийг шалга.
