# Day 40: Stack: LIFO ба Min Stack

**Түвшин:** Дунд шат  
**Хичээлийн сэдэв:** Stack: LIFO ба Min Stack

## Суралцах зүйл

Push/pop/peek, underflow болон үе бүрийн minimum утгыг хянах.

## Java дасгал

ArrayDeque-аар хаалт шалгаж, O(1) min-тэй MinStack хэрэгжүүл.

## Дууссан гэж үзэх шалгуур

Хаалтын алдаа, давхардсан minimum, хоосон pop-ийг шалга.
