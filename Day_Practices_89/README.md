# Day 89: LeetCode бодлого

Энд бодлого бүрийн зорилго, ямар төрлийн асуудалд хэрэглэх, бодож эхлэх чиглэлийг Монгол хэлээр товчлов. Оролтын нарийн формат, жишээ, хязгаарлалтыг LeetCode холбоосоос шалгаарай.

Өнөөдрийн 5 бодлого. Бусад өдрийн бодлоготой давхцахгүй.

1. [Complex Number Multiplication](https://leetcode.com/problems/complex-number-multiplication/) — #537 · Medium
   - **Зорилго:** Томьёо, тоон шинж эсвэл хязгаарыг ашиглан математикийн үр дүнг тооц.
   - **Хэрэглээ:** Тоон хөрвүүлэлт, тоолол, геометр, үр ашигтай арифметикт.
   - **Бодох чиглэл:** Хязгаар, parity, модуль эсвэл томьёог ашиглаж бүх хувилбарыг шалгах шаардлагыг багасга.
2. [Convert BST to Greater Tree](https://leetcode.com/problems/convert-bst-to-greater-tree/) — #538 · Medium
   - **Зорилго:** Модон бүтэц дээр нэрэнд заасан утга, зам, дараалал эсвэл шинжийг ол.
   - **Хэрэглээ:** Файлын хавтас, DOM/JSON зэрэг шаталсан өгөгдөл боловсруулахад.
   - **Бодох чиглэл:** DFS-ийн буцаах утга юу болохыг тодорхойл; хоосон мод, навчийг шалга.
3. [Minimum Time Difference](https://leetcode.com/problems/minimum-time-difference/) — #539 · Medium
   - **Зорилго:** Боломжит сонголтуудаас нэрэнд заасан хамгийн бага утга, зардал эсвэл алхмыг ол.
   - **Хэрэглээ:** Цагийн хуваарь, уулзалтын өрөө, нөөцийн захиалга болон event-ийн мужид.
   - **Бодох чиглэл:** Интервалыг эрэмбэлээд давхцах нөхцөлөөр нэгтгэх эсвэл сонгох аргыг хэрэглэ.
4. [Single Element in a Sorted Array](https://leetcode.com/problems/single-element-in-a-sorted-array/) — #540 · Medium
   - **Зорилго:** Өгөгдлийг эрэмбэлэх эсвэл эрэмбийн шинжийг ашиглан шаардагдах үр дүнг ол.
   - **Хэрэглээ:** Тайлангийн дараалал, эрэмбэлсэн хайлт, давхцал болон top-K олоход.
   - **Бодох чиглэл:** Эрэмбэлсний дараа нэг нэвтрэлт, хоёр заагч эсвэл greedy сонголт хийж болохыг шалга.
5. [Reverse String II](https://leetcode.com/problems/reverse-string-ii/) — #541 · Easy
   - **Зорилго:** Элементүүдийн холбоо, дарааллыг хадгалан өгөгдлийг урвуулах эсвэл дахин байрлуулах үйлдэл хий.
   - **Хэрэглээ:** Текст хайлт, өгөгдөл цэвэрлэх, формат шалгах болон хэлний боловсруулалтад.
   - **Бодох чиглэл:** Тэмдэг бүрийг нэг удаа боловсруулах боломжийг хайж, давтамж эсвэл индекс хадгал.
