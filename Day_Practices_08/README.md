# Day 08: LeetCode бодлого

Энд бодлого бүрийн зорилго, ямар төрлийн асуудалд хэрэглэх, бодож эхлэх чиглэлийг Монгол хэлээр товчлов. Оролтын нарийн формат, жишээ, хязгаарлалтыг LeetCode холбоосоос шалгаарай.

Өнөөдрийн 5 бодлого. Бусад өдрийн бодлоготой давхцахгүй.

1. [First Missing Positive](https://leetcode.com/problems/first-missing-positive/) — #41 · Hard
   - **Зорилго:** Массивт байхгүй хамгийн бага эерэг бүхэл тоог O(n) хугацаа, O(1) нэмэлт зайд ол.
   - **Хэрэглээ:** Жагсаалтын хос, хэсэг, дараалал болон байрлалыг тооцоход.
   - **Бодох чиглэл:** Эерэг x утгыг боломжтой бол x-1 индекст байрлуулах in-place байршуулалтыг ашигла.
2. [Trapping Rain Water](https://leetcode.com/problems/trapping-rain-water/) — #42 · Hard
   - **Зорилго:** Өндрийн багануудын хооронд хуримтлагдах усны нийт хэмжээг ол.
   - **Хэрэглээ:** Хаалт шалгах, undo, илэрхийлэл задлах болон дараагийн их/бага элементийг олоход.
   - **Бодох чиглэл:** Стекэд хадгалах төлөв, push/pop хийх мөчийг дүрмээр тодорхойл.
3. [Multiply Strings](https://leetcode.com/problems/multiply-strings/) — #43 · Medium
   - **Зорилго:** Текстийн тэмдэгт, хэсэг эсвэл дүрмийг шалгаж нэрэнд заасан үр дүнг гарга.
   - **Хэрэглээ:** Текст хайлт, өгөгдөл цэвэрлэх, формат шалгах болон хэлний боловсруулалтад.
   - **Бодох чиглэл:** Тэмдэг бүрийг нэг удаа боловсруулах боломжийг хайж, давтамж эсвэл индекс хадгал.
4. [Wildcard Matching](https://leetcode.com/problems/wildcard-matching/) — #44 · Hard
   - **Зорилго:** Массив эсвэл тоон дарааллын элементүүдээс нэрэнд заасан үр дүнг олж/өөрчил.
   - **Хэрэглээ:** Жагсаалтын хос, хэсэг, дараалал болон байрлалыг тооцоход.
   - **Бодох чиглэл:** Тэмдэгтийн индексүүдээр DP төлөв байгуулж, одоогийн тэмдэгтийн боломжит шилжилтийг тооц.
5. [Jump Game II](https://leetcode.com/problems/jump-game-ii/) — #45 · Medium
   - **Зорилго:** Сүүлийн индексэд хүрэхэд шаардагдах хамгийн цөөн үсрэлтийг ол.
   - **Хэрэглээ:** Хуваарь, нөөц хуваарилах, зардал багасгах зэрэг сонголтын асуудалд.
   - **Бодох чиглэл:** Одоогоор хүрч болох хамгийн баруун индексийг greedily шинэчил; II хувилбарт хүрэх хүрээг түвшнээр тооц.
