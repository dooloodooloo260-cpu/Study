# Day 47: LeetCode бодлого

Энд бодлого бүрийн зорилго, ямар төрлийн асуудалд хэрэглэх, бодож эхлэх чиглэлийг Монгол хэлээр товчлов. Оролтын нарийн формат, жишээ, хязгаарлалтыг LeetCode холбоосоос шалгаарай.

Өнөөдрийн 5 бодлого. Бусад өдрийн бодлоготой давхцахгүй.

1. [Sliding Window Maximum](https://leetcode.com/problems/sliding-window-maximum/) — #239 · Hard
   - **Зорилго:** FIFO дарааллаар элемент эсвэл төлөвийг боловсруул.
   - **Хэрэглээ:** Үйлчилгээний дараалал, түвшин түвшний хайлт, ажил түгээхэд.
   - **Бодох чиглэл:** Монотон deque-д индекс хадгалж, цонхноос гарсан ба дутуу утгуудыг хас.
2. [Search a 2D Matrix II](https://leetcode.com/problems/search-a-2d-matrix-ii/) — #240 · Medium
   - **Зорилго:** Торон хүснэгтийн нүд, хөршийн холбоонд хайлт, тоолол эсвэл замын үр дүнг ол.
   - **Хэрэглээ:** Газрын зураг, зураг-пикселийн бүс, торон тоглоомын байрлал тооцоход.
   - **Бодох чиглэл:** Хөрш нүднүүдийг BFS/DFS-ээр шалгаж visited тэмдэглэ; хил ба диагоналийн дүрмийг нягтал.
3. [Different Ways to Add Parentheses](https://leetcode.com/problems/different-ways-to-add-parentheses/) — #241 · Medium
   - **Зорилго:** Stack ашиглан өмнөх төлөв, хаалт эсвэл дараагийн их/бага элементийн хамаарлыг боловсруул.
   - **Хэрэглээ:** Хаалт шалгах, undo, илэрхийлэл задлах болон дараагийн их/бага элементийг олоход.
   - **Бодох чиглэл:** Stack-д нээгдсэн хаалтыг хадгалж хаагдах бүрд төрөл ба дарааллыг шалга.
4. [Valid Anagram](https://leetcode.com/problems/valid-anagram/) — #242 · Easy
   - **Зорилго:** Өгсөн өгөгдөл нэрэнд заасан дүрэм, бүтэц эсвэл нөхцөлийг хангаж байгаа эсэхийг шалга.
   - **Хэрэглээ:** Текст хайлт, өгөгдөл цэвэрлэх, формат шалгах болон хэлний боловсруулалтад.
   - **Бодох чиглэл:** Мөр бүрт тэмдэгтийн давтамжийн гарын үсэг эсвэл эрэмбэлсэн түлхүүр үүсгэн бүлэглэ.
5. [Binary Tree Paths](https://leetcode.com/problems/binary-tree-paths/) — #257 · Easy
   - **Зорилго:** Модон бүтэц дээр нэрэнд заасан утга, зам, дараалал эсвэл шинжийг ол.
   - **Хэрэглээ:** Файлын хавтас, DOM/JSON зэрэг шаталсан өгөгдөл боловсруулахад.
   - **Бодох чиглэл:** DFS-ийн буцаах утга юу болохыг тодорхойл; хоосон мод, навчийг шалга.
