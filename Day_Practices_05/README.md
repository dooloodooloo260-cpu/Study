# Day 05: LeetCode бодлого

Энд бодлого бүрийн зорилго, ямар төрлийн асуудалд хэрэглэх, бодож эхлэх чиглэлийг Монгол хэлээр товчлов. Оролтын нарийн формат, жишээ, хязгаарлалтыг LeetCode холбоосоос шалгаарай.

Өнөөдрийн 5 бодлого. Бусад өдрийн бодлоготой давхцахгүй.

1. [Remove Duplicates from Sorted Array](https://leetcode.com/problems/remove-duplicates-from-sorted-array/) — #26 · Easy
   - **Зорилго:** Нэрэнд заасан элемент эсвэл зангилааг устгаж үлдсэн өгөгдлийг зөв хадгал.
   - **Хэрэглээ:** Тайлангийн дараалал, эрэмбэлсэн хайлт, давхцал болон top-K олоход.
   - **Бодох чиглэл:** Эрэмбэлсний дараа нэг нэвтрэлт, хоёр заагч эсвэл greedy сонголт хийж болохыг шалга.
2. [Remove Element](https://leetcode.com/problems/remove-element/) — #27 · Easy
   - **Зорилго:** Нэрэнд заасан элемент эсвэл зангилааг устгаж үлдсэн өгөгдлийг зөв хадгал.
   - **Хэрэглээ:** Жагсаалтын хос, хэсэг, дараалал болон байрлалыг тооцоход.
   - **Бодох чиглэл:** Оролтын хэмжээ, эрэмбэ, давхардалд тулгуурлан HashMap, хоёр заагч, prefix sum эсвэл sliding window-ийг сонго.
3. [Find the Index of the First Occurrence in a String](https://leetcode.com/problems/find-the-index-of-the-first-occurrence-in-a-string/) — #28 · Easy
   - **Зорилго:** Хайх мөр текстэд анх эхэлсэн индексийг ол; байхгүй бол -1 буцаа.
   - **Хэрэглээ:** Текст хайлт, өгөгдөл цэвэрлэх, формат шалгах болон хэлний боловсруулалтад.
   - **Бодох чиглэл:** Тэмдэгтүүдийг нэг нэгээр нь харьцуулах эсвэл KMP prefix table ашиглан давтан шалгалтыг багасга.
4. [Divide Two Integers](https://leetcode.com/problems/divide-two-integers/) — #29 · Medium
   - **Зорилго:** Томьёо, тоон шинж эсвэл хязгаарыг ашиглан математикийн үр дүнг тооц.
   - **Хэрэглээ:** Тоон хөрвүүлэлт, тоолол, геометр, үр ашигтай арифметикт.
   - **Бодох чиглэл:** Хязгаар, parity, модуль эсвэл томьёог ашиглаж бүх хувилбарыг шалгах шаардлагыг багасга.
5. [Substring with Concatenation of All Words](https://leetcode.com/problems/substring-with-concatenation-of-all-words/) — #30 · Hard
   - **Зорилго:** Өгсөн үг бүр нэг удаа орсон залгаа нийлбэрийг агуулсан бүх эхлэх индексийг ол.
   - **Хэрэглээ:** Текст хайлт, өгөгдөл цэвэрлэх, формат шалгах болон хэлний боловсруулалтад.
   - **Бодох чиглэл:** Үгсийн уртаар алхам алхмаа өөрчилж sliding window болон үг бүрийн давтамжийг хяна.
