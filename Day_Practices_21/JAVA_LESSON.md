# Day 21: Null ба хамгаалалт

**Түвшин:** Анхан шат  
**Хичээлийн сэдэв:** Null ба хамгаалалт

## Суралцах зүйл

Null reference, null шалгалт, NullPointerException.

## Java дасгал

Нэр эсвэл массив null байж болох method-уудыг аюулгүй болго.

## Дууссан гэж үзэх шалгуур

Null кейсийг тодорхой шалгаж, утгатай алдаа өг.
