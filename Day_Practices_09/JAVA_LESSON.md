# Day 09: Массив ба индекс

**Түвшин:** Анхан шат  
**Хичээлийн сэдэв:** Массив ба индекс

## Суралцах зүйл

Массивын тогтмол хэмжээ, индекс 0-оос эхлэх зарчим.

## Java дасгал

5 өдрийн оноог массивт хадгалж, эхний ба сүүлийн элементийг хэвлэ.

## Дууссан гэж үзэх шалгуур

Хязгаараас гадуур индекс үүсгэхгүй бай.
