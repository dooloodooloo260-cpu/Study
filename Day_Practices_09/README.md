# Day 09: LeetCode бодлого

Энд бодлого бүрийн зорилго, ямар төрлийн асуудалд хэрэглэх, бодож эхлэх чиглэлийг Монгол хэлээр товчлов. Оролтын нарийн формат, жишээ, хязгаарлалтыг LeetCode холбоосоос шалгаарай.

Өнөөдрийн 5 бодлого. Бусад өдрийн бодлоготой давхцахгүй.

1. [Permutations](https://leetcode.com/problems/permutations/) — #46 · Medium
   - **Зорилго:** HashMap/Set ашиглан давтамж, өмнө үзсэн утга эсвэл хурдан хайлтыг удирд.
   - **Хэрэглээ:** Давхардал илрүүлэх, хос тааруулах, давтамж тоолох, индексжүүлэхэд.
   - **Бодох чиглэл:** Backtracking хийж сонголт бүрийн дараа төлөвөө сэргээ; давхардал болон боломжгүй салааг эрт тайр.
2. [Permutations II](https://leetcode.com/problems/permutations-ii/) — #47 · Medium
   - **Зорилго:** HashMap/Set ашиглан давтамж, өмнө үзсэн утга эсвэл хурдан хайлтыг удирд.
   - **Хэрэглээ:** Давхардал илрүүлэх, хос тааруулах, давтамж тоолох, индексжүүлэхэд.
   - **Бодох чиглэл:** Backtracking хийж сонголт бүрийн дараа төлөвөө сэргээ; давхардал болон боломжгүй салааг эрт тайр.
3. [Rotate Image](https://leetcode.com/problems/rotate-image/) — #48 · Medium
   - **Зорилго:** n×n матрицыг 90 градус цагийн зүүний дагуу in-place эргүүл.
   - **Хэрэглээ:** Газрын зураг, зураг-пикселийн бүс, торон тоглоомын байрлал тооцоход.
   - **Бодох чиглэл:** Матрицын диагональ дагуу transpose хийгээд мөр бүрийг урвуул.
4. [Group Anagrams](https://leetcode.com/problems/group-anagrams/) — #49 · Medium
   - **Зорилго:** HashMap/Set ашиглан давтамж, өмнө үзсэн утга эсвэл хурдан хайлтыг удирд.
   - **Хэрэглээ:** Давхардал илрүүлэх, хос тааруулах, давтамж тоолох, индексжүүлэхэд.
   - **Бодох чиглэл:** Мөр бүрт тэмдэгтийн давтамжийн гарын үсэг эсвэл эрэмбэлсэн түлхүүр үүсгэн бүлэглэ.
5. [Pow(x, n)](https://leetcode.com/problems/powx-n/) — #50 · Medium
   - **Зорилго:** x-ийн n зэргийг тооц; сөрөг зэрэг болон бүхэл хязгаарыг зөв боловсруул.
   - **Хэрэглээ:** Жагсаалтын хос, хэсэг, дараалал болон байрлалыг тооцоход.
   - **Бодох чиглэл:** Зэргийг хагаслан fast exponentiation хэрэглэ; n хамгийн бага бүхэл утга байх үед урвуулахдаа overflow-ийг шалга.
