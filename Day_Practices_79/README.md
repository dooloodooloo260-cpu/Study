# Day 79: LeetCode бодлого

Энд бодлого бүрийн зорилго, ямар төрлийн асуудалд хэрэглэх, бодож эхлэх чиглэлийг Монгол хэлээр товчлов. Оролтын нарийн формат, жишээ, хязгаарлалтыг LeetCode холбоосоос шалгаарай.

Өнөөдрийн 5 бодлого. Бусад өдрийн бодлоготой давхцахгүй.

1. [Ones and Zeroes](https://leetcode.com/problems/ones-and-zeroes/) — #474 · Medium
   - **Зорилго:** Массив эсвэл тоон дарааллын элементүүдээс нэрэнд заасан үр дүнг олж/өөрчил.
   - **Хэрэглээ:** Жагсаалтын хос, хэсэг, дараалал болон байрлалыг тооцоход.
   - **Бодох чиглэл:** Оролтын хэмжээ, эрэмбэ, давхардалд тулгуурлан HashMap, хоёр заагч, prefix sum эсвэл sliding window-ийг сонго.
2. [Heaters](https://leetcode.com/problems/heaters/) — #475 · Medium
   - **Зорилго:** Одоогийн алхам бүрт зөв сонголт хийж эцсийн боломжит/хамгийн сайн үр дүнд хүр.
   - **Хэрэглээ:** Хуваарь, нөөц хуваарилах, зардал багасгах зэрэг сонголтын асуудалд.
   - **Бодох чиглэл:** Одоогийн хамгийн ашигтай сонголт эцсийн зөв шийдэлд хүргэх нөхцөлийг шалга.
3. [Number Complement](https://leetcode.com/problems/number-complement/) — #476 · Easy
   - **Зорилго:** Тоог хоёртын дүрслэлд хувирган битийн түвшинд нэрэнд заасан тооцоог хий.
   - **Хэрэглээ:** Flag/permission багцлах, битэн төлөв хадгалах, хурдан XOR тооцоонд.
   - **Бодох чиглэл:** XOR/shift ашиглаж бит тус бүрийн давтамж эсвэл байрлалыг тооц.
4. [Total Hamming Distance](https://leetcode.com/problems/total-hamming-distance/) — #477 · Medium
   - **Зорилго:** Тоог хоёртын дүрслэлд хувирган битийн түвшинд нэрэнд заасан тооцоог хий.
   - **Хэрэглээ:** Flag/permission багцлах, битэн төлөв хадгалах, хурдан XOR тооцоонд.
   - **Бодох чиглэл:** XOR, AND, OR, shift оператор ашиглан бит тус бүрийн төлөвийг тооц.
5. [Generate Random Point in a Circle](https://leetcode.com/problems/generate-random-point-in-a-circle/) — #478 · Medium
   - **Зорилго:** Цэг, шулуун, тэгш өнцөгт зэрэг геометрийн объектын хамаарлыг тооц.
   - **Хэрэглээ:** Координатын зураглал, огтлолцол, чиглэл болон талбай тооцоход.
   - **Бодох чиглэл:** Координатын ялгаа, налалт, огтлолцол/давхцлыг хязгаарын жишээгээр шалга.
