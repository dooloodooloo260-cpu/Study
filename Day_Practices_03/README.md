# Day 03: LeetCode бодлого

Энд бодлого бүрийн зорилго, ямар төрлийн асуудалд хэрэглэх, бодож эхлэх чиглэлийг Монгол хэлээр товчлов. Оролтын нарийн формат, жишээ, хязгаарлалтыг LeetCode холбоосоос шалгаарай.

Өнөөдрийн 5 бодлого. Бусад өдрийн бодлоготой давхцахгүй.

1. [3Sum Closest](https://leetcode.com/problems/3sum-closest/) — #16 · Medium
   - **Зорилго:** Гурван элементийн нийлбэрийг зорилтот утгад хамгийн ойр болго.
   - **Хэрэглээ:** Жагсаалтын хос, хэсэг, дараалал болон байрлалыг тооцоход.
   - **Бодох чиглэл:** Эрэмбэлсэн массивт нэг индекс тогтоож хоёр заагчаар нийлбэрийг зорилтот утга руу ойртуул.
2. [Letter Combinations of a Phone Number](https://leetcode.com/problems/letter-combinations-of-a-phone-number/) — #17 · Medium
   - **Зорилго:** Цифр бүрт харгалзах утасны товчлуурын үсгүүдээс үүсэх бүх боломжит мөрийг гарга.
   - **Хэрэглээ:** Давхардал илрүүлэх, хос тааруулах, давтамж тоолох, индексжүүлэхэд.
   - **Бодох чиглэл:** Цифр бүрийн үсгийн сонголтыг backtracking-ээр нийлүүлж, бүрэн урттай үед хариунд нэм.
3. [4Sum](https://leetcode.com/problems/4sum/) — #18 · Medium
   - **Зорилго:** Өгсөн зорилтот нийлбэр үүсгэх дөрвөн элементийн давхардалгүй хослолуудыг ол.
   - **Хэрэглээ:** Жагсаалтын хос, хэсэг, дараалал болон байрлалыг тооцоход.
   - **Бодох чиглэл:** Эрэмбэлж эхний хоёр индексийг тогтоогоод үлдсэн хэсэгт хоёр заагч ажиллуул; давхардлыг алгас.
4. [Remove Nth Node From End of List](https://leetcode.com/problems/remove-nth-node-from-end-of-list/) — #19 · Medium
   - **Зорилго:** Холбоост жагсаалтын төгсгөлөөс n дэх зангилааг устга.
   - **Хэрэглээ:** Дараалсан өгөгдөлд оруулах/устгах, холбоос урвуулах болон жагсаалтыг алхахад.
   - **Бодох чиглэл:** Заагчийн өмнөх/дараах холбоог тэмдэглэж, өөрчлөхөөс өмнө дараагийн зангилааг хадгал.
5. [Valid Parentheses](https://leetcode.com/problems/valid-parentheses/) — #20 · Easy
   - **Зорилго:** Нээгдсэн хаалт бүр зөв төрлийн хаалтаар зөв дарааллаар хаагдсан эсэхийг шалга.
   - **Хэрэглээ:** Хаалт шалгах, undo, илэрхийлэл задлах болон дараагийн их/бага элементийг олоход.
   - **Бодох чиглэл:** Stack-д нээгдсэн хаалтыг хадгалж хаагдах бүрд төрөл, дарааллыг шалга.
