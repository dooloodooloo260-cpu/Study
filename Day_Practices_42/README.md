# Day 42: LeetCode бодлого

Энд бодлого бүрийн зорилго, ямар төрлийн асуудалд хэрэглэх, бодож эхлэх чиглэлийг Монгол хэлээр товчлов. Оролтын нарийн формат, жишээ, хязгаарлалтыг LeetCode холбоосоос шалгаарай.

Өнөөдрийн 5 бодлого. Бусад өдрийн бодлоготой давхцахгүй.

1. [Shortest Palindrome](https://leetcode.com/problems/shortest-palindrome/) — #214 · Hard
   - **Зорилго:** Нэрэнд заасан нөхцөлийг хангах хамгийн урт/богино хэсэг, зам эсвэл дарааллыг ол.
   - **Хэрэглээ:** Текст хайлт, өгөгдөл цэвэрлэх, формат шалгах болон хэлний боловсруулалтад.
   - **Бодох чиглэл:** Тэмдэг бүрийг нэг удаа боловсруулах боломжийг хайж, давтамж эсвэл индекс хадгал.
2. [Kth Largest Element in an Array](https://leetcode.com/problems/kth-largest-element-in-an-array/) — #215 · Medium
   - **Зорилго:** Олон утгаас хамгийн их/бага эсвэл дараагийн чухал элементийг үр ашигтай сонго.
   - **Хэрэглээ:** Ажлын эрэмбэ, top-K жагсаалт, урсгал өгөгдлийн тэргүүлэх утгад.
   - **Бодох чиглэл:** Хамгийн чухал одоогийн сонголтыг heap-аар сонгож, шинэ боломжуудыг дараалалд нэм.
3. [Combination Sum III](https://leetcode.com/problems/combination-sum-iii/) — #216 · Medium
   - **Зорилго:** Нэрэнд заасан элементүүдийн нийлбэрийг зорилтот нөхцөлтэй уялдуулан ол.
   - **Хэрэглээ:** Таавар, хослол үүсгэх, хязгаарлалттай байрлуулах асуудалд.
   - **Бодох чиглэл:** Backtracking хийж сонголт бүрийн дараа төлөвөө сэргээ; давхардал болон боломжгүй салааг эрт тайр.
4. [Contains Duplicate](https://leetcode.com/problems/contains-duplicate/) — #217 · Easy
   - **Зорилго:** HashMap/Set ашиглан давтамж, өмнө үзсэн утга эсвэл хурдан хайлтыг удирд.
   - **Хэрэглээ:** Давхардал илрүүлэх, хос тааруулах, давтамж тоолох, индексжүүлэхэд.
   - **Бодох чиглэл:** HashMap/Set-д түлхүүр хадгалж давтамж, өмнө үзсэн утга эсвэл хосыг хурдан шалга.
5. [The Skyline Problem](https://leetcode.com/problems/the-skyline-problem/) — #218 · Hard
   - **Зорилго:** Массив эсвэл тоон дарааллын элементүүдээс нэрэнд заасан үр дүнг олж/өөрчил.
   - **Хэрэглээ:** Жагсаалтын хос, хэсэг, дараалал болон байрлалыг тооцоход.
   - **Бодох чиглэл:** Хамгийн чухал одоогийн сонголтыг heap-аар сонгож, шинэ боломжуудыг дараалалд нэм.
