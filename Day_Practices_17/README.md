# Day 17: LeetCode бодлого

Энд бодлого бүрийн зорилго, ямар төрлийн асуудалд хэрэглэх, бодож эхлэх чиглэлийг Монгол хэлээр товчлов. Оролтын нарийн формат, жишээ, хязгаарлалтыг LeetCode холбоосоос шалгаарай.

Өнөөдрийн 5 бодлого. Бусад өдрийн бодлоготой давхцахгүй.

1. [Partition List](https://leetcode.com/problems/partition-list/) — #86 · Medium
   - **Зорилго:** Холбоост жагсаалтын зангилаа, заагчийг ашиглан нэрэнд заасан үйлдлийг хий.
   - **Хэрэглээ:** Дараалсан өгөгдөлд оруулах/устгах, холбоос урвуулах болон жагсаалтыг алхахад.
   - **Бодох чиглэл:** Заагчийн өмнөх/дараах холбоог тэмдэглэж, өөрчлөхөөс өмнө дараагийн зангилааг хадгал.
2. [Scramble String](https://leetcode.com/problems/scramble-string/) — #87 · Hard
   - **Зорилго:** Текстийн тэмдэгт, хэсэг эсвэл дүрмийг шалгаж нэрэнд заасан үр дүнг гарга.
   - **Хэрэглээ:** Текст хайлт, өгөгдөл цэвэрлэх, формат шалгах болон хэлний боловсруулалтад.
   - **Бодох чиглэл:** Тэмдэг бүрийг нэг удаа боловсруулах боломжийг хайж, давтамж эсвэл индекс хадгал.
3. [Merge Sorted Array](https://leetcode.com/problems/merge-sorted-array/) — #88 · Easy
   - **Зорилго:** Өгөгдлүүдийг нэрэнд заасан эрэмбэ, дүрмийн дагуу нэгтгэ.
   - **Хэрэглээ:** Тайлангийн дараалал, эрэмбэлсэн хайлт, давхцал болон top-K олоход.
   - **Бодох чиглэл:** Эрэмбэлсний дараа нэг нэвтрэлт, хоёр заагч эсвэл greedy сонголт хийж болохыг шалга.
4. [Gray Code](https://leetcode.com/problems/gray-code/) — #89 · Medium
   - **Зорилго:** n битээр ялгаатай дараалсан утгууд зөвхөн нэг битээр зөрөх Gray code дарааллыг үүсгэ.
   - **Хэрэглээ:** Flag/permission багцлах, битэн төлөв хадгалах, хурдан XOR тооцоонд.
   - **Бодох чиглэл:** k утгыг `k ^ (k >> 1)` томьёогоор Gray code болгон хувирга.
5. [Subsets II](https://leetcode.com/problems/subsets-ii/) — #90 · Medium
   - **Зорилго:** Сонголтуудыг туршиж, нөхцөл зөрчсөн салааг буцааж тайрч хүчинтэй шийдлүүдийг ол.
   - **Хэрэглээ:** Таавар, хослол үүсгэх, хязгаарлалттай байрлуулах асуудалд.
   - **Бодох чиглэл:** Backtracking хийж сонголт бүрийн дараа төлөвөө сэргээ; давхардал болон боломжгүй салааг эрт тайр.
