# Day 01: LeetCode бодлого

Энд бодлого бүрийн зорилго, ямар төрлийн асуудалд хэрэглэх, бодож эхлэх чиглэлийг Монгол хэлээр товчлов. Оролтын нарийн формат, жишээ, хязгаарлалтыг LeetCode холбоосоос шалгаарай.

Өнөөдрийн 5 бодлого. Бусад өдрийн бодлоготой давхцахгүй.

1. [Zigzag Conversion](https://leetcode.com/problems/zigzag-conversion/) — #6 · Medium
   - **Зорилго:** Мөрийн тэмдэгтүүдийг өгсөн мөрийн тоогоор zigzag байрлуулж, дараа нь мөр бүрээр нь залга.
   - **Хэрэглээ:** Текст хайлт, өгөгдөл цэвэрлэх, формат шалгах болон хэлний боловсруулалтад.
   - **Бодох чиглэл:** Мөрүүдийн чиглэлийг ээлжлэн өөрчилж индексийг тооц; тэмдэгтүүдийг эцэст нь мөрөөр нь залга.
2. [Reverse Integer](https://leetcode.com/problems/reverse-integer/) — #7 · Medium
   - **Зорилго:** Бүхэл тооны цифрүүдийг урвуу дарааллаар эргүүл; 32-битийн хязгаар хэтэрвэл 0 буцаа.
   - **Хэрэглээ:** Тоон хөрвүүлэлт, тоолол, геометр, үр ашигтай арифметикт.
   - **Бодох чиглэл:** Хязгаар, parity, модуль эсвэл томьёог ашиглаж бүх хувилбарыг шалгах шаардлагыг багасга.
3. [String to Integer (atoi)](https://leetcode.com/problems/string-to-integer-atoi/) — #8 · Medium
   - **Зорилго:** Эхний whitespace-ийг алгасаад тэмдэг, цифрийг дүрмийн дагуу уншиж бүхэл тоо болго; overflow-ийг хязгаарла.
   - **Хэрэглээ:** Тоон хөрвүүлэлт, тоолол, геометр, үр ашигтай арифметикт.
   - **Бодох чиглэл:** Тэмдэгтүүдийг зүүнээс баруун тийш төлөвтэй уншиж, тэмдэг/цифр/тусгаарлагчийн дүрмийг шалга.
4. [Palindrome Number](https://leetcode.com/problems/palindrome-number/) — #9 · Easy
   - **Зорилго:** Тооны цифрүүд урдаасаа болон араасаа ижил дарааллаар уншигдах эсэхийг шалга.
   - **Хэрэглээ:** Тоон хөрвүүлэлт, тоолол, геометр, үр ашигтай арифметикт.
   - **Бодох чиглэл:** Хязгаар, parity, модуль эсвэл томьёог ашиглаж бүх хувилбарыг шалгах шаардлагыг багасга.
5. [Regular Expression Matching](https://leetcode.com/problems/regular-expression-matching/) — #10 · Hard
   - **Зорилго:** Мөр бүхэлдээ `.` болон `*` wildcard бүхий өгсөн загварт таарч байгаа эсэхийг шалга.
   - **Хэрэглээ:** Текст хайлт, формат шалгалт, лог/оролтын pattern-д тааруулахад.
   - **Бодох чиглэл:** Мөр болон pattern-ийн индексээр DP хүснэгт байгуулж `*`-ийн тэг эсвэл олон давталтыг ялга.
