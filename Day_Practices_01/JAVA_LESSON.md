# Day 01: Java орчин ба эхний програм

**Түвшин:** Анхан шат  
**Хичээлийн сэдэв:** Java орчин ба эхний програм

## Суралцах зүйл

### JDK, JRE, JVM гэж юу вэ?

- **JVM (Java Virtual Machine):** Java bytecode-ийг ажиллуулдаг виртуал машин.
  Өөр үйлдлийн систем дээр JVM байвал ижил bytecode-ийг ажиллуулах боломжтой.
- **JRE (Java Runtime Environment):** Java програм ажиллуулах орчин. JVM болон
  ажиллахад шаардлагатай сангуудыг агуулна.
- **JDK (Java Development Kit):** Java програм хөгжүүлэх багц. JRE-ээс гадна
  эх кодыг хөрвүүлэх `javac` зэрэг хөгжүүлэлтийн хэрэгслүүдийг агуулна.

Товчоор: **JDK-ээр хөгжүүлнэ, JRE орчинд ажиллуулна, JVM bytecode-ийг
ажиллуулна.** Орчин үеийн Java хувилбаруудад JRE-г тусад нь суулгахын оронд JDK
эсвэл JRE агуулсан runtime багц ашиглах нь түгээмэл.

### Эх кодоос ажиллах програм хүртэл

1. `.java` файлд Java эх кодоо бичнэ.
2. JDK-ийн `javac` хөрвүүлэгч эх кодыг `.class` өргөтгөлтэй bytecode болгоно.
   Жишээ нь: `javac HelloWorld.java`.
3. `java` командаар програмыг ажиллуулахад JVM bytecode-ийг уншиж, тухайн
   систем дээр гүйцэтгэнэ. Жишээ нь: `java HelloWorld`.
4. Програмын үр дүн терминал эсвэл өөр гаралтад харагдана.

Ерөнхий урсгал:

```text
HelloWorld.java (эх код)
        │ javac
        ▼
HelloWorld.class (bytecode)
        │ java / JVM
        ▼
Ажиллаж буй програм ба гаралт
```

`javac` ашиглахын тулд JDK суусан байх ёстой. Харин хөрвүүлсэн програмыг
ажиллуулахад тохирох Java runtime хэрэгтэй.

## Java дасгал

HelloWorld програм бичиж compile/run хийгээд гаралтыг өөрчил.
