# Day 01: Java орчин ба эхний програм

**Түвшин:** Анхан шат  
**Хичээлийн сэдэв:** Java орчин ба эхний програм

## Суралцах зүйл

### JDK, JRE, JVM гэж юу вэ?

Java программ бичих, хөрвүүлэх, ажиллуулахад эдгээр гурван нэр томьёо гарна.
Тэд хоорондоо холбоотой ч **нэг зүйл биш**.

| Нэр | Бүтэн нэр | Үүрэг | Энгийнээр |
| --- | --- | --- | --- |
| **JDK** | Java Development Kit | Java код бичиж, хөрвүүлж, шалгахад хэрэгтэй хөгжүүлэлтийн хэрэгслүүдийг өгнө. Үүнд `javac` хөрвүүлэгч болон `java` ажиллуулагч орно. | Программ **хийх ба ажиллуулахад** хэрэгтэй багажны багц. |
| **JRE** | Java Runtime Environment | Java программыг ажиллуулахад хэрэгтэй runtime сангууд болон JVM-ийг агуулна. | Бэлэн программыг **ажиллуулах орчин**. |
| **JVM** | Java Virtual Machine | `.class` файл дахь Java bytecode-ийг тухайн компьютер дээр ажиллуулна. | Bytecode-ийн зааврыг **гүйцэтгэгч**. |

Уламжлалт ойлголтоор JDK нь хөгжүүлэлтийн хэрэгсэл дээр нэмээд ажиллуулах
орчныг агуулдаг; JRE нь JVM болон стандарт сангуудыг агуулдаг; JVM нь
bytecode-ийг гүйцэтгэдэг. Орчин үеийн Java-д JRE-г дангаар нь тусад нь
суулгадаггүй хувилбар түгээмэл. Тиймээс шинэ Java орчинд **JDK суулгаж кодоо
хөрвүүлээд ажиллуулах** нь энгийн сонголт юм.

Санахад амархан:

- Кодоо **бичиж, хөрвүүлэх** бол JDK хэрэгтэй.
- Бэлэн Java программ **ажиллуулах** бол Java runtime хэрэгтэй.
- `.class` файлын bytecode-ийг **гүйцэтгэдэг** нь JVM.

### Java эх код яаж ажилладаг вэ?

Доорх `Day01.java` файлыг жишээ болгоё:

```java
public class Day01 {
    public static void main(String[] args) {
        System.out.println("hello world");
    }
}
```

Энэ кодыг ажиллуулахад дараах алхамууд явагдана:

1. **Эх код бичнэ.** Хүн уншиж, засаж болох Java код `Day01.java` файлд байна.
   Энэ файлыг компьютер шууд JVM-ийн bytecode хэлбэрээр ажиллуулахгүй.
2. **Хөрвүүлнэ.** JDK-ийн `javac` хэрэгсэл Java эх кодын бичиглэл болон
   дүрмийг шалгаж, JVM-ийн ойлгох bytecode болгон `.class` файл үүсгэнэ.
   ```bash
   javac Day01.java
   ```
   Амжилттай бол энэ хавтсанд `Day01.class` үүснэ. Хөрвүүлэлтийн алдаа байвал
   `javac` алдааны мөрийг мэдээлэх бөгөөд ажиллуулах `.class` файл үүсэхгүй
   эсвэл шинэчлэгдэхгүй.
3. **Ажиллуулна.** Java-ийн `java` ажиллуулагч `Day01` классыг олж, JVM-ийг
   эхлүүлэн түүний bytecode-ийг ажиллуулна. Өргөтгөлийг (`.class`) командыг
   бичихгүй.
   ```bash
   java Day01
   ```
4. **Үр дүн гарна.** JVM `main` аргаас эхлэн зааврыг гүйцэтгэнэ.
   `System.out.println` нь `hello world` текстийг терминалд хэвлэнэ.

Бүх урсгалыг нэг мөрөөр:

```text
Day01.java --javac (JDK)--> Day01.class (bytecode) --java эхлүүлэгч / JVM--> hello world
```

`.java` бол **хүний уншиж бичдэг эх код**; `.class` бол **JVM-ийн уншдаг
bytecode**. JVM болон Java-ийн стандарт сангуудыг ажиллуулах орчныг runtime
гэж ойлгоно. Иймээс Java кодоо хөрвүүлэхэд JDK шаардлагатай, харин хөрвүүлсэн
кодыг ажиллуулахад Java runtime шаардлагатай.

### Яагаад өөр компьютерт ажиллаж болдог вэ?

`javac`-аар үүссэн `.class` bytecode нь шууд нэг төрлийн процессорын машин
код биш. Тохирох Java runtime байгаа Windows, macOS эсвэл Linux компьютер
нэг bytecode-ийг ажиллуулж чадна. Өөрөөр хэлбэл **Java bytecode нь олон
платформд нийтлэг**, харин тухайн системд тохирох **JVM нь платформд
зориулагдсан** байдаг. Энэ нь Java-г “нэг удаа хөрвүүлээд, тохирох runtime
дээр олон платформд ажиллуулах” боломжтой болгодог.
