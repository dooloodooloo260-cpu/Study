leet.java КОДЫН ТАЙЛБАР
=======================

Энэ програм Zigzag Conversion бодлогыг шийднэ. Өгсөн тэмдэгт мөрийн үсгүүдийг
тодорхой тооны мөрөөр доош, дараа нь дээш чиглэн зигзаг хэлбэрээр байрлуулж,
мөр бүрийг дээрээс доош залгаад буцаана.


1. JAVA ТЭМДЭГЛЭГЭЭ БА ТҮЛХҮҮР ҮГС
----------------------------------

package
    Класс аль багцад хамаарахыг зарлана. Энэ файл
    Day_Practices_01.Java_leet_Pratices багцад байна.

public
    Класс эсвэл method-ийг бусад классаас ашиглах боломжтой болгоно.

class
    Java класс зарлана. Энэ жишээнд leet класс үүсгэж байна.

static
    Method-ийг leet объект үүсгэлгүйгээр дуудаж болно.

String
    Тэмдэгт мөрийн төрөл.

int
    Бүхэл тоон төрөл.

void
    Method утга буцаахгүй гэсэн үг. main method үр дүн буцаахгүй.

return
    Method-оос утга буцааж, method-ийн ажиллагааг дуусгана.

new
    Шинэ объект эсвэл массив үүсгэнэ.

if
    Нөхцөл үнэн үед код ажиллуулна.

else if
    Өмнөх if нөхцөл худал үед дараагийн нөхцөлийг шалгана.

for
    Заасан нөхцөл биелж байх үед кодыг давтан ажиллуулна.

null
    Объектын утга байхгүйг илэрхийлнэ.

Хаалт, цэг тэмдэг:

    ;      Нэг Java заавар дууссаныг тэмдэглэнэ.
    {}     Класс, method, давталт, нөхцөлийн кодын хэсгийг хүрээлнэ.
    ()     Method-ийн параметр, аргумент эсвэл нөхцөлийг хүрээлнэ.
    []     Массивын төрлийг зарлах эсвэл индексээр элементэд хандана.
    .      Объект эсвэл классын method, талбарт хандана. Жишээ: s.length()
    ,      Method-ийн аргумент эсвэл параметрүүдийг тусгаарлана.
    " "    String утгын эхлэл ба төгсгөлийг тэмдэглэнэ.
    :      Enhanced for давталтад массивын элементийг ээлжлэн авна.

Операторууд:

    =      Хувьсагчид утга онооно.
    ==     Хоёр утга тэнцүү эсэхийг шалгана.
    !=     Хоёр утга ялгаатай эсэхийг шалгана.
    ||     "Эсвэл": нөхцөлүүдийн аль нэг нь үнэн бол нийт нөхцөл үнэн болно.
    <      Зүүн талын утга баруун талынхаас бага эсэхийг шалгана.
    <=     Бага эсвэл тэнцүү эсэхийг шалгана.
    >=     Их эсвэл тэнцүү эсэхийг шалгана.
    ++     Тоон хувьсагчийг нэгээр нэмнэ. i++ нь i = i + 1-тэй адил.
    +=     Нэмж, үр дүнг тухайн хувьсагчид хадгална.
           row += direction нь row = row + direction-тэй адил.
    -      Хасах үйлдэл. numRows - 1 нь сүүлийн мөрийн индекс.
    -1     Сөрөг нэг. Энэ кодод нэг мөр дээш шилжих чиглэлийг заана.

4. ХУВИРГАХ ШААРДЛАГАГҮЙ ОРОЛТ
-----------------------------

Код:
    if (s == null || s.isEmpty() || numRows <= 1 || numRows >= s.length()) {
        return s;
    }

Нөхцөлүүдийг зүүнээс баруун тийш || буюу "эсвэл" холбоно. Аль нэг нөхцөл
үнэн бол эх мөрийг өөрчлөлгүй буцаана:

    s == null
        Эх тэмдэгт мөр өгөгдөөгүй.
    s.isEmpty()
        Эх мөр хоосон.
    numRows <= 1
        Нэг эсвэл түүнээс цөөн мөр хүссэн тул зигзаг үүсэхгүй.
    numRows >= s.length()
        Мөрийн тоо тэмдэгтийн тооноос багагүй тул тэмдэгт бүр өөрийн мөрөнд
        орно. Дахин байрлуулах шаардлагагүй.

return s нь өгсөн мөрийг буцааж, convert method-ийг дуусгана.


5. МӨР БҮРД StringBuilder БЭЛДЭХ
--------------------------------

Код:
    StringBuilder[] rows = new StringBuilder[numRows];
    for (int i = 0; i < numRows; i++) {
        rows[i] = new StringBuilder();
    }

Тайлбар:
    StringBuilder[]
        StringBuilder объект хадгалах массивын төрөл.
    new StringBuilder[numRows]
        numRows байрлалтай массив үүсгэнэ. Энэ үед байрлал бүрд
        StringBuilder объект хараахан үүсээгүй.
    for (int i = 0; i < numRows; i++)
        i хувьсагч 0-ээс эхэлнэ. i < numRows байх бүрд давталт ажиллана.
        Давталт бүрийн дараа i++ нь i-г нэгээр нэмнэ.
    rows[i]
        rows массивын i индекстэй байрлал. Java массивын индекс 0-ээс эхэлдэг.
    new StringBuilder()
        Тухайн мөрийн тэмдэгтүүдийг залгах хоосон сав үүсгэнэ.

Ингэснээр зигзагийн мөр бүрд тусдаа StringBuilder бэлэн болно.


6. ОДООГИЙН МӨР БА ЧИГЛЭЛ
-------------------------

Код:
    int row = 0;
    int direction = 1;

Тайлбар:
    row
        Дараагийн тэмдэгтийг аль мөрөнд бичихийг заана. Эхний мөрийн индекс 0.
    direction
        Дараагийн алхамд хэдээр хөдлөхийг заана:
            1  = нэг мөр доош
           -1  = нэг мөр дээш


7. ТЭМДЭГТҮҮДИЙГ ЗИГЗАГ МӨРҮҮДЭД ХУВААРИЛАХ
-------------------------------------------

Код:
    for (int i = 0; i < s.length(); i++) {
        rows[row].append(s.charAt(i));

        if (row == 0) {
            direction = 1;
        } else if (row == numRows - 1) {
            direction = -1;
        }

        row += direction;
    }

Тайлбар:
    s.length()
        Эх мөрийн тэмдэгтийн тоог өгнө.
    i
        0-ээс эхлээд тэмдэгт бүрийн индекс болно.
    s.charAt(i)
        Эх мөрийн i индекст байгаа тэмдэгтийг авна.
    rows[row]
        Одоогоор бичиж буй мөрийн StringBuilder.
    .append(...)
        Тэмдэгтийг тухайн мөрийн төгсгөлд залгана.
    row == 0
        Эхний мөрөнд хүрсэн эсэхийг шалгана. Хүрсэн бол доош явах чиглэл
        тогтоож direction = 1 болгоно.
    row == numRows - 1
        Хамгийн сүүлийн мөрөнд хүрсэн эсэхийг шалгана. Индекс 0-ээс эхэлдэг
        тул сүүлийн мөрийн индекс numRows - 1 байна. Хүрсэн бол дээш явах
        чиглэл тогтоож direction = -1 болгоно.
    row += direction
        Дараагийн тэмдэгт орох мөрийн дугаарыг шинэчилнэ.

3 мөртэй үед мөрийн индексүүд ийм дарааллаар явна:

    0 -> 1 -> 2 -> 1 -> 0 -> 1 -> 2 -> ...

PAYPALISHIRING мөрийг 3 мөрөөр байрлуулбал:

    P   A   H   N
    A P L S I I G
    Y   I   R

Зайнууд зөвхөн зигзагийг харуулахын тулд тавигдсан. Код зай нэмэхгүй.


8. МӨРҮҮДИЙГ НЭГ ҮР ДҮН БОЛГОХ
-------------------------------

Код:
    StringBuilder result = new StringBuilder();
    for (StringBuilder currentRow : rows) {
        result.append(currentRow);
    }
    return result.toString();

Тайлбар:
    result
        Эцсийн хариуг залгаж цуглуулах хоосон StringBuilder.
    for (StringBuilder currentRow : rows)
        rows массивын мөр бүрийг дарааллаар нь currentRow хувьсагчид авна.
        : тэмдэгтийн баруун талд давтах массив, зүүн талд элементийн төрөл
        болон тухайн элементийг хадгалах хувьсагч байна.
    result.append(currentRow)
        Тухайн мөрийн тэмдэгтүүдийг эцсийн үр дүнд залгана.
    toString()
        StringBuilder-ийн агуулгыг String төрөл болгон буцаана.
    return
        Бэлэн болсон String үр дүнг convert method-оос буцаана.

3 мөртэй жишээнд мөрүүдийн агуулга:
    Эхний мөр:   PAHN
    Хоёр дахь:   APLSIIG
    Гурав дахь:  YIR

Нэгтгэсэн хариу: PAHNAPLSIIGYIR

Тайлбар:
    main

    String[] args

        Үр дүнг терминалд хэвлээд дараагийн мөр рүү шилжинэ.

    Таслал
        Эх мөр болон мөрийн тоо гэсэн аргументуудыг тусгаарлана.
    Давхар хашилт
        String утгыг эхлүүлж, төгсгөнө.

Хүлээгдэх гаралт:

    PAHNAPLSIIGYIR
    PINALSIGYAHRPI


10. ХУГАЦАА БА САНАХ ОЙ
-----------------------

Эх мөрийн уртыг n, мөрийн тоог r гэе.

    Хугацаа: O(n + r)
        Тэмдэгт бүрийг нэг удаа мөрөнд хийж, мөрүүдийг нийлүүлнэ.

    Нэмэлт санах ой: O(n + r)
        rows массивт r мөр, үр дүнд n хүртэл тэмдэгт хадгална.

    mkdir -p /tmp/leet-java-build
    javac -d /tmp/leet-java-build Day_Practices_01/Java_leet_Pratices/leet.java

Package-тай class ажиллуулахдаа бүтэн package болон class нэрийг цэгээр холбоно.


12. ЭНЭ КОДЫГ ӨӨРӨӨ БИЧИЖ, АШИГЛАХАД ЮУ МЭДЭХ ХЭРЭГТЭЙ ВЭ?
---------------------------------------------------------------

Энэ кодыг ойлгохын тулд Java-г бүхэлд нь мэддэг байх шаардлагагүй. Доорх
ойлголтуудыг дарааллаар нь үзвэл кодыг уншиж, өөрчилж, өөрөө бичихэд хангалттай.

1) Java-ийн үндсэн бичиглэл

    class
        Кодоо класс дотор бичдэг.
    main method
        Програмыг хаанаас эхлүүлэхийг Java-д заана.
    {}
        Кодын хэсгийг эхлүүлж, дуусгана.
    ;
        Ихэнх Java зааврын төгсгөлийг тэмдэглэнэ.
    Том, жижиг үсэг
        Java үсгийн том, жижиг бичлэгийг ялгана. String ба string өөр нэр.

2) Хувьсагч ба төрөл

Энэ кодод:

    String s
        Хувиргах текстийг хадгална.
    int numRows
        Zigzag-д ашиглах мөрийн тоог хадгална.
    int i
        Давталтын тоолуур буюу тэмдэгтийн индекс.
    int row
        Одоогийн мөрийн индекс.
    int direction
        Дараагийн алхамд дээш эсвэл доош явах чиглэл.

Хувьсагчид төрөл оноож зарладаг, дараа нь утга оноодог гэдгийг ойлгоно:

    int row = 0;
    row = row + 1;

3) Нөхцөл ба boolean шалгалт

if, else if, true/false утгыг ойлгох шаардлагатай. Дараах операторууд чухал:

    ==      тэнцүү эсэх
    !=      ялгаатай эсэх
    <       бага эсэх
    <=      бага эсвэл тэнцүү эсэх
    >=      их эсвэл тэнцүү эсэх
    ||      эсвэл

Жишээ:

    if (numRows <= 1) {
        return s;
    }

Энэ нь мөрийн тоо нэг эсвэл түүнээс бага бол эх текстийг шууд буцаа гэсэн үг.

4) Давталт ба индекс

for давталт хэрхэн эхэлж, ямар нөхцөлд үргэлжилж, алхам бүрд тоолуураа
өөрчилдгийг мэднэ:

    for (int i = 0; i < s.length(); i++) {
        // i нь 0, 1, 2, ... гэсэн индексүүдээр өснө.
    }

Java-ийн String болон массивын индекс 0-ээс эхэлнэ. Жишээ нь "ABC" мөрөнд:

    индекс:   0  1  2
    тэмдэгт:  A  B  C

s.charAt(i) нь i индекс дээрх нэг тэмдэгтийг авна. Хүчинтэй индекс нь 0-ээс
s.length() - 1 хүртэл байна.

5) Массив

Массив нь ижил төрлийн олон утгыг дараалсан индексээр хадгалдаг бүтэц. Энэ
кодын StringBuilder[] rows нь мөр бүрийн текстийг хадгалах массив.

    StringBuilder[] rows = new StringBuilder[numRows];
    rows[0] = new StringBuilder();

Массив үүсгэх нь доторх бүх объектыг автоматаар үүсгэхгүй. Тиймээс код
давталтаар rows-ийн байрлал бүрд new StringBuilder() үүсгэж өгдөг.

6) Method ба аргумент

Method нь нэртэй, дахин дуудаж ашиглаж болох кодын хэсэг. convert method хоёр
аргумент авна:

    convert("PAYPALISHIRING", 3)

Энд эхний аргумент нь текст, хоёр дахь аргумент нь мөрийн тоо. Method-ийн
буцаах төрөл String тул үр дүн нь тэмдэгт мөр байна. return нь тэр үр дүнг
дуудсан хэсэгт буцаана.

7) String ба StringBuilder

String нь текст хадгална. charAt(i) нэг тэмдэгт уншиж, length() тэмдэгтийн
тоог өгнө. StringBuilder нь текстийг хэсэг хэсгээр нь үр дүнтэй залгахад
хэрэглэгдэнэ:

    StringBuilder rowText = new StringBuilder();
    rowText.append('P');
    String answer = rowText.toString();

append нь төгсгөлд нэмнэ. toString() нь StringBuilder доторх текстийг String
болгон авна.

8) Алгоритмыг гараар мөрдөх

Код бичихээс өмнө "PAYPALISHIRING" текстийг 3 мөрөөр өөрөө байрлуулж үз:

    P   A   H   N
    A P L S I I G
    Y   I   R

Үсэг бүрийн дараа row болон direction-ийн утга яаж өөрчлөгдөхийг мөрдөхөд
зигзагийн логик ойлгомжтой болно:

    мөрийн индекс: 0 -> 1 -> 2 -> 1 -> 0 -> ...
    чиглэл:        доош     дээш     доош

Энд 0 нь эхний мөр, numRows - 1 нь сүүлийн мөр гэдгийг санаарай.

9) Алдаатай болон захын оролт

Бодит код бичихдээ зөвхөн энгийн жишээг биш дараах тохиолдлыг ч шалгана:

    null текст
    хоосон текст
    нэг мөр хүссэн оролт
    мөрийн тоо текстийн урттай тэнцүү эсвэл түүнээс их байх
    давтагдсан тэмдэгттэй текст

Энэ кодын эхний if нь хувиргалт шаардлагагүй тохиолдлыг эрт буцааж,
массивын индекс хязгаараас гарахаас хамгаалдаг.

10) Компайл хийх ба ажиллуулах

JDK суусан байх хэрэгтэй. Package зарласан Java файлыг ажиллуулахдаа эх
кодын замыг зөв зааж хөрвүүлээд, package болон class-ийн бүтэн нэрээр
ажиллуулна. Энэ тэмдэглэлийн 11-р хэсэгт ашиглах командууд бий.

-----------------------

    3. if, else if болон харьцуулах операторууд
    4. for давталт, тоолуур, 0-ээс эхлэх индекс
    5. String.length() ба String.charAt(index)
    6. массив үүсгэх, индексээр элемент унших/өөрчлөх
    7. method, параметр, аргумент, return
    8. StringBuilder, append(), toString()
    9. кодыг гараар мөрдөх, захын оролтыг тестлэх
    10. javac-аар хөрвүүлэх, java командаар ажиллуулах

Өөрөө бичихээсээ өмнө дээрх алхам бүрийг жижиг жишээгээр туршаарай. Харин
кодыг зөвхөн ажиллуулахын тулд эдгээрийг бүгдийг урьдчилан бүрэн эзэмших
шаардлагагүй: эхлээд ажиллуулаад, дараа нь нэг нэг хэсгийг нь ойлгон өөрчилж
болно.


13. КОД СУРАХАД ҮР ДҮНТЭЙ АРГА
-------------------------------

Хамгийн үр дүнтэй арга бол зөвхөн уншиж, хуулж бичих биш, кодыг өөрөө
таамаглаж, бичиж, ажиллуулж, алдааг нь засаж, дараа нь тайлбарлаж сурах юм.
Дараах давталтыг нэг хичээл бүрд хэрэглээрэй:

    ОЙЛГО -> ТААМАГЛА -> БИЧ -> АЖИЛЛУУЛ -> ШАЛГА -> ТАЙЛБАРЛА -> ДАВТ

1. Нэг удаад нэг жижиг ойлголт сур

    Жишээ нь эхлээд for давталтыг сур. Дараа нь String индекс, дараа нь
    массив, дараа нь StringBuilder-ийг нэм. Бүх кодыг нэг дор цээжлэх гэж
    бүү оролд.

2. Кодоо ажиллуулахаас өмнө үр дүнг таамагла

    convert("PAYPALISHIRING", 3) юу буцаахыг цаасан дээр таамагла.
    Дараа нь ажиллуулж таамгаа шалга. Алдсан бол яагаад алдсанаа ол.
    Ингэснээр кодыг уншаад үр дүнг төсөөлөх чадвар хөгжнө.

3. Кодыг гараар мөрдөж бич

    Жижиг оролт сонго. Жишээ нь "ABCDE", 3.
    Давталтын алхам бүрд дараах утгуудыг хүснэгтэд тэмдэглэ:

        тэмдэгт | i | row | direction | rows-ийн агуулга

    Ингэснээр индекс, чиглэл, нөхцөлүүд хэрхэн хамт ажиллаж байгааг харна.

4. Харахгүйгээр өөрөө бич

    Тайлбар болон бэлэн кодоо түр хаагаад алгоритмыг өөрийн үгээр бич:
        а. Оролт тохиромжгүй бол шууд буцаа.
        б. Мөр тус бүрийн текст хадгалах сав үүсгэ.
        в. Тэмдэгт бүрийг одоогийн мөрөнд нэм.
        г. Дээд/доод захад хүрэхэд чиглэлээ соль.
        д. Мөрүүдийг нийлүүлж буцаа.

    Эхлээд псевдокод бичээд, дараа нь Java код болго. Псевдокод гэдэг нь
    программчлалын хэлний нарийн дүрэм ашиглахгүйгээр алгоритмын алхмыг
    энгийн үгээр, дарааллаар нь бичсэн төлөвлөгөө юм. Энэ нь код биш учраас
    Java-ийн цэг таслал, төрөл, хаалтыг ягштал бичих шаардлагагүй.

    Zigzag Conversion-ийн псевдокод:

        Хэрэв текст хоосон эсвэл өөрчлөх шаардлагагүй бол текстийг буцаа.
        Мөрийн тоотой тэнцүү тооны хоосон мөр бэлд.
        Одоогийн мөрийг эхний мөр болго; чиглэлийг доош гэж тохируул.
        Текстийн тэмдэгт бүрийг дарааллаар нь авч үз:
            Тэмдэгтийг одоогийн мөрөнд нэм.
            Хэрэв эхний мөрөнд байвал чиглэлийг доош болго.
            Үгүй бол, сүүлийн мөрөнд байвал чиглэлийг дээш болго.
            Чиглэлийн дагуу дараагийн мөр рүү шилж.
        Бүх мөрийг дээрээс доош залга.
        Үүссэн текстийг буцаа.

    Псевдокодыг бичсэний дараа алхам бүрийг Java хэлний тодорхой бүтцэд
    хөрвүүлнэ. Жишээ нь “тэмдэгт бүрийг авч үз” гэдэг нь for давталт,
    “хэрэв ... бол” гэдэг нь if нөхцөл, “тэмдэгтийг мөрөнд нэм” гэдэг нь
    append() дуудалт болно. Гацвал багахан хугацаанд тэмдэглэлээ харж болно;
    дараа нь дахин хааж өөрөө үргэлжлүүл.

5. Кодыг нэг нэг өөрчлөлтөөр турш

    Дараах өөрчлөлт бүрийн өмнө юу болохыг таамаглаад, дараа нь ажиллуул:
        - мөрийн тоог 3-аас 4 болгох;
        - эх текстийг өөрчлөх;
        - давтагдсан тэмдэгт оруулах;
        - хамгаалалтын if нөхцөлүүдийн нэгийг түр өөрчлөх;
        - мөрийн индексийн шинэчлэлтийг ажиглах.

    Нэг дор олон өөрчлөлт хийхгүй. Тэгвэл аль өөрчлөлт ямар үр дүн
    гаргасныг ойлгоход амар.

6. Захын тохиолдлуудыг өөрөө сонгож шалга

    Энгийн жишээнээс гадна хоосон мөр, нэг мөртэй оролт, мөрийн тоо текстийн
    урттай тэнцүү оролтыг шалга. Оролт бүрд програм ямар үр дүн өгөх ёстойг
    эхлээд шийдээд, дараа нь кодын үр дүнтэй харьцуул.

7. Алдааг өөрөө оношло

    Алдаа гарвал:
        - алдааны мессежийг бүтнээр унш;
        - заасан файл, мөр, тэмдэгтийг ол;
        - саяхан өөрчилсөн кодоо шалга;
        - нэг удаад нэг засвар хийж дахин ажиллуул.

    Алдааг хараад кодоо шууд бүхэлд нь солиулахын оронд эхлээд өөрөө шалтгааныг
    тайлбарлахыг оролд. Тэгвэл дараагийн удаа ижил алдааг бие даан засаж чадна.

8. Өөрийн үгээр тайлбарла

    Кодыг хүн бүр мөрөөр нь харахгүй байсан ч "row юуг хадгалдаг вэ?",
    "direction яагаад 1 эсвэл -1 болдог вэ?", "numRows - 1 яагаад сүүлийн
    мөрийн индекс вэ?" гэсэн асуултад хариулж чаддаг бол ойлгосны шинж.

9. Давтаж бататга

    Өнөөдөр сурсан кодоо маргааш бэлэн шийдлийг харалгүй дахин бич.
    Хэд хоногийн дараа дахин бод. Санахгүй байвал шууд цээжлэх гэж зүтгэлгүй,
    ойлгоогүй хэсгээ олж жишээгээр бататга.


14. ЭНЭ КОДОД ЗОРИУЛСАН 30 МИНУТЫН ДАДЛАГА
-----------------------------------------

    0-5 минут:
        Кодыг уншаад convert method-ийн оролт, гаралт, зорилгыг өөрийн
        үгээр тэмдэглэ.

    5-10 минут:
        "ABCDE", 3 оролтод тэмдэгт бүр хаашаа орохыг гараар мөрдөж бич.

    10-20 минут:
        Бэлэн кодоо харахгүйгээр convert method-ийг дахин бич.

    20-25 минут:
        Програмыг хөрвүүлж ажиллуулаад, гаралтаа гараар таамагласантай
        харьцуул. Алдааг нэг нэгээр нь зас.

    25-30 минут:
        Өөрийн сонгосон шинэ оролт болон дор хаяж нэг захын тохиолдлыг шалга.
        row, direction, массивын үүргийг чангаар тайлбарла.

Дадлагын зорилго нь 30 минутад төгс код бичих биш. Харин бодлогоо ойлгох,
алхмаа тайлбарлах, алдаагаа олох чадвараа өдөр бүр сайжруулах юм.
