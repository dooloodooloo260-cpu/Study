# Day 06: LeetCode бодлого

Энд бодлого бүрийн зорилго, ямар төрлийн асуудалд хэрэглэх, бодож эхлэх чиглэлийг Монгол хэлээр товчлов. Оролтын нарийн формат, жишээ, хязгаарлалтыг LeetCode холбоосоос шалгаарай.

Өнөөдрийн 5 бодлого. Бусад өдрийн бодлоготой давхцахгүй.

1. [Next Permutation](https://leetcode.com/problems/next-permutation/) — #31 · Medium
   - **Зорилго:** Өгсөн тоон дарааллыг лексикографийн дараагийн байрлалд шилжүүл; боломжгүй бол өсөхөөр эрэмбэл.
   - **Хэрэглээ:** Давхардал илрүүлэх, хос тааруулах, давтамж тоолох, индексжүүлэхэд.
   - **Бодох чиглэл:** Баруунаас өсөхгүй suffix-ийн өмнөх pivot-ийг олж, дараагийн том утгатай сольж suffix-ийг урвуул.
2. [Longest Valid Parentheses](https://leetcode.com/problems/longest-valid-parentheses/) — #32 · Hard
   - **Зорилго:** Зөв тэнцвэржсэн хаалтын хамгийн урт залгаа хэсгийн уртыг ол.
   - **Хэрэглээ:** Хаалт шалгах, undo, илэрхийлэл задлах болон дараагийн их/бага элементийг олоход.
   - **Бодох чиглэл:** Stack-д нээлтийн индекс хадгалах эсвэл хоёр чиглэлд хаалтын тоолол хийх аргыг ашигла.
3. [Search in Rotated Sorted Array](https://leetcode.com/problems/search-in-rotated-sorted-array/) — #33 · Medium
   - **Зорилго:** Эргүүлсэн эрэмбэлэгдсэн массив дахь зорилтот утгын индексийг O(log n) хугацаанд ол.
   - **Хэрэглээ:** Том хайлтын муж, босго утга, эрэмбэлэгдсэн өгөгдөлд хурдан хайлт хийхэд.
   - **Бодох чиглэл:** Binary search бүрд аль тал эрэмбэлэгдсэнийг тогтоож зорилтот утга орох боломжгүй хагасыг хас.
4. [Find First and Last Position of Element in Sorted Array](https://leetcode.com/problems/find-first-and-last-position-of-element-in-sorted-array/) — #34 · Medium
   - **Зорилго:** Эрэмбэлэгдсэн массиваас зорилтот утгын эхний ба сүүлийн индексийг ол.
   - **Хэрэглээ:** Тайлангийн дараалал, эрэмбэлсэн хайлт, давхцал болон top-K олоход.
   - **Бодох чиглэл:** Зорилтот утгын lower bound ба upper bound-ийг хоёр binary search-ээр ол.
5. [Search Insert Position](https://leetcode.com/problems/search-insert-position/) — #35 · Easy
   - **Зорилго:** Эрэмбэлэгдсэн массивт зорилтот утгыг оруулах ёстой байрлалыг ол.
   - **Хэрэглээ:** Том хайлтын муж, босго утга, эрэмбэлэгдсэн өгөгдөлд хурдан хайлт хийхэд.
   - **Бодох чиглэл:** Эрэмбэлэгдсэн массивын lower bound байрлалыг binary search-ээр ол.
