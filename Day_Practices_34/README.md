# Day 34: LeetCode бодлого

Энд бодлого бүрийн зорилго, ямар төрлийн асуудалд хэрэглэх, бодож эхлэх чиглэлийг Монгол хэлээр товчлов. Оролтын нарийн формат, жишээ, хязгаарлалтыг LeetCode холбоосоос шалгаарай.

Өнөөдрийн 5 бодлого. Бусад өдрийн бодлоготой давхцахгүй.

1. [Binary Search Tree Iterator](https://leetcode.com/problems/binary-search-tree-iterator/) — #173 · Medium
   - **Зорилго:** Модон бүтэц дээр нэрэнд заасан утга, зам, дараалал эсвэл шинжийг ол.
   - **Хэрэглээ:** Файлын хавтас, DOM/JSON зэрэг шаталсан өгөгдөл боловсруулахад.
   - **Бодох чиглэл:** Зүүн/баруун хязгаарын invariant-аа хадгалан binary search хий.
2. [Dungeon Game](https://leetcode.com/problems/dungeon-game/) — #174 · Hard
   - **Зорилго:** Асуудлыг давтагддаг жижиг төлөвүүдэд хувааж боломжийн тоо эсвэл хамгийн сайн үр дүнг ол.
   - **Хэрэглээ:** Олон сонголтоос ашиг/зардал, алхам, замын хамгийн сайн үр дүнг тооцоход.
   - **Бодох чиглэл:** Төлөв, суурь нөхцөл, шилжилтийг бичээд давтагдсан дэд асуудлын хариуг хадгал.
3. [Combine Two Tables](https://leetcode.com/problems/combine-two-tables/) — #175 · Easy
   - **Зорилго:** Өгөгдлийн сангийн хүснэгтүүдээс нэрэнд заасан хэрэглэгч, бүлэг, эрэмбэ эсвэл статистикийг гарга.
   - **Хэрэглээ:** Тайлан, хэрэглэгчийн үйлдлийн статистик, олон хүснэгтийн өгөгдөл нэгтгэхэд.
   - **Бодох чиглэл:** Түлхүүр, бүлэглэлт, JOIN/window function хэрэгтэй эсэхийг ялгаж, NULL ба давхардлыг шалга.
