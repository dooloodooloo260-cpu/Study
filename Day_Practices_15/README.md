# Day 15: LeetCode бодлого

Энд бодлого бүрийн зорилго, ямар төрлийн асуудалд хэрэглэх, бодож эхлэх чиглэлийг Монгол хэлээр товчлов. Оролтын нарийн формат, жишээ, хязгаарлалтыг LeetCode холбоосоос шалгаарай.

Өнөөдрийн 5 бодлого. Бусад өдрийн бодлоготой давхцахгүй.

1. [Minimum Window Substring](https://leetcode.com/problems/minimum-window-substring/) — #76 · Hard
   - **Зорилго:** Боломжит сонголтуудаас нэрэнд заасан хамгийн бага утга, зардал эсвэл алхмыг ол.
   - **Хэрэглээ:** Текст хайлт, өгөгдөл цэвэрлэх, формат шалгах болон хэлний боловсруулалтад.
   - **Бодох чиглэл:** Sliding window ба тэмдэгтийн давтамж хадгал; шаардлага зөрчихөд цонхны зүүн талыг урагшлуул.
2. [Combinations](https://leetcode.com/problems/combinations/) — #77 · Medium
   - **Зорилго:** HashMap/Set ашиглан давтамж, өмнө үзсэн утга эсвэл хурдан хайлтыг удирд.
   - **Хэрэглээ:** Давхардал илрүүлэх, хос тааруулах, давтамж тоолох, индексжүүлэхэд.
   - **Бодох чиглэл:** HashMap/Set-д түлхүүр хадгалж давтамж, өмнө үзсэн утга эсвэл хосыг хурдан шалга.
3. [Subsets](https://leetcode.com/problems/subsets/) — #78 · Medium
   - **Зорилго:** Сонголтуудыг туршиж, нөхцөл зөрчсөн салааг буцааж тайрч хүчинтэй шийдлүүдийг ол.
   - **Хэрэглээ:** Таавар, хослол үүсгэх, хязгаарлалттай байрлуулах асуудалд.
   - **Бодох чиглэл:** Backtracking хийж сонголт бүрийн дараа төлөвөө сэргээ; давхардал болон боломжгүй салааг эрт тайр.
4. [Word Search](https://leetcode.com/problems/word-search/) — #79 · Medium
   - **Зорилго:** Торон үсгүүдийн дотор хөрш нүдээр залгаж өгсөн үг үүсэх эсэхийг шалга.
   - **Хэрэглээ:** Газрын зураг, зураг-пикселийн бүс, торон тоглоомын байрлал тооцоход.
   - **Бодох чиглэл:** BFS/DFS болон visited ашигла; хамгийн богино алхам шаардвал BFS сонго.
5. [Remove Duplicates from Sorted Array II](https://leetcode.com/problems/remove-duplicates-from-sorted-array-ii/) — #80 · Medium
   - **Зорилго:** Нэрэнд заасан элемент эсвэл зангилааг устгаж үлдсэн өгөгдлийг зөв хадгал.
   - **Хэрэглээ:** Тайлангийн дараалал, эрэмбэлсэн хайлт, давхцал болон top-K олоход.
   - **Бодох чиглэл:** Эрэмбэлсний дараа нэг нэвтрэлт, хоёр заагч эсвэл greedy сонголт хийж болохыг шалга.
