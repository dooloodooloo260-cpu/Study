# Day 15: String ба immutable утга

**Түвшин:** Анхан шат  
**Хичээлийн сэдэв:** String ба immutable утга

## Суралцах зүйл

String өөрчлөгддөггүй; дахин оноох ба шинэ объектын ялгаа.

## Java дасгал

Өгүүлбэрийн урт, эхлэл, төгсгөлийг шалга.

## Дууссан гэж үзэх шалгуур

String-ийн аргыг зөв хэрэглэж, утгыг дахин оноохыг ойлго.
