# Day Practices: strict test system

Энэ систем `Day_Practices_01`–`Day_Practices_90` хүртэлх бүх өдрийн
LeetCode дасгалын жагсаалт болон Java curriculum-ийг шалгана:

- 90 өдөр дутуугүй, нэмэлт эсвэл буруу нэртэй өдөргүй байх
- Өдөр бүрийн `README.md` зөв өдрийн гарчигтай, яг 5 дугаарласан бодлоготой байх
- Бодлого бүр нэр, эерэг дугаар, LeetCode-ийн зөв форматтай холбоос,
  `Easy`/`Medium`/`Hard` түвшинтэй байх
- 450 бодлогын дугаар, slug, нэр хоорондоо давхцахгүй байх
- Java хичээл яг 90, бүх өдрийн сэдэв нь төлөвлөгөөтэй таарах
- Java түвшин анхан 23, дунд 23, ахисан 22, мэргэжлийн 22 өдөр байх
- Day 29-ийн таван Java шийдэл компайлдаж, үндсэн жишээ болон edge case-уудыг
  зөв ажиллуулах

## Ажиллуулах

Repository-ийн үндсэн хавтаснаас Python 3 болон Java JDK суулгасан орчинд:

```sh
python3 -m unittest discover -s Day_Practices_all_test -v
```

Тестийн тайланд амжилтгүй болсон өдрийн хавтас, мөр, шалгалтыг харуулна.
Java компайл хийсэн файлуудыг түр хавтсанд үүсгээд автоматаар цэвэрлэнэ.

90 өдрийн Java хичээлийг дахин үүсгэх:

```sh
python3 Day_Practices_all_test/java_curriculum.py --write
```
