# Day 25: LeetCode бодлого

Энд бодлого бүрийн зорилго, ямар төрлийн асуудалд хэрэглэх, бодож эхлэх чиглэлийг Монгол хэлээр товчлов. Оролтын нарийн формат, жишээ, хязгаарлалтыг LeetCode холбоосоос шалгаарай.

Өнөөдрийн 5 бодлого. Бусад өдрийн бодлоготой давхцахгүй.

1. [Word Ladder II](https://leetcode.com/problems/word-ladder-ii/) — #126 · Hard
   - **Зорилго:** Орой ба холбоосоос хүрэх боломж, бүлэг, зам эсвэл зөв дарааллыг тогтоо.
   - **Хэрэглээ:** Замын сүлжээ, хэрэглэгчдийн холбоо, ажлын хамаарал болон чиглүүлэлтэд.
   - **Бодох чиглэл:** BFS/DFS болон visited ашигла; хамгийн богино алхам шаардвал BFS сонго.
2. [Word Ladder](https://leetcode.com/problems/word-ladder/) — #127 · Hard
   - **Зорилго:** Орой ба холбоосоос хүрэх боломж, бүлэг, зам эсвэл зөв дарааллыг тогтоо.
   - **Хэрэглээ:** Замын сүлжээ, хэрэглэгчдийн холбоо, ажлын хамаарал болон чиглүүлэлтэд.
   - **Бодох чиглэл:** BFS/DFS болон visited ашигла; хамгийн богино алхам шаардвал BFS сонго.
3. [Longest Consecutive Sequence](https://leetcode.com/problems/longest-consecutive-sequence/) — #128 · Medium
   - **Зорилго:** Массив дахь залгаа бүхэл тоонуудын хамгийн урт дарааллын уртыг ол.
   - **Хэрэглээ:** Давхардал илрүүлэх, хос тааруулах, давтамж тоолох, индексжүүлэхэд.
   - **Бодох чиглэл:** Set-д утгуудыг хадгалж зөвхөн дарааллын эхлэл бүрээс өсгөж тоол.
4. [Sum Root to Leaf Numbers](https://leetcode.com/problems/sum-root-to-leaf-numbers/) — #129 · Medium
   - **Зорилго:** Нэрэнд заасан элементүүдийн нийлбэрийг зорилтот нөхцөлтэй уялдуулан ол.
   - **Хэрэглээ:** Файлын хавтас, DOM/JSON зэрэг шаталсан өгөгдөл боловсруулахад.
   - **Бодох чиглэл:** Рекурсив DFS-ийн буцаах утгаа тодорхойлж, хоосон мод ба навчийг тусад нь шалга.
5. [Surrounded Regions](https://leetcode.com/problems/surrounded-regions/) — #130 · Medium
   - **Зорилго:** Торон хүснэгтийн нүд, хөршийн холбоонд хайлт, тоолол эсвэл замын үр дүнг ол.
   - **Хэрэглээ:** Газрын зураг, зураг-пикселийн бүс, торон тоглоомын байрлал тооцоход.
   - **Бодох чиглэл:** Хөрш нүднүүдийг BFS/DFS-ээр шалгаж visited тэмдэглэ; хил ба диагоналийн дүрмийг нягтал.
