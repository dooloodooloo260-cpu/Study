# Day 12: LeetCode бодлого

Энд бодлого бүрийн зорилго, ямар төрлийн асуудалд хэрэглэх, бодож эхлэх чиглэлийг Монгол хэлээр товчлов. Оролтын нарийн формат, жишээ, хязгаарлалтыг LeetCode холбоосоос шалгаарай.

Өнөөдрийн 5 бодлого. Бусад өдрийн бодлоготой давхцахгүй.

1. [Rotate List](https://leetcode.com/problems/rotate-list/) — #61 · Medium
   - **Зорилго:** Холбоост жагсаалтыг баруун тийш k байрлалаар эргүүл.
   - **Хэрэглээ:** Дараалсан өгөгдөлд оруулах/устгах, холбоос урвуулах болон жагсаалтыг алхахад.
   - **Бодох чиглэл:** Заагчийн өмнөх/дараах холбоог тэмдэглэж, өөрчлөхөөс өмнө дараагийн зангилааг хадгал.
2. [Unique Paths](https://leetcode.com/problems/unique-paths/) — #62 · Medium
   - **Зорилго:** Торон хүснэгтийн нүд, хөршийн холбоонд хайлт, тоолол эсвэл замын үр дүнг ол.
   - **Хэрэглээ:** Газрын зураг, зураг-пикселийн бүс, торон тоглоомын байрлал тооцоход.
   - **Бодох чиглэл:** BFS/DFS болон visited ашигла; хамгийн богино алхам шаардвал BFS сонго.
3. [Unique Paths II](https://leetcode.com/problems/unique-paths-ii/) — #63 · Medium
   - **Зорилго:** Торон хүснэгтийн нүд, хөршийн холбоонд хайлт, тоолол эсвэл замын үр дүнг ол.
   - **Хэрэглээ:** Газрын зураг, зураг-пикселийн бүс, торон тоглоомын байрлал тооцоход.
   - **Бодох чиглэл:** BFS/DFS болон visited ашигла; хамгийн богино алхам шаардвал BFS сонго.
4. [Minimum Path Sum](https://leetcode.com/problems/minimum-path-sum/) — #64 · Medium
   - **Зорилго:** Боломжит сонголтуудаас нэрэнд заасан хамгийн бага утга, зардал эсвэл алхмыг ол.
   - **Хэрэглээ:** Газрын зураг, зураг-пикселийн бүс, торон тоглоомын байрлал тооцоход.
   - **Бодох чиглэл:** BFS/DFS болон visited ашигла; хамгийн богино алхам шаардвал BFS сонго.
5. [Valid Number](https://leetcode.com/problems/valid-number/) — #65 · Hard
   - **Зорилго:** Өгсөн өгөгдөл нэрэнд заасан дүрэм, бүтэц эсвэл нөхцөлийг хангаж байгаа эсэхийг шалга.
   - **Хэрэглээ:** Текст хайлт, өгөгдөл цэвэрлэх, формат шалгах болон хэлний боловсруулалтад.
   - **Бодох чиглэл:** Тэмдэгтүүдийг зүүнээс баруун тийш төлөвтэй уншиж, тэмдэг/цифр/тусгаарлагчийн дүрмийг шалга.
