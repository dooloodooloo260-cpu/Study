# Day 73: LeetCode бодлого

Энд бодлого бүрийн зорилго, ямар төрлийн асуудалд хэрэглэх, бодож эхлэх чиглэлийг Монгол хэлээр товчлов. Оролтын нарийн формат, жишээ, хязгаарлалтыг LeetCode холбоосоос шалгаарай.

Өнөөдрийн 5 бодлого. Бусад өдрийн бодлоготой давхцахгүй.

1. [K-th Smallest in Lexicographical Order](https://leetcode.com/problems/k-th-smallest-in-lexicographical-order/) — #440 · Hard
   - **Зорилго:** Орой ба холбоосоос хүрэх боломж, бүлэг, зам эсвэл зөв дарааллыг тогтоо.
   - **Хэрэглээ:** Замын сүлжээ, хэрэглэгчдийн холбоо, ажлын хамаарал болон чиглүүлэлтэд.
   - **Бодох чиглэл:** BFS/DFS болон visited ашигла; хамгийн богино алхам шаардвал BFS сонго.
2. [Arranging Coins](https://leetcode.com/problems/arranging-coins/) — #441 · Easy
   - **Зорилго:** Эрэмбэлэгдсэн өгөгдөл эсвэл боломжит хариунаас зорилтот утга, байрлал, хязгаарыг хай.
   - **Хэрэглээ:** Том хайлтын муж, босго утга, эрэмбэлэгдсэн өгөгдөлд хурдан хайлт хийхэд.
   - **Бодох чиглэл:** Хариуны боломжит мужид monotonic нөхцөл байгаа эсэхийг шалгаад binary search хэрэглэ.
3. [Find All Duplicates in an Array](https://leetcode.com/problems/find-all-duplicates-in-an-array/) — #442 · Medium
   - **Зорилго:** Өгөгдлөөс зорилтот утга, байрлал эсвэл мужийг ол; эхний/сүүлийн тохиолдлыг шаардлагатай бол ялга.
   - **Хэрэглээ:** Давхардал илрүүлэх, хос тааруулах, давтамж тоолох, индексжүүлэхэд.
   - **Бодох чиглэл:** HashMap/Set-д түлхүүр хадгалж давтамж, өмнө үзсэн утга эсвэл хосыг хурдан шалга.
4. [String Compression](https://leetcode.com/problems/string-compression/) — #443 · Medium
   - **Зорилго:** Текстийн тэмдэгт, хэсэг эсвэл дүрмийг шалгаж нэрэнд заасан үр дүнг гарга.
   - **Хэрэглээ:** Текст хайлт, өгөгдөл цэвэрлэх, формат шалгах болон хэлний боловсруулалтад.
   - **Бодох чиглэл:** Тэмдэг бүрийг нэг удаа боловсруулах боломжийг хайж, давтамж эсвэл индекс хадгал.
5. [Add Two Numbers II](https://leetcode.com/problems/add-two-numbers-ii/) — #445 · Medium
   - **Зорилго:** Цифрүүдийг урагшаа хадгалсан хоёр холбоост тоог нэмж шинэ жагсаалтаар илэрхийл.
   - **Хэрэглээ:** Дараалсан өгөгдөлд оруулах/устгах, холбоос урвуулах болон жагсаалтыг алхахад.
   - **Бодох чиглэл:** Нэг нэг цифрийг нэмээд carry-г дараагийн байрлалд дамжуул; жагсаалтуудын урт ялгаатайг шалга.
