# Day 22: Объектын тэнцүү байдал

**Хичээлийн сэдэв:** Объектын тэнцүү байдал

## Суралцах зүйл

Reference equality ба утгын equality; equals/hashCode ойлголт.

## Java дасгал

Өөр ижил утгатай хоёр объектын == болон equals үр дүнг шалга.

## Дууссан гэж үзэх шалгуур

Identity ба logical equality-г андуурахгүй тайлбарла.
