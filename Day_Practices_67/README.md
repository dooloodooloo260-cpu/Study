# Day 67: LeetCode бодлого

Энд бодлого бүрийн зорилго, ямар төрлийн асуудалд хэрэглэх, бодож эхлэх чиглэлийг Монгол хэлээр товчлов. Оролтын нарийн формат, жишээ, хязгаарлалтыг LeetCode холбоосоос шалгаарай.

Өнөөдрийн 5 бодлого. Бусад өдрийн бодлоготой давхцахгүй.

1. [Binary Watch](https://leetcode.com/problems/binary-watch/) — #401 · Easy
   - **Зорилго:** Тоог хоёртын дүрслэлд хувирган битийн түвшинд нэрэнд заасан тооцоог хий.
   - **Хэрэглээ:** Flag/permission багцлах, битэн төлөв хадгалах, хурдан XOR тооцоонд.
   - **Бодох чиглэл:** XOR, AND, OR, shift оператор ашиглан бит тус бүрийн төлөвийг тооц.
2. [Remove K Digits](https://leetcode.com/problems/remove-k-digits/) — #402 · Medium
   - **Зорилго:** Тоон мөрөөс k цифр устгаж үүсэх хамгийн бага тоог ол.
   - **Хэрэглээ:** Хаалт шалгах, undo, илэрхийлэл задлах болон дараагийн их/бага элементийг олоход.
   - **Бодох чиглэл:** Monotonic stack ашиглан өмнөх боломжгүй сонголтыг pop хийж, дараагийн илүү тохирох утгыг хадгал.
3. [Frog Jump](https://leetcode.com/problems/frog-jump/) — #403 · Hard
   - **Зорилго:** Асуудлыг давтагддаг жижиг төлөвүүдэд хувааж боломжийн тоо эсвэл хамгийн сайн үр дүнг ол.
   - **Хэрэглээ:** Олон сонголтоос ашиг/зардал, алхам, замын хамгийн сайн үр дүнг тооцоход.
   - **Бодох чиглэл:** Төлөв, суурь нөхцөл, шилжилтийг бичээд давтагдсан дэд асуудлын хариуг хадгал.
4. [Sum of Left Leaves](https://leetcode.com/problems/sum-of-left-leaves/) — #404 · Easy
   - **Зорилго:** Нэрэнд заасан элементүүдийн нийлбэрийг зорилтот нөхцөлтэй уялдуулан ол.
   - **Хэрэглээ:** Жагсаалтын хос, хэсэг, дараалал болон байрлалыг тооцоход.
   - **Бодох чиглэл:** Оролтын хэмжээ, эрэмбэ, давхардалд тулгуурлан HashMap, хоёр заагч, prefix sum эсвэл sliding window-ийг сонго.
5. [Convert a Number to Hexadecimal](https://leetcode.com/problems/convert-a-number-to-hexadecimal/) — #405 · Easy
   - **Зорилго:** Тоог хоёртын дүрслэлд хувирган битийн түвшинд нэрэнд заасан тооцоог хий.
   - **Хэрэглээ:** Flag/permission багцлах, битэн төлөв хадгалах, хурдан XOR тооцоонд.
   - **Бодох чиглэл:** XOR, AND, OR, shift оператор ашиглан бит тус бүрийн төлөвийг тооц.
