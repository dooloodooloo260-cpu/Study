# Day 74: LeetCode бодлого

Энд бодлого бүрийн зорилго, ямар төрлийн асуудалд хэрэглэх, бодож эхлэх чиглэлийг Монгол хэлээр товчлов. Оролтын нарийн формат, жишээ, хязгаарлалтыг LeetCode холбоосоос шалгаарай.

Өнөөдрийн 5 бодлого. Бусад өдрийн бодлоготой давхцахгүй.

1. [Arithmetic Slices II - Subsequence](https://leetcode.com/problems/arithmetic-slices-ii-subsequence/) — #446 · Hard
   - **Зорилго:** Асуудлыг давтагддаг жижиг төлөвүүдэд хувааж боломжийн тоо эсвэл хамгийн сайн үр дүнг ол.
   - **Хэрэглээ:** Олон сонголтоос ашиг/зардал, алхам, замын хамгийн сайн үр дүнг тооцоход.
   - **Бодох чиглэл:** Төлөв, шилжилт, base case-аа бичээд давтагдсан дэд асуудлын хариуг хадгал.
2. [Number of Boomerangs](https://leetcode.com/problems/number-of-boomerangs/) — #447 · Medium
   - **Зорилго:** Өгөгдсөн оролтоос нэрэнд заасан объект эсвэл тохиолдлын тоог тооц.
   - **Хэрэглээ:** Координатын зураглал, огтлолцол, чиглэл болон талбай тооцоход.
   - **Бодох чиглэл:** Цэг бүрээс бусад цэг хүртэлх налалтыг харьцуул; бутархай налалтыг хурааж хадгал.
3. [Find All Numbers Disappeared in an Array](https://leetcode.com/problems/find-all-numbers-disappeared-in-an-array/) — #448 · Easy
   - **Зорилго:** Өгөгдлөөс зорилтот утга, байрлал эсвэл мужийг ол; эхний/сүүлийн тохиолдлыг шаардлагатай бол ялга.
   - **Хэрэглээ:** Давхардал илрүүлэх, хос тааруулах, давтамж тоолох, индексжүүлэхэд.
   - **Бодох чиглэл:** HashMap/Set-д түлхүүр хадгалж давтамж, өмнө үзсэн утга эсвэл хосыг хурдан шалга.
4. [Serialize and Deserialize BST](https://leetcode.com/problems/serialize-and-deserialize-bst/) — #449 · Medium
   - **Зорилго:** Модон бүтэц дээр нэрэнд заасан утга, зам, дараалал эсвэл шинжийг ол.
   - **Хэрэглээ:** Файлын хавтас, DOM/JSON зэрэг шаталсан өгөгдөл боловсруулахад.
   - **Бодох чиглэл:** DFS-ийн буцаах утга юу болохыг тодорхойл; хоосон мод, навчийг шалга.
5. [Delete Node in a BST](https://leetcode.com/problems/delete-node-in-a-bst/) — #450 · Medium
   - **Зорилго:** Нэрэнд заасан элемент эсвэл зангилааг устгаж үлдсэн өгөгдлийг зөв хадгал.
   - **Хэрэглээ:** Файлын хавтас, DOM/JSON зэрэг шаталсан өгөгдөл боловсруулахад.
   - **Бодох чиглэл:** DFS-ийн буцаах утга юу болохыг тодорхойл; хоосон мод, навчийг шалга.
