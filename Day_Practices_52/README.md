# Day 52: LeetCode бодлого

Энд бодлого бүрийн зорилго, ямар төрлийн асуудалд хэрэглэх, бодож эхлэх чиглэлийг Монгол хэлээр товчлов. Оролтын нарийн формат, жишээ, хязгаарлалтыг LeetCode холбоосоос шалгаарай.

Өнөөдрийн 5 бодлого. Бусад өдрийн бодлоготой давхцахгүй.

1. [Bulls and Cows](https://leetcode.com/problems/bulls-and-cows/) — #299 · Medium
   - **Зорилго:** HashMap/Set ашиглан давтамж, өмнө үзсэн утга эсвэл хурдан хайлтыг удирд.
   - **Хэрэглээ:** Давхардал илрүүлэх, хос тааруулах, давтамж тоолох, индексжүүлэхэд.
   - **Бодох чиглэл:** HashMap/Set-д түлхүүр хадгалж давтамж, өмнө үзсэн утга эсвэл хосыг хурдан шалга.
2. [Longest Increasing Subsequence](https://leetcode.com/problems/longest-increasing-subsequence/) — #300 · Medium
   - **Зорилго:** Нэрэнд заасан нөхцөлийг хангах хамгийн урт/богино хэсэг, зам эсвэл дарааллыг ол.
   - **Хэрэглээ:** Олон сонголтоос ашиг/зардал, алхам, замын хамгийн сайн үр дүнг тооцоход.
   - **Бодох чиглэл:** Төлөв, шилжилт, base case-аа бичээд давтагдсан дэд асуудлын хариуг хадгал.
3. [Remove Invalid Parentheses](https://leetcode.com/problems/remove-invalid-parentheses/) — #301 · Hard
   - **Зорилго:** Нэрэнд заасан элемент эсвэл зангилааг устгаж үлдсэн өгөгдлийг зөв хадгал.
   - **Хэрэглээ:** Хаалт шалгах, undo, илэрхийлэл задлах болон дараагийн их/бага элементийг олоход.
   - **Бодох чиглэл:** Stack-д нээгдсэн хаалтыг хадгалж хаагдах бүрд төрөл ба дарааллыг шалга.
4. [Range Sum Query - Immutable](https://leetcode.com/problems/range-sum-query-immutable/) — #303 · Easy
   - **Зорилго:** Нэрэнд заасан элементүүдийн нийлбэрийг зорилтот нөхцөлтэй уялдуулан ол.
   - **Хэрэглээ:** Жагсаалтын хос, хэсэг, дараалал болон байрлалыг тооцоход.
   - **Бодох чиглэл:** Оролтын хэмжээ, эрэмбэ, давхардалд тулгуурлан HashMap, хоёр заагч, prefix sum эсвэл sliding window-ийг сонго.
5. [Range Sum Query 2D - Immutable](https://leetcode.com/problems/range-sum-query-2d-immutable/) — #304 · Medium
   - **Зорилго:** Нэрэнд заасан элементүүдийн нийлбэрийг зорилтот нөхцөлтэй уялдуулан ол.
   - **Хэрэглээ:** Жагсаалтын хос, хэсэг, дараалал болон байрлалыг тооцоход.
   - **Бодох чиглэл:** Оролтын хэмжээ, эрэмбэ, давхардалд тулгуурлан HashMap, хоёр заагч, prefix sum эсвэл sliding window-ийг сонго.
