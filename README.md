### Java ба шийдэгдээгүй асуудлууд

Зарим асуудал Java-аар хараахан шийдэгдээгүйдээ биш, ямар ч програмчлалын
хэлээр бүх тохиолдолд шийдэх боломжгүй эсвэл одоогоор нээлттэй хэвээр байдаг.

- **Halting Problem:** дурын програм дурын оролт дээр зогсох эсэхийг бүх
  тохиолдолд зөв шийдэх алгоритм байхгүй. Java-аар тодорхой програмыг ажиллуулах,
  тестлэх, хязгаартай нөхцөлд шинжлэх боломжтой; бүх програмын хувьд бүрэн
  шийдэх боломжгүй.
- **P vs NP:** математик болон компьютерийн шинжлэх ухаанд нээлттэй асуудал.
  Java дээр туршилт хийх нь асуудлыг ерөнхийд нь баталж шийдсэн гэсэн үг биш.
- **Бүх програмыг төгс баталгаажуулах:** тодорхой хязгаар, дүрэмтэй програмд
  тест болон формал аргаар баталгаа гаргаж болно. Харин дурын програмын бүх
  оролтод алдаагүй гэдгийг автоматаар батлах ерөнхий арга байхгүй.

Аюулгүй ажиллагаа, тод байдлыг Java-аар дадлагажуулах боломжит төслүүд:

1. **Нууцлалыг хүндэтгэсэн сургалтын апп:** хэрэгцээтэй хамгийн бага өгөгдөл
   цуглуулж, юу хадгалж байгаагаа хэрэглэгчид тайлбарлах.
2. **Ил тод үйлдлийн бүртгэл:** сургалтын ахицад гарсан өөрчлөлт, өгөгдөл
   синк болсон эсэхийг хэрэглэгчид ойлгомжтой харуулах.
3. **Хамгаалалтын шалгах хэрэгсэл:** өөрийн Java төслүүдэд нууц түлхүүр
   санамсаргүй commit-д орсон эсэх, SQL query параметрлэгдсэн эсэх зэрэг
   урьдчилан тогтоосон эрсдэлийг илрүүлж, шалгах зөвлөмж өгөх.

Эдгээр нь хөтөлбөрт хэрэгжсэн боломж биш, цаашид бүтээж турших төслийн санаа юм.
Шалгах хүрээ, хязгаарлалтыг ил тод зааж, хэрэгслийн үр дүнг хүний хяналтаар
баталгаажуулах шаардлагатай.

### Java and unsolved problems

Some challenges are not unsolved because Java has failed to solve them. They
are either impossible to solve for every case with any programming language
or remain open research questions:

- **The Halting Problem:** no algorithm can correctly decide, for every
  arbitrary program and input, whether execution will terminate. Java can run
  and test specific programs or analyze restricted cases, but it cannot solve
  the general problem.
- **P vs NP:** an open question in mathematics and computer science. Running
  experiments in Java does not prove a general solution.
- **Perfectly verifying every program:** testing and formal methods can prove
  properties under defined constraints. There is no general automatic method
  that proves every arbitrary program correct for every possible input.

Potential Java projects for practicing security and transparency:

1. **A privacy-conscious learning app:** collect only necessary data and
   clearly explain what is stored.
2. **A transparent activity log:** show users understandable records of
   learning progress changes and whether data has synced.
3. **A defensive code-checking tool:** inspect your own Java projects for
   predefined risks such as accidentally committed secrets or unparameterized
   SQL queries, then provide actionable guidance.

These are future project ideas, not features already implemented in this
curriculum. Define the checks and their limitations clearly, and have a person
review the results rather than treating the tool as a complete security audit.

problems, and Java source compilation.
