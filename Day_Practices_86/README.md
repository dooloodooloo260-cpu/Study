# Day 86: LeetCode бодлого

Энд бодлого бүрийн зорилго, ямар төрлийн асуудалд хэрэглэх, бодож эхлэх чиглэлийг Монгол хэлээр товчлов. Оролтын нарийн формат, жишээ, хязгаарлалтыг LeetCode холбоосоос шалгаарай.

Өнөөдрийн 5 бодлого. Бусад өдрийн бодлоготой давхцахгүй.

1. [Super Washing Machines](https://leetcode.com/problems/super-washing-machines/) — #517 · Hard
   - **Зорилго:** Одоогийн алхам бүрт зөв сонголт хийж эцсийн боломжит/хамгийн сайн үр дүнд хүр.
   - **Хэрэглээ:** Хуваарь, нөөц хуваарилах, зардал багасгах зэрэг сонголтын асуудалд.
   - **Бодох чиглэл:** Одоогийн хамгийн ашигтай сонголт эцсийн зөв шийдэлд хүргэх нөхцөлийг шалга.
2. [Coin Change II](https://leetcode.com/problems/coin-change-ii/) — #518 · Medium
   - **Зорилго:** Асуудлыг давтагддаг жижиг төлөвүүдэд хувааж боломжийн тоо эсвэл хамгийн сайн үр дүнг ол.
   - **Хэрэглээ:** Олон сонголтоос ашиг/зардал, алхам, замын хамгийн сайн үр дүнг тооцоход.
   - **Бодох чиглэл:** Төлөв, суурь нөхцөл, шилжилтийг бичээд давтагдсан дэд асуудлын хариуг хадгал.
3. [Random Flip Matrix](https://leetcode.com/problems/random-flip-matrix/) — #519 · Medium
   - **Зорилго:** Торон хүснэгтийн нүд, хөршийн холбоонд хайлт, тоолол эсвэл замын үр дүнг ол.
   - **Хэрэглээ:** Газрын зураг, зураг-пикселийн бүс, торон тоглоомын байрлал тооцоход.
   - **Бодох чиглэл:** Хөрш нүднүүдийг BFS/DFS-ээр шалгаж visited тэмдэглэ; хил ба диагоналийн дүрмийг нягтал.
4. [Detect Capital](https://leetcode.com/problems/detect-capital/) — #520 · Easy
   - **Зорилго:** Массив эсвэл тоон дарааллын элементүүдээс нэрэнд заасан үр дүнг олж/өөрчил.
   - **Хэрэглээ:** Жагсаалтын хос, хэсэг, дараалал болон байрлалыг тооцоход.
   - **Бодох чиглэл:** Оролтын хэмжээ, эрэмбэ, давхардалд тулгуурлан HashMap, хоёр заагч, prefix sum эсвэл sliding window-ийг сонго.
5. [Longest Uncommon Subsequence I](https://leetcode.com/problems/longest-uncommon-subsequence-i/) — #521 · Easy
   - **Зорилго:** Нэрэнд заасан нөхцөлийг хангах хамгийн урт/богино хэсэг, зам эсвэл дарааллыг ол.
   - **Хэрэглээ:** Олон сонголтоос ашиг/зардал, алхам, замын хамгийн сайн үр дүнг тооцоход.
   - **Бодох чиглэл:** Төлөв, шилжилт, base case-аа бичээд давтагдсан дэд асуудлын хариуг хадгал.
