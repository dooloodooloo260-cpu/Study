# Day 56: LeetCode бодлого

Энд бодлого бүрийн зорилго, ямар төрлийн асуудалд хэрэглэх, бодож эхлэх чиглэлийг Монгол хэлээр товчлов. Оролтын нарийн формат, жишээ, хязгаарлалтыг LeetCode холбоосоос шалгаарай.

Өнөөдрийн 5 бодлого. Бусад өдрийн бодлоготой давхцахгүй.

1. [Odd Even Linked List](https://leetcode.com/problems/odd-even-linked-list/) — #328 · Medium
   - **Зорилго:** Холбоост жагсаалтын зангилаа, заагчийг ашиглан нэрэнд заасан үйлдлийг хий.
   - **Хэрэглээ:** Дараалсан өгөгдөлд оруулах/устгах, холбоос урвуулах болон жагсаалтыг алхахад.
   - **Бодох чиглэл:** Заагчийн өмнөх/дараах холбоог тэмдэглэж, өөрчлөхөөс өмнө дараагийн зангилааг хадгал.
2. [Longest Increasing Path in a Matrix](https://leetcode.com/problems/longest-increasing-path-in-a-matrix/) — #329 · Hard
   - **Зорилго:** Нэрэнд заасан нөхцөлийг хангах хамгийн урт/богино хэсэг, зам эсвэл дарааллыг ол.
   - **Хэрэглээ:** Газрын зураг, зураг-пикселийн бүс, торон тоглоомын байрлал тооцоход.
   - **Бодох чиглэл:** Хөрш нүднүүдийг BFS/DFS-ээр шалгаж visited тэмдэглэ; хил ба диагоналийн дүрмийг нягтал.
3. [Patching Array](https://leetcode.com/problems/patching-array/) — #330 · Hard
   - **Зорилго:** Одоогийн алхам бүрт зөв сонголт хийж эцсийн боломжит/хамгийн сайн үр дүнд хүр.
   - **Хэрэглээ:** Хуваарь, нөөц хуваарилах, зардал багасгах зэрэг сонголтын асуудалд.
   - **Бодох чиглэл:** Одоогийн хамгийн ашигтай сонголт эцсийн зөв шийдэлд хүргэх нөхцөлийг шалга.
4. [Verify Preorder Serialization of a Binary Tree](https://leetcode.com/problems/verify-preorder-serialization-of-a-binary-tree/) — #331 · Medium
   - **Зорилго:** Модон бүтэц дээр нэрэнд заасан утга, зам, дараалал эсвэл шинжийг ол.
   - **Хэрэглээ:** Файлын хавтас, DOM/JSON зэрэг шаталсан өгөгдөл боловсруулахад.
   - **Бодох чиглэл:** DFS-ийн буцаах утга юу болохыг тодорхойл; хоосон мод, навчийг шалга.
5. [Reconstruct Itinerary](https://leetcode.com/problems/reconstruct-itinerary/) — #332 · Hard
   - **Зорилго:** Орой ба холбоосоос хүрэх боломж, бүлэг, зам эсвэл зөв дарааллыг тогтоо.
   - **Хэрэглээ:** Замын сүлжээ, хэрэглэгчдийн холбоо, ажлын хамаарал болон чиглүүлэлтэд.
   - **Бодох чиглэл:** BFS/DFS болон visited ашигла; хамгийн богино алхам шаардвал BFS сонго.
