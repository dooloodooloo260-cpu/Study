# Day 78: LeetCode бодлого

Энд бодлого бүрийн зорилго, ямар төрлийн асуудалд хэрэглэх, бодож эхлэх чиглэлийг Монгол хэлээр товчлов. Оролтын нарийн формат, жишээ, хязгаарлалтыг LeetCode холбоосоос шалгаарай.

Өнөөдрийн 5 бодлого. Бусад өдрийн бодлоготой давхцахгүй.

1. [Unique Substrings in Wraparound String](https://leetcode.com/problems/unique-substrings-in-wraparound-string/) — #467 · Medium
   - **Зорилго:** Текстийн тэмдэгт, хэсэг эсвэл дүрмийг шалгаж нэрэнд заасан үр дүнг гарга.
   - **Хэрэглээ:** Текст хайлт, өгөгдөл цэвэрлэх, формат шалгах болон хэлний боловсруулалтад.
   - **Бодох чиглэл:** DFS-ийн буцаах утга юу болохыг тодорхойл; хоосон мод, навчийг шалга.
2. [Validate IP Address](https://leetcode.com/problems/validate-ip-address/) — #468 · Medium
   - **Зорилго:** Өгсөн өгөгдөл нэрэнд заасан дүрэм, бүтэц эсвэл нөхцөлийг хангаж байгаа эсэхийг шалга.
   - **Хэрэглээ:** Жагсаалтын хос, хэсэг, дараалал болон байрлалыг тооцоход.
   - **Бодох чиглэл:** Оролтын хэмжээ, эрэмбэ, давхардалд тулгуурлан HashMap, хоёр заагч, prefix sum эсвэл sliding window-ийг сонго.
3. [Implement Rand10() Using Rand7()](https://leetcode.com/problems/implement-rand10-using-rand7/) — #470 · Medium
   - **Зорилго:** Нэрэнд заасан үйлдлүүдийг шаардлагатай хурдтай дэмжих өгөгдлийн бүтцийг загварчил.
   - **Хэрэглээ:** Кэш, индекс, санамсаргүй сонголт, API-ийн төлөв хадгалалтад.
   - **Бодох чиглэл:** Үйлдэл бүрийн хурдны шаардлагад нийцүүлэн бүтцүүдийг хослуулж, шинэчлэлтийн invariants-ийг хадгал.
4. [Concatenated Words](https://leetcode.com/problems/concatenated-words/) — #472 · Hard
   - **Зорилго:** Текстийн тэмдэгт, хэсэг эсвэл дүрмийг шалгаж нэрэнд заасан үр дүнг гарга.
   - **Хэрэглээ:** Текст хайлт, өгөгдөл цэвэрлэх, формат шалгах болон хэлний боловсруулалтад.
   - **Бодох чиглэл:** Тэмдэг бүрийг нэг удаа боловсруулах боломжийг хайж, давтамж эсвэл индекс хадгал.
5. [Matchsticks to Square](https://leetcode.com/problems/matchsticks-to-square/) — #473 · Medium
   - **Зорилго:** Сонголтуудыг туршиж, нөхцөл зөрчсөн салааг буцааж тайрч хүчинтэй шийдлүүдийг ол.
   - **Хэрэглээ:** Таавар, хослол үүсгэх, хязгаарлалттай байрлуулах асуудалд.
   - **Бодох чиглэл:** Сонголт хийж рекурсив шалгаад, буцахдаа төлөвөө сэргээ; боломжгүй салааг эрт тайр.
