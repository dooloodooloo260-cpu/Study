# Day 71: LeetCode бодлого

Энд бодлого бүрийн зорилго, ямар төрлийн асуудалд хэрэглэх, бодож эхлэх чиглэлийг Монгол хэлээр товчлов. Оролтын нарийн формат, жишээ, хязгаарлалтыг LeetCode холбоосоос шалгаарай.

Өнөөдрийн 5 бодлого. Бусад өдрийн бодлоготой давхцахгүй.

1. [Construct Quad Tree](https://leetcode.com/problems/construct-quad-tree/) — #427 · Medium
   - **Зорилго:** Модон бүтэц дээр нэрэнд заасан утга, зам, дараалал эсвэл шинжийг ол.
   - **Хэрэглээ:** Файлын хавтас, DOM/JSON зэрэг шаталсан өгөгдөл боловсруулахад.
   - **Бодох чиглэл:** DFS-ийн буцаах утга юу болохыг тодорхойл; хоосон мод, навчийг шалга.
2. [N-ary Tree Level Order Traversal](https://leetcode.com/problems/n-ary-tree-level-order-traversal/) — #429 · Medium
   - **Зорилго:** Модон бүтэц дээр нэрэнд заасан утга, зам, дараалал эсвэл шинжийг ол.
   - **Хэрэглээ:** Файлын хавтас, DOM/JSON зэрэг шаталсан өгөгдөл боловсруулахад.
   - **Бодох чиглэл:** DFS-ийн буцаах утга юу болохыг тодорхойл; хоосон мод, навчийг шалга.
3. [Flatten a Multilevel Doubly Linked List](https://leetcode.com/problems/flatten-a-multilevel-doubly-linked-list/) — #430 · Medium
   - **Зорилго:** Холбоост жагсаалтын зангилаа, заагчийг ашиглан нэрэнд заасан үйлдлийг хий.
   - **Хэрэглээ:** Дараалсан өгөгдөлд оруулах/устгах, холбоос урвуулах болон жагсаалтыг алхахад.
   - **Бодох чиглэл:** Заагчийн өмнөх/дараах холбоог тэмдэглэж, өөрчлөхөөс өмнө дараагийн зангилааг хадгал.
4. [All O`one Data Structure](https://leetcode.com/problems/all-oone-data-structure/) — #432 · Hard
   - **Зорилго:** Нэрэнд заасан үйлдлүүдийг шаардлагатай хурдтай дэмжих өгөгдлийн бүтцийг загварчил.
   - **Хэрэглээ:** Кэш, индекс, санамсаргүй сонголт, API-ийн төлөв хадгалалтад.
   - **Бодох чиглэл:** Үйлдэл бүрийн хурдны шаардлагад нийцүүлэн бүтцүүдийг хослуулж, шинэчлэлтийн invariants-ийг хадгал.
5. [Minimum Genetic Mutation](https://leetcode.com/problems/minimum-genetic-mutation/) — #433 · Medium
   - **Зорилго:** Боломжит сонголтуудаас нэрэнд заасан хамгийн бага утга, зардал эсвэл алхмыг ол.
   - **Хэрэглээ:** Замын сүлжээ, хэрэглэгчдийн холбоо, ажлын хамаарал болон чиглүүлэлтэд.
   - **Бодох чиглэл:** BFS/DFS болон visited ашигла; хамгийн богино алхам шаардвал BFS сонго.
