# Day 82: LeetCode бодлого

Энд бодлого бүрийн зорилго, ямар төрлийн асуудалд хэрэглэх, бодож эхлэх чиглэлийг Монгол хэлээр товчлов. Оролтын нарийн формат, жишээ, хязгаарлалтыг LeetCode холбоосоос шалгаарай.

Өнөөдрийн 5 бодлого. Бусад өдрийн бодлоготой давхцахгүй.

1. [Reverse Pairs](https://leetcode.com/problems/reverse-pairs/) — #493 · Hard
   - **Зорилго:** Элементүүдийн холбоо, дарааллыг хадгалан өгөгдлийг урвуулах эсвэл дахин байрлуулах үйлдэл хий.
   - **Хэрэглээ:** Тайлангийн дараалал, эрэмбэлсэн хайлт, давхцал болон top-K олоход.
   - **Бодох чиглэл:** Эрэмбэлсний дараа нэг нэвтрэлт, хоёр заагч эсвэл greedy сонголт хийж болохыг шалга.
2. [Target Sum](https://leetcode.com/problems/target-sum/) — #494 · Medium
   - **Зорилго:** Нэрэнд заасан элементүүдийн нийлбэрийг зорилтот нөхцөлтэй уялдуулан ол.
   - **Хэрэглээ:** Жагсаалтын хос, хэсэг, дараалал болон байрлалыг тооцоход.
   - **Бодох чиглэл:** Оролтын хэмжээ, эрэмбэ, давхардалд тулгуурлан HashMap, хоёр заагч, prefix sum эсвэл sliding window-ийг сонго.
3. [Teemo Attacking](https://leetcode.com/problems/teemo-attacking/) — #495 · Easy
   - **Зорилго:** Хугацаа эсвэл интервалуудын давхцал, нэгтгэл, дараалалтай холбоотой үр дүнг ол.
   - **Хэрэглээ:** Цагийн хуваарь, уулзалтын өрөө, нөөцийн захиалга болон event-ийн мужид.
   - **Бодох чиглэл:** Интервалыг эрэмбэлээд давхцах нөхцөлөөр нэгтгэх эсвэл сонгох аргыг хэрэглэ.
4. [Next Greater Element I](https://leetcode.com/problems/next-greater-element-i/) — #496 · Easy
   - **Зорилго:** Stack ашиглан өмнөх төлөв, хаалт эсвэл дараагийн их/бага элементийн хамаарлыг боловсруул.
   - **Хэрэглээ:** Хаалт шалгах, undo, илэрхийлэл задлах болон дараагийн их/бага элементийг олоход.
   - **Бодох чиглэл:** Monotonic stack ашиглан өмнөх боломжгүй сонголтыг pop хийж, дараагийн илүү тохирох утгыг хадгал.
5. [Random Point in Non-overlapping Rectangles](https://leetcode.com/problems/random-point-in-non-overlapping-rectangles/) — #497 · Medium
   - **Зорилго:** Хугацаа эсвэл интервалуудын давхцал, нэгтгэл, дараалалтай холбоотой үр дүнг ол.
   - **Хэрэглээ:** Цагийн хуваарь, уулзалтын өрөө, нөөцийн захиалга болон event-ийн мужид.
   - **Бодох чиглэл:** Интервалыг эрэмбэлээд давхцах нөхцөлөөр нэгтгэх эсвэл сонгох аргыг хэрэглэ.
