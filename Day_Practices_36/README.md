# Day 36: LeetCode бодлого

Энд бодлого бүрийн зорилго, ямар төрлийн асуудалд хэрэглэх, бодож эхлэх чиглэлийг Монгол хэлээр товчлов. Оролтын нарийн формат, жишээ, хязгаарлалтыг LeetCode холбоосоос шалгаарай.

Өнөөдрийн 5 бодлого. Бусад өдрийн бодлоготой давхцахгүй.

1. [Customers Who Never Order](https://leetcode.com/problems/customers-who-never-order/) — #183 · Easy
   - **Зорилго:** Өгөгдлийн сангийн хүснэгтүүдээс нэрэнд заасан хэрэглэгч, бүлэг, эрэмбэ эсвэл статистикийг гарга.
   - **Хэрэглээ:** Тайлан, хэрэглэгчийн үйлдлийн статистик, олон хүснэгтийн өгөгдөл нэгтгэхэд.
   - **Бодох чиглэл:** Түлхүүр, бүлэглэлт, JOIN/window function хэрэгтэй эсэхийг ялгаж, NULL ба давхардлыг шалга.
2. [Department Highest Salary](https://leetcode.com/problems/department-highest-salary/) — #184 · Medium
   - **Зорилго:** Өгөгдлийн сангийн хүснэгтүүдээс нэрэнд заасан хэрэглэгч, бүлэг, эрэмбэ эсвэл статистикийг гарга.

   - **Зорилго:** Өгөгдлийн сангийн хүснэгтүүдээс нэрэнд заасан хэрэглэгч, бүлэг, эрэмбэ эсвэл статистикийг гарга.

4. [Repeated DNA Sequences](https://leetcode.com/problems/repeated-dna-sequences/) — #187 · Medium
   - **Зорилго:** HashMap/Set ашиглан давтамж, өмнө үзсэн утга эсвэл хурдан хайлтыг удирд.
   - **Хэрэглээ:** Давхардал илрүүлэх, хос тааруулах, давтамж тоолох, индексжүүлэхэд.
   - **Бодох чиглэл:** HashMap/Set-д түлхүүр хадгалж давтамж, өмнө үзсэн утга эсвэл хосыг хурдан шалга.
5. [Best Time to Buy and Sell Stock IV](https://leetcode.com/problems/best-time-to-buy-and-sell-stock-iv/) — #188 · Hard
   - **Зорилго:** Массив эсвэл тоон дарааллын элементүүдээс нэрэнд заасан үр дүнг олж/өөрчил.
   - **Хэрэглээ:** Жагсаалтын хос, хэсэг, дараалал болон байрлалыг тооцоход.
   - **Бодох чиглэл:** Төлөв, суурь нөхцөл, шилжилтийг бичээд давтагдсан дэд асуудлын хариуг хадгал.
