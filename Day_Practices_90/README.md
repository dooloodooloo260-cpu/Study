# Day 90: LeetCode бодлого

Энд бодлого бүрийн зорилго, ямар төрлийн асуудалд хэрэглэх, бодож эхлэх чиглэлийг Монгол хэлээр товчлов. Оролтын нарийн формат, жишээ, хязгаарлалтыг LeetCode холбоосоос шалгаарай.

Өнөөдрийн 5 бодлого. Бусад өдрийн бодлоготой давхцахгүй.

1. [01 Matrix](https://leetcode.com/problems/01-matrix/) — #542 · Medium
   - **Зорилго:** Матрицын нүд бүрээс хамгийн ойр 0 хүртэлх Manhattan зайг ол.
   - **Хэрэглээ:** Газрын зураг, зураг-пикселийн бүс, торон тоглоомын байрлал тооцоход.
   - **Бодох чиглэл:** Хөрш нүднүүдийг BFS/DFS-ээр шалгаж visited тэмдэглэ; хил ба диагоналийн дүрмийг нягтал.
2. [Diameter of Binary Tree](https://leetcode.com/problems/diameter-of-binary-tree/) — #543 · Easy
   - **Зорилго:** Хоёр зангилааны хоорондох хамгийн урт замын ирмэгийн тоог модноос ол.
   - **Хэрэглээ:** Файлын хавтас, DOM/JSON зэрэг шаталсан өгөгдөл боловсруулахад.
   - **Бодох чиглэл:** DFS-ийн буцаах утга юу болохыг тодорхойл; хоосон мод, навчийг шалга.
3. [Remove Boxes](https://leetcode.com/problems/remove-boxes/) — #546 · Hard
   - **Зорилго:** Ижил өнгийн хайрцгийг бүлгээр нь устгаж болох онооны хамгийн их утгыг ол.
   - **Хэрэглээ:** Олон сонголтоос ашиг/зардал, алхам, замын хамгийн сайн үр дүнг тооцоход.
   - **Бодох чиглэл:** Төлөв, суурь нөхцөл, шилжилтийг бичээд давтагдсан дэд асуудлын хариуг хадгал.
4. [Number of Provinces](https://leetcode.com/problems/number-of-provinces/) — #547 · Medium
   - **Зорилго:** Холбоосын матрицад шууд болон дам холбоотой хотуудын бүлгийн тоог ол.
   - **Хэрэглээ:** Замын сүлжээ, хэрэглэгчдийн холбоо, ажлын хамаарал болон чиглүүлэлтэд.
   - **Бодох чиглэл:** BFS/DFS болон visited ашигла; хамгийн богино алхам шаардвал BFS сонго.
5. [Game Play Analysis IV](https://leetcode.com/problems/game-play-analysis-iv/) — #550 · Medium
   - **Зорилго:** Тоглогчдын анхны өдрийн дараагийн өдөр дахин тоглосон хувь хэмжээг SQL-ээр тооц.
   - **Хэрэглээ:** Тайлан, хэрэглэгчийн үйлдлийн статистик, олон хүснэгтийн өгөгдөл нэгтгэхэд.
   - **Бодох чиглэл:** Түлхүүр, бүлэглэлт, JOIN/window function хэрэгтэй эсэхийг ялгаж, NULL ба давхардлыг шалга.
