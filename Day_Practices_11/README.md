# Day 11: LeetCode бодлого

Энд бодлого бүрийн зорилго, ямар төрлийн асуудалд хэрэглэх, бодож эхлэх чиглэлийг Монгол хэлээр товчлов. Оролтын нарийн формат, жишээ, хязгаарлалтыг LeetCode холбоосоос шалгаарай.

Өнөөдрийн 5 бодлого. Бусад өдрийн бодлоготой давхцахгүй.

1. [Merge Intervals](https://leetcode.com/problems/merge-intervals/) — #56 · Medium
   - **Зорилго:** Өгөгдлүүдийг нэрэнд заасан эрэмбэ, дүрмийн дагуу нэгтгэ.
   - **Хэрэглээ:** Цагийн хуваарь, уулзалтын өрөө, нөөцийн захиалга болон event-ийн мужид.
   - **Бодох чиглэл:** Эхлэх цэгээр эрэмбэлээд өмнөх интервалтай давхцах эсэхээр нэгтгэ.
2. [Insert Interval](https://leetcode.com/problems/insert-interval/) — #57 · Medium
   - **Зорилго:** Хугацаа эсвэл интервалуудын давхцал, нэгтгэл, дараалалтай холбоотой үр дүнг ол.
   - **Хэрэглээ:** Цагийн хуваарь, уулзалтын өрөө, нөөцийн захиалга болон event-ийн мужид.
   - **Бодох чиглэл:** Эхлэх цэгээр эрэмбэлээд өмнөх интервалтай давхцах эсэхээр нэгтгэ.
3. [Length of Last Word](https://leetcode.com/problems/length-of-last-word/) — #58 · Easy
   - **Зорилго:** Текстийн тэмдэгт, хэсэг эсвэл дүрмийг шалгаж нэрэнд заасан үр дүнг гарга.
   - **Хэрэглээ:** Текст хайлт, өгөгдөл цэвэрлэх, формат шалгах болон хэлний боловсруулалтад.
   - **Бодох чиглэл:** Тэмдэг бүрийг нэг удаа боловсруулах боломжийг хайж, давтамж эсвэл индекс хадгал.
4. [Spiral Matrix II](https://leetcode.com/problems/spiral-matrix-ii/) — #59 · Medium
   - **Зорилго:** Торон хүснэгтийн нүд, хөршийн холбоонд хайлт, тоолол эсвэл замын үр дүнг ол.
   - **Хэрэглээ:** Газрын зураг, зураг-пикселийн бүс, торон тоглоомын байрлал тооцоход.
   - **Бодох чиглэл:** Дээд/доод мөр, зүүн/баруун баганын хилүүдийг үе шаттай нарийсга.
5. [Permutation Sequence](https://leetcode.com/problems/permutation-sequence/) — #60 · Hard
   - **Зорилго:** HashMap/Set ашиглан давтамж, өмнө үзсэн утга эсвэл хурдан хайлтыг удирд.
   - **Хэрэглээ:** Давхардал илрүүлэх, хос тааруулах, давтамж тоолох, индексжүүлэхэд.
   - **Бодох чиглэл:** HashMap/Set-д түлхүүр хадгалж давтамж, өмнө үзсэн утга эсвэл хосыг хурдан шалга.
