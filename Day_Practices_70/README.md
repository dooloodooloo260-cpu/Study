# Day 70: LeetCode бодлого

Энд бодлого бүрийн зорилго, ямар төрлийн асуудалд хэрэглэх, бодож эхлэх чиглэлийг Монгол хэлээр товчлов. Оролтын нарийн формат, жишээ, хязгаарлалтыг LeetCode холбоосоос шалгаарай.

Өнөөдрийн 5 бодлого. Бусад өдрийн бодлоготой давхцахгүй.

1. [Battleships in a Board](https://leetcode.com/problems/battleships-in-a-board/) — #419 · Medium
   - **Зорилго:** Торон хүснэгтийн нүд, хөршийн холбоонд хайлт, тоолол эсвэл замын үр дүнг ол.
   - **Хэрэглээ:** Газрын зураг, зураг-пикселийн бүс, торон тоглоомын байрлал тооцоход.
   - **Бодох чиглэл:** BFS/DFS болон visited ашигла; хамгийн богино алхам шаардвал BFS сонго.
2. [Strong Password Checker](https://leetcode.com/problems/strong-password-checker/) — #420 · Hard
   - **Зорилго:** Текстийн тэмдэгт, хэсэг эсвэл дүрмийг шалгаж нэрэнд заасан үр дүнг гарга.
   - **Хэрэглээ:** Текст хайлт, өгөгдөл цэвэрлэх, формат шалгах болон хэлний боловсруулалтад.
   - **Бодох чиглэл:** Тэмдэг бүрийг нэг удаа боловсруулах боломжийг хайж, давтамж эсвэл индекс хадгал.
3. [Maximum XOR of Two Numbers in an Array](https://leetcode.com/problems/maximum-xor-of-two-numbers-in-an-array/) — #421 · Medium
   - **Зорилго:** Боломжит сонголтуудаас нэрэнд заасан хамгийн их утга эсвэл хэмжээг тооц.
   - **Хэрэглээ:** Flag/permission багцлах, битэн төлөв хадгалах, хурдан XOR тооцоонд.
   - **Бодох чиглэл:** XOR/shift ашиглаж бит тус бүрийн давтамж эсвэл байрлалыг тооц.
4. [Reconstruct Original Digits from English](https://leetcode.com/problems/reconstruct-original-digits-from-english/) — #423 · Medium
   - **Зорилго:** Массив эсвэл тоон дарааллын элементүүдээс нэрэнд заасан үр дүнг олж/өөрчил.
   - **Хэрэглээ:** Жагсаалтын хос, хэсэг, дараалал болон байрлалыг тооцоход.
   - **Бодох чиглэл:** Оролтын хэмжээ, эрэмбэ, давхардалд тулгуурлан HashMap, хоёр заагч, prefix sum эсвэл sliding window-ийг сонго.
5. [Longest Repeating Character Replacement](https://leetcode.com/problems/longest-repeating-character-replacement/) — #424 · Medium
   - **Зорилго:** Нэрэнд заасан нөхцөлийг хангах хамгийн урт/богино хэсэг, зам эсвэл дарааллыг ол.
   - **Хэрэглээ:** Текст хайлт, өгөгдөл цэвэрлэх, формат шалгах болон хэлний боловсруулалтад.
   - **Бодох чиглэл:** Тэмдэг бүрийг нэг удаа боловсруулах боломжийг хайж, давтамж эсвэл индекс хадгал.
