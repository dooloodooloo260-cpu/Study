# Day 28: Массивын хувиргалт ба давтамж

**Түвшин:** Дунд шат  
**Хичээлийн сэдэв:** Массивын хувиргалт ба давтамж

## Суралцах зүйл

In-place эргүүлэлт, modulo индекс, frequency Map.

## Java дасгал

## Дууссан гэж үзэх шалгуур
