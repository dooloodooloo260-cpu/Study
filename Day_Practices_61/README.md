# Day 61: LeetCode бодлого

Энд бодлого бүрийн зорилго, ямар төрлийн асуудалд хэрэглэх, бодож эхлэх чиглэлийг Монгол хэлээр товчлов. Оролтын нарийн формат, жишээ, хязгаарлалтыг LeetCode холбоосоос шалгаарай.

Өнөөдрийн 5 бодлого. Бусад өдрийн бодлоготой давхцахгүй.

1. [Largest Divisible Subset](https://leetcode.com/problems/largest-divisible-subset/) — #368 · Medium
   - **Зорилго:** Асуудлыг давтагддаг жижиг төлөвүүдэд хувааж боломжийн тоо эсвэл хамгийн сайн үр дүнг ол.
   - **Хэрэглээ:** Олон сонголтоос ашиг/зардал, алхам, замын хамгийн сайн үр дүнг тооцоход.
   - **Бодох чиглэл:** Төлөв, шилжилт, base case-аа бичээд давтагдсан дэд асуудлын хариуг хадгал.
2. [Sum of Two Integers](https://leetcode.com/problems/sum-of-two-integers/) — #371 · Medium
   - **Зорилго:** Нэрэнд заасан элементүүдийн нийлбэрийг зорилтот нөхцөлтэй уялдуулан ол.
   - **Хэрэглээ:** Тоон хөрвүүлэлт, тоолол, геометр, үр ашигтай арифметикт.
   - **Бодох чиглэл:** Хязгаар, parity, модуль эсвэл томьёог ашиглаж бүх хувилбарыг шалгах шаардлагыг багасга.
3. [Super Pow](https://leetcode.com/problems/super-pow/) — #372 · Medium
   - **Зорилго:** Массив эсвэл тоон дарааллын элементүүдээс нэрэнд заасан үр дүнг олж/өөрчил.
   - **Хэрэглээ:** Жагсаалтын хос, хэсэг, дараалал болон байрлалыг тооцоход.
   - **Бодох чиглэл:** Оролтын хэмжээ, эрэмбэ, давхардалд тулгуурлан HashMap, хоёр заагч, prefix sum эсвэл sliding window-ийг сонго.
4. [Find K Pairs with Smallest Sums](https://leetcode.com/problems/find-k-pairs-with-smallest-sums/) — #373 · Medium
   - **Зорилго:** Өгөгдлөөс зорилтот утга, байрлал эсвэл мужийг ол; эхний/сүүлийн тохиолдлыг шаардлагатай бол ялга.
   - **Хэрэглээ:** Жагсаалтын хос, хэсэг, дараалал болон байрлалыг тооцоход.
   - **Бодох чиглэл:** Оролтын хэмжээ, эрэмбэ, давхардалд тулгуурлан HashMap, хоёр заагч, prefix sum эсвэл sliding window-ийг сонго.
5. [Guess Number Higher or Lower](https://leetcode.com/problems/guess-number-higher-or-lower/) — #374 · Easy
   - **Зорилго:** Эрэмбэлэгдсэн өгөгдөл эсвэл боломжит хариунаас зорилтот утга, байрлал, хязгаарыг хай.
   - **Хэрэглээ:** Том хайлтын муж, босго утга, эрэмбэлэгдсэн өгөгдөлд хурдан хайлт хийхэд.
   - **Бодох чиглэл:** Хариуны боломжит мужид monotonic нөхцөл байгаа эсэхийг шалгаад binary search хэрэглэ.
