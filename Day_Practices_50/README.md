# Day 50: LeetCode бодлого

Энд бодлого бүрийн зорилго, ямар төрлийн асуудалд хэрэглэх, бодож эхлэх чиглэлийг Монгол хэлээр товчлов. Оролтын нарийн формат, жишээ, хязгаарлалтыг LeetCode холбоосоос шалгаарай.

Өнөөдрийн 5 бодлого. Бусад өдрийн бодлоготой давхцахгүй.

1. [Perfect Squares](https://leetcode.com/problems/perfect-squares/) — #279 · Medium
   - **Зорилго:** Массив эсвэл тоон дарааллын элементүүдээс нэрэнд заасан үр дүнг олж/өөрчил.
   - **Хэрэглээ:** Жагсаалтын хос, хэсэг, дараалал болон байрлалыг тооцоход.
   - **Бодох чиглэл:** Оролтын хэмжээ, эрэмбэ, давхардалд тулгуурлан HashMap, хоёр заагч, prefix sum эсвэл sliding window-ийг сонго.
2. [Expression Add Operators](https://leetcode.com/problems/expression-add-operators/) — #282 · Hard
   - **Зорилго:** Stack ашиглан өмнөх төлөв, хаалт эсвэл дараагийн их/бага элементийн хамаарлыг боловсруул.
   - **Хэрэглээ:** Хаалт шалгах, undo, илэрхийлэл задлах болон дараагийн их/бага элементийг олоход.
   - **Бодох чиглэл:** Стекэд хадгалах төлөв, push/pop хийх мөчийг дүрмээр тодорхойл.
3. [Move Zeroes](https://leetcode.com/problems/move-zeroes/) — #283 · Easy
   - **Зорилго:** Массив эсвэл тоон дарааллын элементүүдээс нэрэнд заасан үр дүнг олж/өөрчил.
   - **Хэрэглээ:** Жагсаалтын хос, хэсэг, дараалал болон байрлалыг тооцоход.
   - **Бодох чиглэл:** Оролтын хэмжээ, эрэмбэ, давхардалд тулгуурлан HashMap, хоёр заагч, prefix sum эсвэл sliding window-ийг сонго.
4. [Peeking Iterator](https://leetcode.com/problems/peeking-iterator/) — #284 · Medium
   - **Зорилго:** Нэрэнд заасан үйлдлүүдийг шаардлагатай хурдтай дэмжих өгөгдлийн бүтцийг загварчил.
   - **Хэрэглээ:** Кэш, индекс, санамсаргүй сонголт, API-ийн төлөв хадгалалтад.
   - **Бодох чиглэл:** Үйлдэл бүрийн хурдны шаардлагад нийцүүлэн бүтцүүдийг хослуулж, шинэчлэлтийн invariants-ийг хадгал.
5. [Find the Duplicate Number](https://leetcode.com/problems/find-the-duplicate-number/) — #287 · Medium
   - **Зорилго:** Өгөгдлөөс зорилтот утга, байрлал эсвэл мужийг ол; эхний/сүүлийн тохиолдлыг шаардлагатай бол ялга.
   - **Хэрэглээ:** Жагсаалтын хос, хэсэг, дараалал болон байрлалыг тооцоход.
   - **Бодох чиглэл:** Оролтын хэмжээ, эрэмбэ, давхардалд тулгуурлан HashMap, хоёр заагч, prefix sum эсвэл sliding window-ийг сонго.
