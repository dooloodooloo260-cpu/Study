# Day 29: LeetCode бодлого

Энд бодлого бүрийн зорилго, ямар төрлийн асуудалд хэрэглэх, бодож эхлэх чиглэлийг Монгол хэлээр товчлов. Оролтын нарийн формат, жишээ, хязгаарлалтыг LeetCode холбоосоос шалгаарай.

Өдөр бүр хийх 5 бодлого. Нийт 90 өдрийн жагсаалт нь бодлогын нэр, дугаар,
хэцүүгийн түвшин, LeetCode холбоостой.

1. [Two Sum](https://leetcode.com/problems/two-sum/) — #1 · Easy
   - **Зорилго:** Нэрэнд заасан элементүүдийн нийлбэрийг зорилтот нөхцөлтэй уялдуулан ол.
   - **Хэрэглээ:** Жагсаалтын хос, хэсэг, дараалал болон байрлалыг тооцоход.
   - **Бодох чиглэл:** HashMap-д өмнө үзсэн утгуудыг хадгалж, одоогийн утгад зорилтот нийлбэр хүргэх нөхөх утгыг хай.
2. [Add Two Numbers](https://leetcode.com/problems/add-two-numbers/) — #2 · Medium
   - **Зорилго:** Урвуу дарааллаар цифр хадгалсан хоёр холбоост тоог нэмж шинэ жагсаалтаар илэрхийл.
   - **Хэрэглээ:** Дараалсан өгөгдөлд оруулах/устгах, холбоос урвуулах болон жагсаалтыг алхахад.
   - **Бодох чиглэл:** Нэг нэг цифрийг нэмээд carry-г дараагийн байрлалд дамжуул; жагсаалтуудын урт ялгаатайг шалга.
3. [Longest Substring Without Repeating Characters](https://leetcode.com/problems/longest-substring-without-repeating-characters/) — #3 · Medium
   - **Зорилго:** Нэрэнд заасан нөхцөлийг хангах хамгийн урт/богино хэсэг, зам эсвэл дарааллыг ол.
   - **Хэрэглээ:** Текст хайлт, өгөгдөл цэвэрлэх, формат шалгах болон хэлний боловсруулалтад.
   - **Бодох чиглэл:** Sliding window ба тэмдэгтийн сүүлийн индексийг хадгал; давхардалд зүүн заагийг урагшлуул.
4. [Median of Two Sorted Arrays](https://leetcode.com/problems/median-of-two-sorted-arrays/) — #4 · Hard
   - **Зорилго:** Өгөгдлийг эрэмбэлэх эсвэл эрэмбийн шинжийг ашиглан шаардагдах үр дүнг ол.
   - **Хэрэглээ:** Тайлангийн дараалал, эрэмбэлсэн хайлт, давхцал болон top-K олоход.
   - **Бодох чиглэл:** Хоёр эрэмбэлэгдсэн массивыг хуваах binary search хийж, зүүн/баруун хэсгийн заагуудыг тэнцүүл.
5. [Longest Palindromic Substring](https://leetcode.com/problems/longest-palindromic-substring/) — #5 · Medium
   - **Зорилго:** Нэрэнд заасан нөхцөлийг хангах хамгийн урт/богино хэсэг, зам эсвэл дарааллыг ол.
   - **Хэрэглээ:** Текст хайлт, өгөгдөл цэвэрлэх, формат шалгах болон хэлний боловсруулалтад.
   - **Бодох чиглэл:** Тэмдэгтийн төв болон хоёр тэмдэгтийн завсраас хоёр тийш тэлж хамгийн уртыг хадгал.

Эдгээр таван бодлогын Java жишээ энэ хавтсанд тусдаа `.java` файлаар байна.
